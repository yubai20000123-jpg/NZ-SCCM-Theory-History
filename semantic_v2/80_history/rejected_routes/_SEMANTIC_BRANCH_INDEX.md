# Rejected-route semantic branch

This branch exists to prevent rejected analytical experiments from being resurrected merely because their legacy files live under `current/theory` or carry historical `PASS/CURRENT` labels.

Examples already direct-audited include:

- global D-q panel Chebyshev surrogate R07R as formal production;
- global energy-potential material replacement;
- low-order M1 structured polynomial route;
- PF1/Picard–Fuchs / large auxiliary connection routes that exceeded production-complexity bounds;
- old user-sketch/local D-q surrogate routes.

Their mathematical/audit evidence is retained. Production identity is rejected/superseded.
