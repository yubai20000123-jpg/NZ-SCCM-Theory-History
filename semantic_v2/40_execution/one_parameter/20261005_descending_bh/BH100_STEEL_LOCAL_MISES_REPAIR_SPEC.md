## Separate global yielding from local postbuckling yielding
Let the current corrected global base stress at a continuous steel point be
g = (gx, gy, gtau).

Let the elastic Yun/R06 local increment be
l = (lx, ly, ltau).

First correct the global base by the already chosen current-state steel law if its global Mises value exceeds fy.

Then add the local increment through a local remaining-capacity multiplier lambda_l.

Plane-stress Mises:
Phi(sx,sy,tau) = sx^2 - sx*sy + sy^2 + 3*tau^2.

For sigma = g + lambda_l*l:
Phi = a*lambda_l^2 + 2*b*lambda_l + c0

where
a = lx^2 - lx*ly + ly^2 + 3*ltau^2
b = gx*lx - 0.5*(gx*ly + gy*lx) + gy*ly + 3*gtau*ltau
c0 = gx^2 - gx*gy + gy^2 + 3*gtau^2.

If Phi(g+l) <= fy^2, lambda_l = 1.

Otherwise solve
a*lambda_l^2 + 2*b*lambda_l + c0 - fy^2 = 0
and select the largest real root in [0,1] lying on the admissible connected loading direction.

Thus local first yield is pointwise/algebraic. No single controlling point is allowed to reduce the recoverable amplitude of the entire steel face.

## Face force
After local limiting:
sigma_y(x,y,zeta) = gy + lambda_l(x,y,zeta)*ly.

The face mean is the continuous integral
mean_sigma_y = (1/(b*ah*ts)) * integral_A integral_thickness sigma_y d(zeta) dA.

Face axial force:
P_s = b*ts*mean_sigma_y.

The yield-region boundary is an algebraic level set Phi=fy^2. No spatial Gauss/material-point discretization is part of the theory.
