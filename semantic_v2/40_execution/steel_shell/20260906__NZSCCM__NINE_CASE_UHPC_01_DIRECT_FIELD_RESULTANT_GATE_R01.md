## 0. Purpose

Use the newly extracted physical-direction UHPC peak state to test the current 01 compression backend independently from the global generalized-state closure.

The gate is

\[
\varepsilon_y^{FEM}(x,z)\to\sigma_{01}(\varepsilon_y^{FEM})\to N_U^{pred}
\]

using the archived effective cross-section weights. This is a material/resultant forward audit only. FEM values are not used to fit parameters.

The current 01 compression law is retained exactly:

\[
A_c=E_c\varepsilon_{c0}/f_c,\quad B_c=6-5A_c,\quad C_c=4A_c-5,
\]

\[
\sigma_{01}(\varepsilon)=E_c\varepsilon+
\frac{f_cB_c}{\varepsilon_{c0}^5}\varepsilon^5-
\frac{f_cC_c}{\varepsilon_{c0}^6}\varepsilon^6,
\qquad -\varepsilon_{c0}\le\varepsilon\le0,
\]

with `Ec=43.4 GPa`, `fc=141.1 MPa`, `eps_c0=0.0035`.

## 3. Thickness-linearization gate

At each of the 18 physical width stations, the actual FEM axial strain records were independently fitted to

\[
\varepsilon_y(x,z)=\varepsilon_0(x)+\kappa(x)z.
\]

Replacing the raw FEM strain records by these local linear-through-thickness fits before applying the 01 law changes the predicted full-section resultant by only:

| case | change from raw-field 01 resultant |
|---|---:|
| BH032 | +0.00519% |
| BH050 | -0.00102% |
| BH060 | -0.00100% |
| BH070 | -0.00239% |
| BH085 | -0.00603% |
| BH100 | -0.01199% |

Therefore, for these six cases,

\[
\boxed{\text{local through-thickness affine strain + 01 exact section primitive is not the dominant error source.}}
\]

The critical issue is not the affine `z` form itself, but how the generalized membrane strain/curvature fields are generated and distributed over the plate.

## 6. Consequence for the Aghayere–MacGregor route

The preferred architecture is now

\[
(u,v,w)\to \varepsilon^0(x,y),\kappa(x,y)
\to \varepsilon(x,y,z)=\varepsilon^0(x,y)+z\kappa(x,y)
\to \text{01 UHPC local section primitive}
\to N(x,y),M(x,y)
\to \text{generalized equilibrium / virtual work}.
\]

This replaces the old force-first logic in which a single prescribed/capacity section state was inverted from `N,M` and then interpreted as the deformation state.
