## 6. R06 的最新纠偏：没有所谓“上下 topology 组合”

此前为了 Excel 程序实现，曾把完整二维极值位置拆成：

`INTERIOR / U+ / U- / V+ / V- / C++ / C+- / C-+ / C--`

甚至进一步提出上下钢面 `10×10` 组合。

**用户明确质疑这是新增私货；复核后确认：该外层组合不是技术总账本身，已经撤销。**

技术总账真正的数学要求只是对同一个完整二维 Mises 多项式：

`Phi(u,v)`

计算：

`max_{u,v in [-1,1]^2} Phi(u,v)`

内部驻点、四条边驻点、四角点只是求这个 MAX 的**内部数学步骤**，不是用户参数、不是结构状态，也不应作为上下钢面外层组合。

当前 Excel 改为统一方程：

- `(1-u^2) Phi_u = 0`
- `(1-v^2) Phi_v = 0`

这样内部点、边、角点在同一个代数方程中自动覆盖。

R06 内部求根变量仍是：

- `lambda_upper, u_upper, v_upper`
- `lambda_lower, u_lower, v_lower`

它们是**内部求根变量，不是用户输入参数**。

R06 projected state 的接触条件通过 `Phi=fy^2` 与 `lambda` 的关系表达；`lambda=1` 表示不需要径向投影，但最终仍需由完整根集合/全域最大值检查确认。
