## 2. Exact R02-compatible local mode identities

phi=(1-cos(kx*x))(1-cos(ky*y)), kx=2*pi/Lx, ky=2*pi/Ly.

- kx = 0.0111701072127637 1/mm
- ky = 0.0113097335529233 1/mm
- cx = 3*kx²/8 = 4.67892356792384e-05 1/mm²
- cy = 3*ky²/8 = 4.79662773892943e-05 1/mm²
- Ds = Es*ts³/[12(1-nu_s²)] = 1207326.007326007355 N mm

Exact cell integrals:

- int(phi²)dA = 9 Lx Ly / 4
- int(phi_x²)dA = 3 Lx Ly kx² / 4
- int(phi_y²)dA = 3 Lx Ly ky² / 4
- int(phi_xx²)dA = 3 Lx Ly kx⁴ / 4
- int(phi_yy²)dA = 3 Lx Ly ky⁴ / 4
- int(phi_xy²)dA = Lx Ly kx² ky² / 4
- int(phi_xx phi_yy)dA = Lx Ly kx² ky² / 4

The x-averaged axial geometric mismatch generated by d=U²-A0² is

g_y_bar(y)=3/4*d*ky²*sin²(ky*y)
          =cy*d*[1-cos(2*ky*y)].

Since ky=2*pi/Ly, the fluctuating term is the n=4 harmonic:
g4(y)=-cy*d*cos(4*pi*y/Ly).

## 3. Exact partial-interaction harmonic kernel

For one harmonic:
s(y)=S_n sin(n*pi*y/L)
g(y)=g_n cos(n*pi*y/L)

K_eq = K_s K_c/(K_s+K_c)

U_rel = 1/2 int K_eq (s'+g)² dy + 1/2 int k_P s² dy

Exact integrals:
- int(s²)dy = S_n² L/2
- int(s'²)dy = S_n² n² pi²/(2L)
- int(s' g)dy = S_n g_n n pi/2
- int(g²)dy = g_n² L/2

Stationarity gives:

S_n = -g_n n*pi*L /(n²*pi² + Lambda)

Lambda = k_P L²/K_eq = C_P L/K_eq
C_P = k_P L
C0 = K_eq/L
bar(C_P)=C_P/C0=Lambda

Force-mobilization/restraint ratio:
eta_n = Lambda/(n²*pi²+Lambda)

Slip-relief ratio:
r_n = n²*pi²/(n²*pi²+Lambda)

For R02 geometric forcing n=4:
eta_4 = Lambda/(16*pi²+Lambda).

## 7. Formal matrix insertion

Let local internal vector l=[A,S]^T. The exact local tangent block is

J_ll = [[k_A, k_AS],
        [k_AS, k_S]]

with
k_S = int K_eq h'² dy + int k_P h² dy
k_AS = int K_eq h' g_,A dy
k_A = k_A,plate + int K_eq [g_,A²+(s'+g)g_,AA] dy.

For one A-S pair:
J_ll^-1 = 1/(k_A k_S-k_AS²) * [[k_S,-k_AS],[-k_AS,k_A]]

If g_A=∂R_x/∂A and g_S=∂R_x/∂S are 4x1 columns,

J4_cond = J_xx -
 [k_S g_A g_A^T - k_AS(g_A g_S^T+g_S g_A^T)+k_A g_S g_S^T]
 /(k_A k_S-k_AS²).

The global terminal must use this condensed tangent, not the old uncondensed 4x4 section Jacobian.
