## 0. Purpose

Execute the next step after the direct physical-strain gate: determine the minimum low-order membrane basis needed to reconstruct the corrected FEM physical axial membrane-strain profile at the peak mid-gauge section.

This audit does **not** fit material parameters and does **not** prescribe production amplitudes from FEM. FEM is used only to determine whether a proposed kinematic basis has sufficient representational capacity.

## 1. Coordinate correction that controls this audit

The physical-direction workbook verifies:

\[
\text{FE global X}=x_{width},\qquad
\text{FE global Z}=y_{axial},\qquad
\text{FE global Y}=z_{thickness}.
\]

Therefore the corrected physical axial strain is the tensor component projected onto FE-global-Z/physical-y, not the historical solid `LE22` interpretation. Any old `epsilon0/kappa` ledger formed by treating solid `LE22` as axial strain must be re-audited.

## 2. Collapse from 864 UHPC records to 18 width stations

For each case and each of the 18 physical width stations \(x_j\), the 48 UHPC records through thickness were fitted by weighted least squares to

\[
\varepsilon_y(x_j,z)
=\varepsilon_y^0(x_j)+\kappa_y(x_j)\,\zeta,
\]

where \(\zeta\) is the local thickness coordinate centered at the weighted station centroid. The effective-area weights from the physical-direction workbook were retained.

The resulting \(\varepsilon_y^0(x)\) is the object audited below.

## 3. Candidate symmetric harmonic basis

Using centered width coordinate \(x\in[-B/2,B/2]\), fit

\[
\varepsilon_y^0(x)
=c_0+\sum_{n=1}^{N}c_n\cos\left(\frac{2n\pi x}{B}\right).
\]

The first harmonic is physically attractive because it can be generated by one axial in-plane displacement amplitude while satisfying uniform end displacement:

\[
\boxed{
v(x,y)
=-\lambda y
+q_{v1}\sin\left(\frac{2\pi y}{a}\right)
\cos\left(\frac{2\pi x}{B}\right)
}
\]

so at the audited mid-gauge \(y=a/2\), for a first global out-of-plane half-wave whose \(w_{,y}\) vanishes there,

\[
\varepsilon_y^0(x)
=-\lambda
-\frac{2\pi q_{v1}}{a}
\cos\left(\frac{2\pi x}{B}\right).
\]

Thus one additional membrane DOF \(q_{v1}\) beyond the path parameter \(\lambda\) generates the leading observed widthwise redistribution mode.

A second optional mode is

\[
q_{v2}\sin\left(\frac{2\pi y}{a}\right)
\cos\left(\frac{4\pi x}{B}\right).
\]

## 7. Resultant sensitivity

For BH032--BH100, replacing the raw widthwise FEM physical axial strain by even a low-order reconstructed profile changes the 01 UHPC resultant very little. With the one-harmonic profile, the change relative to the direct raw-FEM-strain 01 resultant is approximately:

- BH032: +0.040%
- BH050: -0.003%
- BH060: -0.002%
- BH070: -0.006%
- BH085: -0.019%
- BH100: -0.035%

This shows that the widthwise mode is essential primarily for local strain/stress redistribution, peak-event location and coupled equilibrium, not because many harmonics are required to integrate the total UHPC force.

## 8. Immediate modelling decision

The first Aghayere-type kinematic candidate should therefore be **minimal**, not a return to a large Ritz system:

\[
\boxed{
\lambda\;\text{(path parameter)}
+q_{v1}\;\text{(one symmetric axial membrane-redistribution DOF)}
+\bar\varepsilon_x\;\text{or equivalent transverse equilibrium DOF}
+q\;\text{(global out-of-plane amplitude)}.
}
\]

Use

\[
v(x,y)=-\lambda y+q_{v1}\sin(2\pi y/a)\cos(2\pi x/B)
\]

as the first axial in-plane enrichment. The transverse field should initially remain the lowest DOF needed to satisfy \(R_x=0\); do not add higher \(u\) harmonics until a direct residual/profile gate proves them necessary.

The optional second axial membrane mode

\[
q_{v2}\sin(2\pi y/a)\cos(4\pi x/B)
\]

is **reserve mode M2**, to be activated only if BH032 or path-wide audits fail the one-mode gate.
