The source file

Therefore the historical explicit Airy theory does not support the statement

as a frozen identity.

This is a valid reconstruction of the **elastic Airy front**. It is not, however, a source-supported replacement for the membrane strain state of the nonlinear UHPC + R02/R06 + web section.

```text

```

to

```text
elastic Airy strain -> nonlinear material response, with resultant equilibrium no longer enforced
```

which is a different approximation and is not frozen by the source theory.

Hence

