# 紫线钢壳双模态＋非线性横向平均膜力释放：从几何到虚功的重新建模（2026-10-31）

**身份**：这是紫线材料算子在双模态上的扩展；并非2026-10-25纯钢板紫线的原样复现。用户确认增加每片试算钢壳的平均横向膜力为零。保持双模态非线性外层变量 W,A；给定轴向端缩 d，另需由非线性标量方程确定横向均匀应变 e_perp。绝不使用线弹性泊松近似替代真正的释放条件。

## 1. 几何

域 `0≤x≤b,0≤y≤a`，x横向，y轴压方向，z穿厚；s为钢板厚度。压缩应变 d>0。X=πx/b，Y=πy/a。

Φ=sinX sinY； Ψ=[1−cos(2NX)][1−cos(2mY)]/4，N,m为正整数。Ψ≥0，最大1，子仓边界 Ψ=∂n Ψ=0。外鼓A≥0。

初始：w0=W0Φ+A0Ψ； 当前：wt=(W0+W)Φ+(A0+A)Ψ；新增：Δw=WΦ+AΨ。注意W0=b/400仅为代表试算输入；A0=t/60指**局部峰值**，不同于原未归一化代码的系数。

Φx=(π/b)cosXsinY，Φy=(π/a)sinXcosY，Φxx=−(π²/b²)Φ，Φyy=−(π²/a²)Φ，Φxy=(π²/ab)cosXcosY。

Ψx=(Nπ/2b)sin(2NX)[1−cos(2mY)]；Ψy=(mπ/2a)[1−cos(2NX)]sin(2mY)。

Ψxx=(N²π²/b²)cos(2NX)[1−cos(2mY)]；Ψyy=(m²π²/a²)[1−cos(2NX)]cos(2mY)；Ψxy=(Nmπ²/ab)sin(2NX)sin(2mY)。

定义 Z=2W0W+W²，H=W0A+A0W+WA，J=2A0A+A²。

真实几何膜应变：
`ε^g_x= Z Φx²/2 + H ΦxΨx + J Ψx²/2`；
`ε^g_y= Z Φy²/2 + H ΦyΨy + J Ψy²/2`；
`γ^g_xy= Z ΦxΦy + H(ΦxΨy+ΦyΨx) + J ΨxΨy`。

## 2. 面内解析预凝聚和非线性平均横向释放

**新增的平均横向释放是真实额外约束，不是弹性泊松替换**。位移：
`u(x,y)=e_perp*x+Σ_i c_i U_i(x,y)`，`v(x,y)=−d*y+Σ_i c_i V_i(x,y)`。

允许的六组面内位移试函数（未列位移分量取0）：

```
i    U_i                                  V_i
1    b/(2π) sin(2X)                       0
2    b/(2π) sin(2X)cos(2Y)                0
3    0                                     a/(2π)sin(2Y)
4    0                                     a/(2π)cos(2X)sin(2Y)
5    b/(2πN)sin(2NX)[1−cos(2mY)]         0
6    0                                     a/(2πm)[1−cos(2NX)]sin(2mY)
```

这些是一个固定、有限的Ritz位移子空间，不是对真实位移场的唯一精确表示。定义 β_i=[U_i,x,V_i,y,U_i,y+V_i,x]，和对称平面应力矩阵 `C=E/(1−ν²)[[1,ν,0],[ν,1,0],[0,0,(1−ν)/2]]`。

**仅用于预凝聚**的六元线性方程
`Σ_j K_ij c_j = −f_i`，其中 `K_ij=<β_i^T C β_j>`，`f_i=<β_i^T C ([e_perp,−d,0]+ε^g)>`。

每项由有限Fourier积精确解析积分。结果 `c=−K⁻¹f`，**它们不进入非线性方程组**。紫线原来的两个p,q也是按弹性膜能预凝聚的，双模态后需要重新推导，不能机械复制0.15、0.175。

中面应变：`ε^m=[e_perp,−d,0]+Σ_i c_i β_i+ε^g`。

定义单位幅值曲率三向函数：`κ_Φ=−t[Φxx,Φyy,2Φxy]` 和 `κ_Ψ=−t[Ψxx,Ψyy,2Ψxy]`。

总应变按归一化厚度坐标 ξ=z/t，`−1/2≤ξ≤1/2`：
`ε(x,y,ξ)=ε^m(x,y)+ξ[W κ_Φ(x,y)+A κ_Ψ(x,y)]`。

重要：横向应变 e_perp 进入**当前完整非线性应力计算**，由 `Σ_j ω_j n_{xj}=0` 决定，而不是预先填入线弹性的 `νd` 或 `νd−<εx^g+νεy^g>`。它在塑性段一般不能闭式消元。

## 3. 七节点解析Lagrange投影

`T=Ψ²=sin⁴(Nπx/b)sin⁴(mπy/a)`；`q_j=[1−cos((j−1)π/6)]/2`，j=1,…,7。

`L_j(T)=∏_{i≠j}(T−q_i)/(q_j−q_i)`；`ω_j=<L_j>`，其中 `<f>=(ab)⁻¹∫_0^b∫_0^a f dxdy`。对于正整数N,m，上述T的分布与原单波形变量相同，因此原七节点**权重数值**恰好不变；**任何新的几何应变、曲率及Mises矩都必须重算**。

`e_j^m=<L_j ε^m>/ω_j`，`κ_j=<L_j (Wκ_Φ+Aκ_Ψ)>/ω_j`；定义 `n_j=∫_{−1/2}^{1/2}σ_j dξ`，`m_j=∫_{−1/2}^{1/2}ξσ_jdξ`。

注意真实连续剪应变可能不为零，即使某个插值节点代表剪应变接近零，计算Mises平方前不能删去连续剪切平方。

## 4. 平面应力Mises平方先投影后厚度二次展开

H_VM=[[1,−1/2,0],[−1/2,1,0],[0,0,3]]；`σ⁰(x,y,ξ)=C[ε^m(x,y)+ξ(Wκ_Φ+Aκ_Ψ)]`。

首先定义完整板面场：`s⁰=Cε^m`，`s¹=C(Wκ_Φ+Aκ_Ψ)`。

`Q_j(ξ)=<L_j(s⁰+ξs¹)^T H_VM(s⁰+ξs¹)>/ω_j`
`=c0_j+c1_j ξ+c2_j ξ²`，其中
`c0_j=<L_j(s⁰)^T H_VM s⁰>/ω_j`；
`c1_j=2<L_j(s⁰)^T H_VM s¹>/ω_j`；
`c2_j=<L_j(s¹)^T H_VM s¹>/ω_j`。

屈服根满足 `c2 ξ²+c1 ξ+c0−fy²=0`，仅保留物理厚度内根，形成弹性/塑性片段；全厚塑性且Mises最小点 ξ*=−c1/(2c2) 在内部时保留两条端点弦线。这沿用原紫线算法。若带符号插值造成某节点Q<0，记录投影非物理状态，不悄悄称为真实材料点。

截面代表弹性试应力 `σ⁰_j(ξ)=<L_j s⁰>/ω_j+ξ<L_j s¹>/ω_j`。弹性段直接积分；塑性段两端取 `σ^P_j(ξ)=fy/√Q_j(ξ)·σ⁰_j(ξ)`，两端间用线性弦线；全厚塑化时顶点双弦避免单弦切换造成的内力跳变。

## 5. 弹性核心抗弯能的缺失和恢复

`Dexact_pq=<κ_p^T C κ_q>`，p,q∈{Φ,Ψ}。
`D7_pq=Σ_j ω_j κ_{p,j}^T C κ_{q,j}`，`ΔD=Dexact−D7`。

`χ_D=12 Σ_j ω_j Σ_[l,h]∈elastic_j (h³−l³)/3`。

`R_D,i=(χ_D/12) Σ_{p∈{Φ,Ψ}} ΔD_{i p} q_p`，幅值q=(W,A)。该工程补偿沿用紫线的原思路，不是χ的完整链式势能导数。

## 6. 两模态膜容量——明确为紫线推广的新结构假定

每个方向i∈{W,A}的几何膜应变速率（保持外加d和e_perp不变）为 `g_i=∂ε^m/∂q_i`（包含预凝聚面内系数随幅值的解析导数）。

轴压方向为y，定义正交常数 `c_i=<g_{i,y}+νg_{i,x}>`，节点正向独立膜虚功 `B_{j,i}=n_j·g_{j,i}−c_i n_{y,j}`。在原正方形单波退化且g=η' a时，该式恢复原紫线 `η'[a_j(n_x+n_y)−0.4875 n_ax]`。

几何储备标量：`E_j=|ε^g,cond_{y,j}−<ε^g,cond_y+ν ε^g,cond_x>|`，其中 `ε^g,cond` 包括非均匀面内弹性预凝聚后的几何部分，不含均匀d和e_perp。

阈值为与轴压方向对应的Ritz特征应变：
`εcr,i = <κ_i^T C κ_i> / [12 E <(∂φ_i/∂y)²>]`，这里κ_i含t，故无量纲。

候选推广 `g_{j,i}=max(0,1−εcr,i/max(E_j,tol))`；`Rcap,i=−Σ_j ω_j g_{j,i} max(B_{j,i},0)`。

**这一两模态膜容量定义是新假定；不是从原紫线唯一推出的，也未通过新钢壳全过程验证。绝不把它的失败归咎于Mises或者横向释放。**

## 7. 三个实际代数条件 / 两个外层面外自由度

对于给定端缩d：

`R_W = Σ_j ω_j[n_j·∂e^m_j/∂W + m_j·κ_Φ,j] + R_D,W+Rcap,W=0`。
`R_A = Σ_j ω_j[n_j·∂e^m_j/∂A + m_j·κ_Ψ,j] + R_D,A+Rcap,A=0`（A>0）；A=0时单侧条件 R_A≥0。
`R_⊥=Σ_j ω_j n_{x,j}=0`。

三未知 `(W,A,e_perp)` 对应三残量。**可实现为外部W,A二元、内部e_perp一元求根，但严格代数维数是3而不是2。** 非线性Mises使内层e_perp一般没有纯解析闭式消元。

总钢板轴压反力 `P=−btΣ_j ω_j n_{y,j}`，不可再次把膜虚功容量Rcap从荷载P中扣除。

## 8. 解析Ritz临界应变闭式

令 λx=2Nπ/b，λy=2mπ/a，则局部Ψ形函数有
`<Ψxx²>=3λx⁴/64`，`<Ψyy²>=3λy⁴/64`，`<ΨxxΨyy>=λx²λy²/64`，`<Ψxy²>=λx²λy²/64`，`<Ψy²>=3λy²/64`。

直接得到 `εcr,A = t²/[12(1−ν²)] × [3λx⁴+3λy⁴+2λx²λy²]/[3λy²]`。

整体 Φ，令 α=π/b、β=π/a，`εcr,W=t²/[12(1−ν²)] × (α²+β²)²/β²`。

在b=a=2500mm,t=4mm,N=5,m=4,ν=.3，`εcr,W=9.25501365×10⁻⁶`、`εcr,A=6.63854417×10⁻⁴`；5000mm分别为`2.31375341×10⁻⁶`和`1.65963604×10⁻⁴`。

## 9. 实际执行及性质

代码为`rebuild_lateral.py`，解析Fourier内核`fourier_exact.py`，源紫线相关算子`purple_projection_kernel.py`。`check_geometry_energy.py`严格检查**原紫线投影膜能＋连续抗弯能**的导数与R值，不是完整连续膜能（原紫线原本没有补膜能）；W,A,e_perp方向的弹性对应误差≤1.7×10⁻⁹。固定W,A下通过非线性横向求根后，`|R⊥|`达10⁻¹⁴MPa量级。

完整W,A双模式求根试算记录在`roots_2size.csv`：初步找到的有效候选多在A=0边界；承载力数值明显失真。**这证明这版双模式容量的具体推广仍不能产生可信的钢壳Pu或加载路径；不能宣布移植已得到正确峰值。** 公式合同、解析积分和横向释放可作为下一版明确的基准，不应为拟合荷载而修改横向边界条件。
