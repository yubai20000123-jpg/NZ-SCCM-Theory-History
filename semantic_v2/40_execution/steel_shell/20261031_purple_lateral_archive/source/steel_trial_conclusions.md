# 2026-10-31 原锁定模型试算（无公式调整）

计算对象：单片钢壳，两种板宽 b=a=2500、5000 mm，t=4 mm，N=5，m=4，E=206000 MPa，ν=0.3，fy=355 MPa；W0=b/400，A0=t/60。

模型：`rebuild_lateral.py`，七节点Lagrange解析投影，Mises分段双弦，弹性核心抗弯恢复，固定上一版双模态膜容量候选，横向平均膜力在非线性应力计算后等于零。

扫描：给定轴向端缩 d，共17个初始/中/后期状态每个板宽；通过 R_W=0、N_x平均=0 求 A=0 边界分支，核验R_A>=0。

补充：在d=0.0014至0.00185加密16个点；并对若干d进行15个不同W/A初值的内部根搜索，不宣称穷尽全部根。

## 结果

- b=2500 mm，17点中的最大载荷：0.01367512 MN，d=0.0015000，平均轴向压应力1.367512 MPa。此数为扫描最大值，不是已验证Pu。
- b=5000 mm，17点中的最大载荷：0.00681508 MN，d=0.0015000，平均轴向压应力0.340754 MPa。此数为扫描最大值，不是已验证Pu。

观察：主要平衡分支 A=0；在极早期d≈1e-5至2.5e-5可以搜索到A≈0.0001–0.0004 mm的极小正值内部根；中后期未检索到大幅度稳定局部鼓曲。

当前峰前荷载尺度相对接近 E*εcr,W，其中单片板的临界应变按已锁定的形函数由薄板Ritz弯曲能/几何功计算；这不是组合柱Pu。2500mm与5000mm的板宽翻倍导致εcr,W约降为1/4，荷载反而约为1/2，表明整体屈曲控制。

在d≈0.00166–0.00178的狭窄区间，χ_D从1降至0，同时荷载急剧下降。局部振幅仍为零，故下降机制不能解释为局部波后屈曲。

重要限制：尚未与FEM钢壳应力曲线比较；没有UHPC和PBL；当前两模态膜容量是尚未经六件钢板检验的新推广；根的数学存在性和KKT满足不等于完整路径稳定性；未取得有说服力的局部后屈曲Pu。

详见 `trial_fixed_20261031.csv`、`phase_scan_20261031.csv`、`execute_trial.log`和`phase_audit.log`，全程无板面积分网格/Gauss。
