## 2. Why the naive J4-Schur block is not a physical bending tangent

Let the terminal capacity-resultant map use coordinates

`x = [e ; beta]`,

where `e` denotes the two membrane-like affine coordinates and

`beta = [B_x^cap, B_y^cap]^T`

is the pair of capacity coordinates. Partition

`J4 = d[N;M]/d[e;beta]`

`J4 = [[K_Ne, K_Nbeta], [K_Me, K_Mbeta]]`.

If `K_Ne` is nonsingular, the algebraic Schur complement is

`D_cap = K_Mbeta - K_Me K_Ne^{-1} K_Nbeta`.

This object is a legitimate condensed derivative **with respect to the chosen capacity coordinate beta**. It is not automatically the physical work-conjugate derivative `dM/dkappa`.

### Coordinate-rescaling falsification

Reparameterize only the nonphysical capacity coordinate by an arbitrary nonzero scalar `lambda`:

`beta_tilde = lambda beta`.

Then

`d beta / d beta_tilde = 1/lambda`,

so

`K_Nbeta_tilde = K_Nbeta/lambda`,

`K_Mbeta_tilde = K_Mbeta/lambda`,

and hence

`D_cap_tilde = D_cap/lambda`.

Thus a Navier load obtained by directly inserting `D_cap` as physical `D_x, D_y, D_mu` would change under a mere reparameterization of a capacity-surface coordinate, unless a work-conjugate mapping to the physical curvature is also supplied.

No such `beta <-> kappa` identity exists in the current R02 theory; in fact R02 explicitly prohibits treating `B^cap` as physical curvature.

**DIRECT_J4_SCHUR_AS_PHYSICAL_D = INVALID**.
