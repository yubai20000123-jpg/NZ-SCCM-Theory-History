# NZ-SCCM 05 — BH050 Kt→slip-amplitude kinematic sweep R01

本文件只做 05 双界面滑移层的解析/数值门禁，不调用 FEM Pu 反标，也不修改 production R14。

采用 BH050 当前冻结几何/初始相刚度：

- b = 2500 mm
- a = 5000 mm
- m* = 2
- beta = pi/b
- tc = 42 mm
- ts = 4 mm
- Aw = 1332 mm^2
- zf = 23 mm
- Es = 206000 MPa
- nu_s = 0.3
- Ec = 43400 MPa
- nu_c = 0.2
- k+ = 296 Kt
- k- = 370 Kt

相刚度按 05-R01：

K+ = K- = Qs b ts

Kc = (1-rho_w) Qc b tc + Es Aw

固定滑移基函数：

s+(y)=S+ cos(beta y)

s-(y)=S- cos(beta y)

结论：

1. `Kt` 不改变 `cos(beta y)` 的滑移基函数；只改变 `S+,S-` 的幅值。
2. 随 `Kt` 增大，`S+,S-→0`。
3. 数值上 `c+,c-→1`，`zcPI→0`，`z+PI→+23 mm`，`z-PI→-23 mm`。
4. 因而 05 的滑移层在运动学层面通过 `Kt→∞` 的完全组合极限门禁。
5. 如果完整 `R4/J4/Pu` 在 `Kt→∞` 下不能回到冻结 R14，则错误不在本 2×2 滑移幅值方程，而应继续定位在 section assembly / local operator / continuation / terminal implementation。
