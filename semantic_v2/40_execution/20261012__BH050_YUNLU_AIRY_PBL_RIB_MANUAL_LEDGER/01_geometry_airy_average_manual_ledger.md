# 01 | 三层几何 → Yun-Lu Airy 特解 → 平均截面应力：纸笔完整计算账本

记号约定：应力拉正、压负； `x` 横向、`y` 轴向；本文件一切应力函数 `Φ` 产生**应力**（MPa），不直接产生力膜量。单位厚度膜应力结果乘各层厚度 `t_i` 得 N/mm。`W`、`A_+`、`A_-` 为加载新增幅值，初始 `w0,A0±` 另计。

## 1.01 三层位移母式（零应力时无新增位移）

- 组合芯板（UHPC）： `w_c^0=w0*φ`, `w_c=w0*φ+W*φ`。
- 上钢面：`w_+^0=w0*φ+A0+*ψ`, `w_+=w0*φ+W*φ+A0+*ψ+A+*ψ`。
- 下钢面：`w_-^0=w0*φ-A0-*ψ`, `w_-=w0*φ+W*φ-A0-*ψ-A-*ψ`。
- `φ=sin(αx)sin(βy)`, `α=π/b,β=π/a`；`ψ=(1-cos kx x)(1-cos ky y)`, `kx=2Nπ/b,ky=2mπ/a`。
- PBL 纵肋线必须来自实测 `x_j`；如果恰为 `x_j=j*b/N`，ψ=ψ_x=ψ_y=0；此条件验证了局部模式在肋线满足零相对位移及零一阶斜率，**不指定 A±**。

## 1.02 把平方项每一行写出

设 `s=+1` 上壳、`s=-1` 下壳；记当前 `w_s^0+w_s^added=(w0+W)φ+s(A0s+As)ψ`。

`[w_s^current,x]^2 = [(w0+W)φ_x+s(A0s+As)ψ_x]^2`

`= (w0+W)^2 φ_x² + 2s(w0+W)(A0s+As)φ_xψ_x + (A0s+As)^2 ψ_x²`。

`[w_s^initial,x]^2 = [w0 φ_x+s A0s ψ_x]^2`

`=w0² φ_x²+2s w0 A0s φ_xψ_x+A0s² ψ_x²`。

用第一式逐项减第二式：

- 整体项 `(w0+W)^2−w0² = w0²+2w0W+W²−w0² = 2w0W+W²`。
- 交叉项 `(w0+W)(A0s+As)−w0A0s = w0A0s+w0As+WA0s+WAs−w0A0s = WA0s+(w0+W)As`。
- 局部项 `(A0s+As)^2−A0s²=A0s²+2A0sAs+As²−A0s²=2A0sAs+As²`。

所以几何膜应变（中面）x 分量：

`gx,s = [W²+2w0W]φ_x²/2 + s[WA0s+(w0+W)As]φ_xψ_x + [As²+2A0sAs]ψ_x²/2`。

y 分量把 x 换 y：

`gy,s = [W²+2w0W]φ_y²/2 + s[WA0s+(w0+W)As]φ_yψ_y + [As²+2A0sAs]ψ_y²/2`。

工程剪应变的几何增量：

`gxy,s = [W²+2w0W]φ_xφ_y + s[WA0s+(w0+W)As](φ_xψ_y+φ_yψ_x) + [As²+2A0sAs]ψ_xψ_y`。

将 `As=0` 代回：

`gx,s(As=0)=Qg φ_x²/2+s(WA0s)φ_xψ_x`；可见仍保留初始局部缺陷与 W 的交叉项，**不得删除**。

## 1.03 含初始缺陷的二维 Airy 兼容（单层子域无平面分布连接体力）

各层线弹性（平面应力），令 `Φ_i` 的应力恢复关系为

`σ_x,i=Φ_i,yy ; σ_y,i=Φ_i,xx ; τ_xy,i=−Φ_i,xy`。

则对于已减去初始缺陷的 von Kármán 膜应变，有

`∇⁴Φ_i=E_i { w_added,xy²−w_added,xx*w_added,yy +2*w0,xy*w_added,xy−w0,xx*w_added,yy−w_added,xx*w0,yy }`。

这对应云露式(2-23)按当前坐标改写。注意：仅在肋间无分布面内连接力的子域中可直接这样写；在实际肋线上各层应力的界面牵引允许跳跃，必须另外施加连接条件，不能把三张全域平滑 Airy 当作已联立。

三个来自几何的幅值：

`Qg=W²+2w0W`；`Ql,s=As²+2A0sAs`；`Qx,s=WA0s+(w0+W)As`。

于是：

`∇⁴Φ_c =Ec*Qg*[φ_xy²−φ_xx φ_yy]`。

`∇⁴Φ_s =Es{ Qg[φ_xy²−φ_xxφ_yy] +Ql,s[ψ_xy²−ψ_xxψ_yy] +s Qx,s[2φ_xyψ_xy−φ_xxψ_yy−ψ_xxφ_yy] }`。

逐式可在 W=0,As=0 时看到三个 Q 均为 0，故新增应力特解全为零，满足初始基准约定。

## 1.04 整体 φ 源项的三角化（不省略中间平方）

`φ_xx=−α² sinαx sinβy`；`φ_yy=−β² sinαx sinβy`；`φ_xy=αβ cosαx cosβy`。

`φ_xy²=α²β² cos²αx cos²βy`。

`φ_xxφ_yy=(−α²sinαx sinβy)(−β²sinαx sinβy)=α²β² sin²αx sin²βy`。

相减得 `α²β²[cos²X cos²Y−sin²X sin²Y]`。

`cos²X=(1+cos2X)/2`；`sin²X=(1−cos2X)/2`；Y 同理。

`cos²X cos²Y−sin²X sin²Y`

`=[(1+cos2X)(1+cos2Y)−(1−cos2X)(1−cos2Y)]/4`

`=[1+cos2X+cos2Y+cos2Xcos2Y−1+cos2X+cos2Y−cos2Xcos2Y]/4`

`=[2cos2X+2cos2Y]/4=[cos2X+cos2Y]/2`。

故 `Gg=α²β²[cos(2αx)+cos(2βy)]/2`。

因 `∇⁴cos(2αx)=(2α)^4 cos(2αx)=16α⁴cos(2αx)`，得

`Φg,i = Ei Qg{[β²/(32α²)]cos2αx+[α²/(32β²)]cos2βy}`。

核对 x 谐波：`16α⁴*[β²/(32α²)]=α²β²/2`；y 谐波亦同。

纵向非均匀膜应力特解为

`σy,g,i =∂xxΦg,i= −Ei Qg (β²/8)cos(2αx)`。

## 1.05 局部 ψ 的完整七谐波推导

记 `X=kx*x,Y=ky*y`, `cX=cosX,cY=cosY`, 则

`ψ_xx=kx² cX(1−cY)`；`ψ_yy=ky²(1−cX)cY`；`ψ_xy=kxky sinXsinY`。

`[ψ_xy²−ψ_xxψ_yy]/(kx²ky²)`

`=(1−cX²)(1−cY²)−cXcY(1−cX)(1−cY)`

`=1−cX²−cY²+cX²cY²−cXcY+cX²cY+cXcY²−cX²cY²`

`=1−cX²−cY²−cXcY+cX²cY+cXcY²`。

以 `cX²=(1+cos2X)/2` 和 `cY²=(1+cos2Y)/2` 替换：

`=1−(1+cos2X)/2−(1+cos2Y)/2−cosXcosY`

` + [(1+cos2X)/2]cosY+cosX[(1+cos2Y)/2]`

`=−(cos2X)/2−(cos2Y)/2−cosXcosY`

` +(cosY)/2+(cos2XcosY)/2+(cosX)/2+(cosXcos2Y)/2`。

因此一项一项积分的局部 Airy 特解：

`Φl,i =Ei Ql *{`

` +(ky²/(2kx²))cosX `

` −(ky²/(32kx²))cos2X `

` +(kx²/(2ky²))cosY `

` −(kx²/(32ky²))cos2Y `

` −kx²ky²/(kx²+ky²)² cosXcosY `

` +kx²ky²/[2(4kx²+ky²)²] cos2XcosY `

` +kx²ky²/[2(kx²+4ky²)²] cosXcos2Y }`。

其中 `i` 取具体材料刚度，钢壳 `Ei=Es`， `Ql=Ql,s`。UHPC 无 ψ 时此项为零。

例如前面 `cosXcosY` 这一项：`∇⁴(cosXcosY)=(kx²+ky²)²*cosXcosY`；因此系数乘回后恰恢复 `−Ei Ql kx²ky² cosXcosY`。

**重要**：此 Φl 为兼容方程的特解。边界对应的双调和齐次场不能简单置零。

## 1.06 整体×局部交叉源项及独立谐波频率

完整混合源项（上／下壳外鼓号 s 在整个源项前）：

`Gx=2αβkxky cosαx cosβy sin(kx x)sin(ky y)`

` +α²ky² sinαx sinβy[1−cos(kx x)]cos(ky y)`

` +β²kx² sinαx sinβy cos(kx x)[1−cos(ky y)]`。

这来自：`2φ_xyψ_xy −φ_xxψ_yy−ψ_xxφ_yy`，所有符号逐项追溯上一行的二阶导数。

对于 `ky=8β`，

`sinβy cos8βy=[sin9βy−sin7βy]/2`；

`cosβy sin8βy=[sin9βy+sin7βy]/2`；

故混合源项只产生纵向正弦波数 `n=1,7,9`（还包括对应的横向混合频率）。

整体 Gg 产生 `n=0,2`（cos）；局部 Gl 产生 `n=0,8,16`（cos）；因此**H4 条件算例纵向非零谐波候选恰为 `{1,2,7,8,9,16}`，加上 n=0**。

这意味着按真实纵肋逐谐波建立齐次补偿时，是有限谐波工作，而不是“对每个材料点做网格积分”。但是每个实体肋间的边界条件仍必须单独代入。

## 1.07 均匀应力齐次部分的独立求解（M0 平均模型）

三层的均匀齐次应力函数：

`Φh,i^uniform = 0.5*σy,bar,i*x²+0.5*σx,bar,i*y² − τbar_i*x*y`。

其两次偏导：`∂xx=σy,bar,i`; `∂yy=σx,bar,i`; `−∂xy=τbar_i`。均匀项的拉压反力由边界条件控制，不属于特解。

为了计算平均应变，与此同时选取中面公共运动的平均线应变 `e_x0,e_y0`，平均非线性贡献 `χ_x,i,χ_y,i`；并声明层内补充面内函数的平均导数在本算例中被设为 0（这正是 M0 的边界假定）。

`Kc=Ec/(1−νc²)`；`Ks=Es/(1−νs²)`。

`σx,bar,i =Ki[(e_x0+χx,i)+νi(e_y0+χy,i)]`。

`σy,bar,i =Ki[νi(e_x0+χx,i)+(e_y0+χy,i)]`。

本次不把 UHPC 核心空间扣掉的 PBL 肋面积既当独立肋又当核心连续材料；M0演示版只比较**核心+两钢面，不含肋自身轴向刚度**。需计入真实肋钢材时，在总 N 和平均约束中独立加上肋线应力/面积。详见 03。

## 1.08 平均三角积分：每个系数都能人工复算

`<f>=(1/(ab))∫_0^b∫_0^a f dxdy`。

`<φ_x²>= α² <cos²αx><sin²βy> =α²(1/2)(1/2)=α²/4`。

`<φ_y²>= β² <sin²αx><cos²βy> =β²(1/2)(1/2)=β²/4`。

`<ψ_x²>=kx² <sin²kxx><(1−coskyy)²>`。

`<sin²kxx>=1/2`。

`<(1−coskyy)²>=<1−2coskyy+cos²kyy>=1−2*0+1/2=3/2`。

所以 `<ψ_x²>=kx²*(1/2)*(3/2)=3kx²/4`；y 同理 `<ψ_y²>=3ky²/4`。

求交叉积分时先分别积分：

`(1/b)∫_0^b cosαx sin2Nαx dx = 4N/[π(4N²−1)]`；

`(1/a)∫_0^a sinβy (1−cos2mβy)dy =8m²/[π(4m²−1)]`。

前式用 `cos t sin2Nt=[sin(2N+1)t+sin(2N−1)t]/2`，后式用 `sin t cos2mt=[sin(2m+1)t+sin(1−2m)t]/2`，端点积分都是 `2/(整数频率)`。

再乘 `φ_x ψ_x` 的 `α*kx=α*(2Nα)=2Nα²` 得

`<φ_xψ_x> = [2Nα²]*[4N/(π(4N²−1))]*[8m²/(π(4m²−1))]`

`=[2*4*8*N²*m²*α²]/[π²(4N²−1)(4m²−1)]`

`=64N²m²α²/[π²(4N²−1)(4m²−1)]`。

对 `<φ_yψ_y>` 互换 x/y、N/m，得 `64N²m²β²/[π²(4N²−1)(4m²−1)]`。

从 `φ_xx=−α²φ`, `<φ>= (2/π)*(2/π)=4/π²`, 所以 `<φ_xx>=−α²*4/π²=−4/b²`。相应 `<φ_yy>=−4/a²`。

## 1.09 每层平均几何应变逐项

`Qg=W²+2w0W`, `Ql±=A±²+2A0±A±`, `Qx±=WA0±+(w0+W)A±`。

UHPC（中面 z=0）：

`χx,c=Qg*α²/8`，`χy,c=Qg*β²/8`。

上壳（中面 z+=+(tc+ts)/2）：

`χx,+=4z+W/b²+Qg α²/8+Qx+*[64N²m²α²/(π²(4N²−1)(4m²−1))]+Ql+*3kx²/8`；

`χy,+=4z+W/a²+Qg β²/8+Qx+*[64N²m²β²/(π²(4N²−1)(4m²−1))]+Ql+*3ky²/8`。

下壳 z-=−z+，与上壳类似但交叉前置负号：

`χx,-=4z_-W/b²+Qg α²/8−Qx-*[64N²m²α²/(π²(4N²−1)(4m²−1))]+Ql-*3kx²/8`；

`χy,-=4z_-W/a²+Qg β²/8−Qx-*[64N²m²β²/(π²(4N²−1)(4m²−1))]+Ql-*3ky²/8`。

**统一写法**： `χ_{q,s}=4 z_s W/L_q² + Qg k_q²/8 + s Qx,s C_q + Ql,s *3k_loc,q²/8`，其中 `(L_x,L_y)=(b,a)`，`(k_q)=(α,β)`，`C_q` 为 1.08 的交叉系数。不可将减号误用在偏心项上。

## 1.10 横向自由总合力 → 唯一公共横向均匀应变

定义 `Tc=tc*Kc`，`Ts=ts*Ks`。因为核心＋两钢面总横向平均膜力为零，写：

`0=Tc[(e_x0+χx,c)+νc(e_y0+χy,c)]`

`  +Ts[(e_x0+χx,+)+νs(e_y0+χy,+)]`

`  +Ts[(e_x0+χx,-)+νs(e_y0+χy,-)]`。

将 e_x0 项收集：

`0=(Tc+Ts+Ts)e_x0+(Tc νc+Ts νs+Ts νs)e_y0`

`  +Tc(χx,c+νcχy,c)+Ts(χx,++νsχy,+)+Ts(χx,-+νsχy,-)`。

先把 `Tc+Ts+Ts=Tc+2Ts`；`Tcνc+Tsνs+Tsνs=Tcνc+2Tsνs`。

于是

`e_x0 =−{(Tcνc+2Tsνs)e_y0+Tc(χx,c+νcχy,c)+Ts[(χx,++χx,-)+νs(χy,++χy,-)]}/(Tc+2Ts)`。

**这是 M0 已经实际完成的消元公式**，不是平均轴向压力任意指定。

平均纵向压力：

`P_M0(W,A+,A-,e_y0)=−b{ Tc[νc(e_x0+χx,c)+e_y0+χy,c] +Ts[νs(e_x0+χx,+)+e_y0+χy,+] +Ts[νs(e_x0+χx,-)+e_y0+χy,-] }`。

上式仍含 e_y0，必须由三层合体面外整体 Galerkin 平衡（或给定力控制边界下的相应轴力条件）确定。**不能因为 e_x0 已消去就报告 P(W)**。
