## 1. User intent to preserve

The production result must be a **visible calculation ledger that can be entered into Excel**. The formal chain must start from specimen/material inputs and proceed by explicit formulas to the coupled ultimate-capacity solution. A conceptual derivation, a blocked gate, or a workbook that merely pastes coefficients generated by external code is not completion.

Execution must continue until a complete ledger exists. If one analytic organization becomes impractical, switch route rather than stopping at a half-product.

## 2. Material doctrine

R10/R13 is a fixed current-material system for a given material parameter set. Geometry/specimen identity does not modify the material law.

Formal chain:

```text
raw material parameters
-> direct continuous strain state from structural kinematics
-> direct R10/R13 current operator at that strain state
-> stress / virtual-work integrand
-> continuous analytic integration
-> P, Rq, Ralpha and same-source derivatives
-> Rq=0, Ralpha=0, det(Jlim)=0
-> Du, qu, alphau, Pu
```

The following are NOT formal production layers:

- material-coordinate sampling;
- N48/N96 material grids;
- specimen-specific material polynomial fits;
- panel-level response fits;
- spatial Gauss/Simpson/adaptive quadrature/material-point grids.

R13's finite global truncated-power spline is retained because it is pointwise identical to the frozen R10 tensile law, not a fit.

## 3. Primary exact-integration route

First try to reorganize the continuous integral by material-state reduction rather than approximating the material law.

Use principal-state interpretation for exposition:

```text
CC: eps1<0, eps2<0
TC: eps1*eps2<0
TT: eps1>0, eps2>0
uniaxial boundaries: eps1=0 or eps2=0
```

For computation prefer invariants J1=tr(E), J2=det(E) where possible:

```text
CC: J2>0, J1<0
TC: J2<0
TT: J2>0, J1>0
boundary: J2=0
```

The purpose is to change the organization/order of integration and separate structural occupancy weights from the R10/R13 material surface. Increasing integral multiplicity is admissible only when it produces an analytic change-of-variables / coarea / layer-cake representation; it is not a numerical spatial discretization.

## 4. Fallback route if exact R10/R13 integration remains non-Excel-evaluable

Do NOT fit a specimen-specific 2D material surface.

Instead simplify only the **source one-dimensional scalar material curves** while preserving the R10 multi-axial CC/TC/TT assembly structure. The simplified scalar curves must be source-constrained, finite, Excel-evaluable, and intentionally conservative. The original R10/R13 remains the audit reference.

Conservatism must be checked at material level for stress/tangent/work over the physically used strain range, then checked at structural Pu level. The fallback is a different explicit material approximation, not a change in specimen-specific material identity.

## 5. Reinforcement generalization

The production workbook must support two independently positioned reinforcement rows in each direction:

```text
(rho_x1, z_x1), (rho_x2, z_x2)
(rho_y1, z_y1), (rho_y2, z_y2)
```

Symmetric two-row reinforcement is a special case z1=+hr/2, z2=-hr/2. A single mid-plane row is the degenerate case rho2=0, z1=0.

The reinforcement contribution must be analytic and may not introduce spatial integration points. If yielding is reached, use a finite global constitutive expression or a separately documented analytic treatment; do not silently retain an elastic formula.

## 6. Completion criterion

Completion is ONLY when a workbook exists in which:

1. user changes raw geometry/material/reinforcement inputs;
2. all downstream material/kinematic/integral coefficients update by workbook formulas;
3. no external generator must be rerun and no coefficients must be pasted manually;
4. Solver only solves the final structural unknowns, not material fitting;
5. P, Rq, Ralpha, Jlim and Pu are visible and traceable;
6. at least Case21 and one materially/geometrically different benchmark are calculated by changing inputs only;
7. formula errors are zero in the production ranges;
8. an independent audit calculation is provided.

Case21 experimental load is post-solve comparison only and never enters fitting/root selection.
