## 3. Why no global Pu is released for Shi

The source specimen contains steel-bar trusses whose stated functions include carrying vertical load and restraining local buckling, plus edge CFST members. Those are not passive connector-only boundary devices in the current frozen reduced NC + two-faceplate object.

The current ordinary-concrete R10 operator also requires `eps0` as an explicit material input; it is not generated by the R10 energy fit. No source-frozen `eps0` for the exact Shi specimen has been recovered.

Consequently a global `D,q,A` root would require either deleting source load-resisting members or inventing a concrete material input. Both are prohibited.

## 5. Zhou ultimate-capacity comparator correction

The previous raw cross-section strength comparison is not the proper Zhou ultimate-capacity comparison.

Zhou's axial stability identity is

\[
\boxed{P_u=\varphi_NP_{yth}}.
\]

For the four-edge simply-supported axial case, the proposed factor in Eqs. (5-87)-(5-88) is

\[
\varphi_N=
\begin{cases}
1,&\lambda_n\le0.55,\\
\dfrac{1}{\Phi+\sqrt{\Phi^2-\lambda_n^2}},&\lambda_n>0.55,
\end{cases}
\]

where

\[
\Phi=
\begin{cases}
0.454+0.192\lambda_n+0.416\lambda_n^2,&\lambda_n\le1.0,\\
-0.140+1.387\lambda_n-0.186\lambda_n^2,&\lambda_n>1.0.
\end{cases}
\]

Accordingly:

```text
Pyth_reduced = section-strength baseline only
Pyth_reduced as ultimate comparator = RETIRED
correct Zhou ultimate comparator = phi_N(lambda_n) * Pyth
```

The previously calculated `39.2928 MN` remains valid only as `Pyth_reduced` on the same reduced section.

A numerical `Pu_Zhou,emp` is intentionally withheld until the source-exact definition of `lambda_n` is recovered and evaluated for the same structural object. The common normalized-slenderness form is not inserted by assumption.
