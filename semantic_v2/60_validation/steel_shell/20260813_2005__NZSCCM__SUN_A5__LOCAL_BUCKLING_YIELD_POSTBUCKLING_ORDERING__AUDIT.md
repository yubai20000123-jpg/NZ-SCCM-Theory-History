## 2. Separate events on one global branch

The coupled solver must distinguish at least:

- `B_s`: activation of a local shell buckling/postbuckling mode;
- `Y_s`: first local steel yield / ideal-EP strength boundary;
- `K_Z=0`: current condensed global tangent loss;

None of these events is automatically identical to another.


For one local amplitude:

\[

\[
