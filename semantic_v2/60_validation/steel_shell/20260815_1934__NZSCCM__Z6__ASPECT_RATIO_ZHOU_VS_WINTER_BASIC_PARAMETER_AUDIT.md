# Z6 长宽比修改前后：从基本设计参数重算周思铭经验公式与 Winter 公式

**Timestamp:** 2026-08-15 19:34 +08:00

## 1. 固定设计参数

保持 Z6 截面与材料不变，仅修改加载方向长度 a：

- b = 12000 mm
- h = 130 mm
- ns = 60
- ls = 200 mm
- ts = 4 mm
- fy = 355 MPa
- fcu = 40 MPa
- f'c = 0.76 fcu = 30.4 MPa
- Es = 206000 MPa
- Ec = 32500 MPa
- nu_s = 0.30
- nu_c = 0.20

三种几何：

1. 原 Z6: a=9000 mm, a/b=0.75
2. 方形: a=12000 mm, a/b=1.00
3. 高板: a=15000 mm, a/b=1.25

## 2. 截面强度基准

混凝土面积：

Ac = ns (ls-ts)(h-2ts) = 1,434,720 mm^2

钢面积：

As = bh - Ac = 125,280 mm^2

截面理论轴压强度：

Pyth = fy As + f'c Ac = 88.089888 MN

由于仅改变 a，三个算例的 Ac, As, Pyth 完全相同。

## 3. Zhou 弹性屈曲骨架

保持同一截面后：

Dx = 1.14610310e10 N mm
Dy = 1.1986113713333336e10 N mm
H  = 1.2160676566638557e10 N mm

对 m=1：

Pcr = b*pi^2 [ Dx a^2/(m^2 b^4) + 2H/b^2 + Dy m^2/a^2 ]

得到：

- a/b=0.75: Pcr = 42.83147561 MN
- a/b=1.00: Pcr = 39.28801472 MN
- a/b=1.25: Pcr = 41.04137379 MN

因此从 0.75 -> 1.00，Pcr 下降 8.273%；从 1.00 -> 1.25，Pcr 回升 4.463%。这一趋势与经典 m=1 简支板 k=(a/b+b/a)^2 的能量规律一致。

## 4. 归一化长细比

lambda_n = sqrt(Pyth/Pcr)

- 0.75: 1.4341068510
- 1.00: 1.4973833062
- 1.25: 1.4650487766

## 5. Zhou Eq.5-87/5-88 经验下包络

三个 lambda 均 >1，因此：

Phi = -0.140 + 1.387 lambda - 0.186 lambda^2

phi_Zhou = 1 / [ Phi + sqrt(Phi^2-lambda^2) ]

Pu_Zhou = phi_Zhou Pyth

结果：

- 0.75: phi=0.563883518, Pu=49.67243594 MN
- 1.00: phi=0.561775794, Pu=49.48676675 MN
- 1.25: phi=0.562021341, Pu=49.50839695 MN

相对原 Z6：

- square: -0.374%
- 1.25: -0.330%

说明 Eq.5-87/5-88 在 lambda≈1.43~1.50 区间非常平坦，因此它显著削弱了底层 Pcr 的长宽比敏感性。这是经验拟合曲线的性质，不是弹性能量规律。

## 6. Winter Eq.5-86

Zhou 论文给出的 Winter 曲线：

phi_W = 1, lambda<=0.673
phi_W = (1/lambda)(1-0.22/lambda), lambda>0.673

三个算例均采用第二支。

Pu_W = phi_W Pyth

结果：

- 0.75: phi_W=0.590328688, Pu_W=52.00198798 MN
- 1.00: phi_W=0.569711862, Pu_W=50.18585413 MN
- 1.25: phi_W=0.580072394, Pu_W=51.09851222 MN

相对原 Z6：

- 0.75 -> 1.00: Pu_W 下降 3.492%
- 1.00 -> 1.25: Pu_W 回升 1.819%
- 0.75 -> 1.25: Pu_W 仍低 1.737%

Winter 因为 phi_W(lambda) 在该区间保持明显单调响应，所以保留了 Pcr 能量变化的明显“先降后升”趋势。

## 7. 关键裁决

1. Z6 的底层 Zhou 弹性 Pcr 对 a/b 的响应没有违反能量法；它与 Z4 以及经典简支板趋势一致。
2. Zhou Eq.5-87/5-88 的 Pu 对 a/b 几乎不敏感，是因为该 FE 拟合下包络在 lambda≈1.45 附近非常平，不应被当成纯能量响应。
3. Winter 公式对同一 Pyth/Pcr 输入给出 52.002 -> 50.186 -> 51.099 MN，明确体现从 a/b=0.75 到 1.0 降低、再到 1.25 回升的经典趋势。
4. 因而后续检查 NZ-SCCM 的长宽比响应时，应同时列出 Pcr、lambda、Winter Pu 与 Zhou-fit Pu；不得只看 Zhou-fit Pu。
5. 这次计算不改变任何 NZ-SCCM 材料或求解理论，仅纠正比较基准和解释方式。
