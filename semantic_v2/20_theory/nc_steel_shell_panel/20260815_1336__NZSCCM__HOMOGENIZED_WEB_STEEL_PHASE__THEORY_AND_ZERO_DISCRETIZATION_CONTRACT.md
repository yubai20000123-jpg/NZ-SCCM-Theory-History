## 1. Geometry-derived web-steel fraction

For cell pitch `ls` and web thickness `ts`, with `b = ns*ls`, define

\[
\boxed{\rho_w=\frac{t_s}{l_s}}.
\]

The equivalent web-steel area in the core is

\[
\boxed{A_{w,eq}=\rho_w b t_c=n_s t_s t_c}.
\]

The remaining concrete area is

\[
\boxed{A_{c,eq}=(1-\rho_w)b t_c}.
\]

Hence material volume is conserved. The forbidden alternative

\[
100\%\;\text{concrete}+\rho_w\;\text{steel}
\]

is not used because it would double-count the replaced core volume.

For Z0-Z6, `ts=4 mm` and `ls=200 mm`, therefore

\[
\boxed{\rho_w=0.02}.
\]

## 2. Exact section-strength identity

The web-phase section baseline is

\[
P_{yth}^{web}
=(1-\rho_w)f'_c b t_c
+f_y\rho_w b t_c
+f_y(2bt_s).
\]

Since `rho_w*b*tc = ns*ts*tc`, this is algebraically identical to the original full-section steel/concrete bookkeeping used on the Zhou side. This is a geometry identity, not a fitted correction.

The web phase therefore restores the omitted web-steel material amount without restoring discrete web topology.

## 3. Kinematics and material map

The web phase shares the locked Nguyen second-order continuous strain field. It introduces no displacement DOF and no web index.

For loading direction `y`,

\[
\varepsilon_y^w=\varepsilon_y(D,q;X,Y,z),
\qquad
z\in[-t_c/2,t_c/2].
\]

The first diagnostic web-steel current map uses the same ideal-elastic/plastic local radial-cap identity as the current steel diagnostic, reduced to uniaxial form:

\[
u=\frac{E_s\varepsilon_y^w}{f_y},\qquad r=u^2,
\]

\[
\alpha(r)=\begin{cases}
1,&r\le1,\\
r^{-1/2},&r>1,
\end{cases}
\]

\[
\boxed{\sigma_y^w=f_y\,u\,\alpha(u^2)}.
\]

Thus the uniaxial web stress is elastic before yield and capped at `+-fy` after yield. No steel hardening is introduced.

## 6. Explicit limitation

The continuous web phase restores material amount and its homogenized loading-direction stress/tangent contribution. It does **not** claim to reproduce all discrete-web topology effects, in particular:

- periodic lateral support of outer faceplates;
- discrete-cell boundary conditions;
- the full original orthotropic `Dx,Dy,Dxy,Dmu,H` topology;
- local web plate buckling.

Therefore:

```text
WEB_MATERIAL_CONTRIBUTION = REPRESENTED
DISCRETE_WEB_SUPPORT_TOPOLOGY = NOT REPRESENTED
```

No empirical factor is introduced to compensate for the omitted topology.
