======================================================================
D. GLOBAL MODE / AIRY
======================================================================
ell_m = a_phys / m
alpha = pi / b
beta_m = m*pi/a_phys = pi/ell_m
psi = sin(alpha*x)*sin(beta*y)
q0 = A0g / b
w0 = b*q0*psi
w = b*(q0+q)*psi
wd = b*q*psi
Q(q) = q*(q+2*q0)
kappa_x_geo = b*q*alpha^2*psi
kappa_y_geo = b*q*beta^2*psi
At modal antinode and ell=b: kappa_x_geo = kappa_y_geo = pi^2*q/b

Ncr_m = [Dx*alpha^4 + 2*H*alpha^2*beta_m^2 + Dy*beta_m^4] / beta_m^2
Pcr_m = b*Ncr_m
Select m_star as minimum Pcr_m without comparator information.

Runtime Airy:
P(q) = Pcr*q/(q+q0) + C*Q(q)
NT = Kx*Q(q)*cos(2*beta*y)
NL = -[P(q)/b + G*Q(q)*(1-2*sin(alpha*x)^2)]
MT = Jx*q*sin(alpha*x)*sin(beta*y)
ML = Jy*q*sin(alpha*x)*sin(beta*y)

C,Kx,G,Jx,Jy must be compiled from the audited Airy derivation or supplied as audited coefficients. They are not fitted parameters.

======================================================================
E. R02 LOCAL STEEL FACE
======================================================================
kx = 2*pi/Lx
ky = 2*pi/Ly
phi = (1-cos(kx*xi))*(1-cos(ky*eta))
cx = 3*kx^2/8
cy = 3*ky^2/8
Ds = Es*ts^3/[12*(1-nu_s^2)]
Kb = Ds * [3/4*(kx^4+ky^4) + 1/2*kx^2*ky^2]
d = U^2 - A0^2
Delta = face_sign*b*[(q0+q)*U - q0*A0]
mx = ex - cx*d - hx*Delta
my = ey - cy*d - hy*Delta
mg = gamma - hgamma*Delta

hx,hy,hgamma must be obtained from exact cell registration integrals or supplied as precompiled audited coefficients.

LL harmonics:
(0,1): +1/2
(0,2): -1/2
(1,0): +1/2
(1,1): -1
(1,2): +1/2
(2,0): -1/2
(2,1): +1/2
Lambda_pq = [(p*kx)^2+(q*ky)^2]^2

KA = kx^4*ky^4 * [17/(256*ky^4)+17/(256*kx^4)+1/(8*(kx^2+ky^2)^2)+1/(32*(kx^2+4*ky^2)^2)+1/(32*(4*kx^2+ky^2)^2)]

GL frequencies are finite:
lambda in {+/-alpha, +/-alpha +/- kx}
mu in {+/-beta, +/-beta +/- ky}
KdDelta and KDeltaDelta are exact finite harmonic-energy sums; no sampling.

Qs = Es/(1-nu_s^2)
Gs = Es/[2*(1+nu_s)]
Pi_R02(U) =
0.5*Kb*(U-A0)^2
+0.5*ts*Qs*(mx^2+my^2+2*nu_s*mx*my)
+0.5*ts*Gs*mg^2
+ts*Es*KA*d^2
+2*ts*Es*KdDelta*d*Delta
+ts*Es*KDeltaDelta*Delta^2

Pi is quartic. dPi/dU is cubic.
AUTHORITATIVE ACTIVE SET:
U_star = argmin_{U>=0} Pi_R02(U)
Candidate set = U=0 + every positive real stationary root.
Never impose U>=A0. Never select largest/closest-to-test root.

======================================================================
