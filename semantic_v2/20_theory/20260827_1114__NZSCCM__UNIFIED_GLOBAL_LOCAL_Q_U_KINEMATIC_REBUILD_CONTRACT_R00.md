## 0. Decision

The next SSUHPC theory is **not** to choose between the previously identified `qU` coupling and the common-section-curvature defect. Both are retained because they arise from different terms of the same total kinematics and were both omitted/separated in the current terminal architecture.

The new reconstruction must start from the existing explicit common theory and restore, in one derivation, the relations that were previously lost:

1. common global amplitude `q` -> common composite curvature `kappa^g(q)`;
2. global/local von-Karman cross term `qU` in the steel-face membrane field;
3. reciprocal feedback of `U` into the global `q` equilibrium and of `q` into the local `U` stationarity/yield field;
4. strict separation between local steel-face curvature and common composite-section curvature;
5. current constituent resultants feed the same global virtual-work equation, rather than allowing independent section curvatures to re-close two separate pointwise moment equations.

This is a reconstruction of the governing closure, **not** a new empirical correction to R06.

## 3. Exact decomposition of von-Karman membrane increments

For a steel face, the geometric normal strain increment is generated from the **total** slope field. For example,

\[
\Delta\varepsilon_{xx}^{geom}
=\frac12\left[(w_{g,x}+w_{\ell,x})^2-(w_{g,x}^0+w_{\ell,x}^0)^2\right].
\]

It decomposes exactly into

\[
\boxed{
\Delta\varepsilon_{xx}^{geom}
=\Delta\varepsilon_{xx}^{GG}
+\Delta\varepsilon_{xx}^{GL}
+\Delta\varepsilon_{xx}^{LL}
}
\]

with

\[
\Delta\varepsilon_{xx}^{GG}
=\frac12(W^2-W_0^2)\psi_x^2,
\]

\[
\boxed{
\Delta\varepsilon_{xx}^{GL}
=s_f(WU_f-W_0A_0)\psi_x\phi_{f,x}
}
\]

and

\[
\Delta\varepsilon_{xx}^{LL}
=\frac12(U_f^2-A_0^2)\phi_{f,x}^2.
\]

Likewise,

\[
\boxed{
\Delta\varepsilon_{yy}^{GL}
=s_f(WU_f-W_0A_0)\psi_y\phi_{f,y}
}
\]

and for engineering shear,

\[
\boxed{
\Delta\gamma_{xy}^{GL}
=s_f(WU_f-W_0A_0)
(\psi_x\phi_{f,y}+\psi_y\phi_{f,x}).
}
\]

Therefore the previously studied `qU` effect is not an optional correction. It is the GL term of the same total kinematics whose GG term generated the global postbuckling response and whose LL term is already represented in the R02 condensed local operator.

The previous diagnostic established that the existing R02 mean operator already contains the LL `U^2-A0^2` effect. The missing relation is specifically the GL part and its reciprocal generalized work.

## 4. Common curvature must be generated by q

The stress-free initial imperfection `w_g^0` is not a current bending strain. The common incremental curvature is generated by `Delta w_g=bq psi`:

\[
\boxed{
\boldsymbol\kappa^g(q)
=-bq\{\psi_{,xx},\psi_{,yy},2\psi_{,xy}\}.
}
\]

For the BH family at the global antinode (`a=2b`, `m*=2`, `ell=b`),

\[
\boxed{
\kappa_x^g=\kappa_y^g=\pi^2q/b.
}
\]

Accordingly, `kappa_x` and `kappa_y` are **not independent terminal unknowns** in the rebuilt theory.

Local steel-face curvature from `w_l` remains local and enters the R02 local plate energy/stress field. It is not automatically added to the gross composite-section moment as a common `kappa`.

## 5. No more independent pointwise Mx/My closure

The previous terminal system used independent section variables

\[
(q,\varepsilon_x^0,\kappa_x,\varepsilon_y^0,\kappa_y)
\]

and imposed both

\[
M_x^{sec}=M_x^d,
\qquad
M_y^{sec}=M_y^d.
\]

The 2026-08-27 hard-closure diagnostic showed that these equations are incompatible with the curvature contained in the same global `q` mode after current steel/UHPC redistribution. They therefore cannot simply be retained together with `kappa=kappa(q)`.

The rebuilt theory must use one generalized transverse equilibrium conjugate to the one global amplitude `q`:

\[
\boxed{R_q=0.}
\]

In virtual-work form,

\[
\boxed{
R_q=
\int_{\Omega_h}
\left[
\mathbf N:\frac{\partial\boldsymbol\varepsilon}{\partial q}
+
\mathbf M:\frac{\partial\boldsymbol\kappa^g}{\partial q}
\right]d\Omega
-\frac{\partial W_{ext}}{\partial q}=0.
}
\]

`N` and `M` here are the **current** resultants assembled from UHPC + steel faces + web. The steel-face contribution includes the local `U_f` dependence and the GL `qU_f` terms.

This is the required current-material/global-kinematic feedback that the old `CURRENT_MATERIAL_TANGENT_INTO_AIRY = NO` terminal bridge did not contain.

## 6. Reciprocal q-U coupling

Each local steel amplitude remains an internal generalized coordinate. Before any yield admissibility projection is applied, its condensed stationarity must be written from the same total kinematics:

\[
\boxed{R_{U_f}=\partial\Pi/\partial U_f=0.}
\]

Because the GL term contains `WU_f-W0A0`, the rebuilt residuals necessarily satisfy

\[
\frac{\partial R_q}{\partial U_f}\ne0,
\qquad
\frac{\partial R_{U_f}}{\partial q}\ne0
\]

in general.

Thus the previous triangular `q-U` diagnostic matrix is not a fundamental result; it was triangular because the frozen global Airy residual contained no `U` feedback. In the rebuilt common virtual-work system, the reciprocal terms arise analytically from the same total strain field and require no fitted coupling coefficient.
