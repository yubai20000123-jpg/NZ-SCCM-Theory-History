# NZ-SCCM — NC-M2 拉伸骨架审计修正：撤销强制峰值门禁

时间：2026-08-20 14:51 +08:00

## 1. 用户纠正

用户明确指出：上一轮把 `T(1)=1`、`T'(1)=0` 当成新拉伸函数的硬约束过于僵化。用户希望允许更宽的峰区/平台区，并允许峰值位置不固定在 `t=1`，只要曲线整体物理趋势合理、公式仍保持单式、光滑、低复杂度。

该纠正成立。

## 2. 本轮正式撤回的硬门禁

上一轮新增的以下要求不再作为 production 硬门禁：

- 强制 `t=1` 为唯一峰值点；
- 强制 `T(1)=1`；
- 强制 `T'(1)=0`；
- 以 `t->infinity` 的总拉伸功是否有限作为当前材料候选的单独否决条件。

原因：当前 NZ-SCCM 的 current material operator 服务于有限结构应变域内的连续积分与平衡求解。无穷应变极限可作为材料诊断，但不能在用户尚未选择 fracture-energy / crack-band 正则化之前被擅自升级为硬门禁。

## 3. 继续保留的真正约束

拉伸骨架仍应满足：

- 从零状态连续起始；
- 峰前上升；
- 存在有限峰值或宽峰区；
- 峰后总体软化；
- 不出现人为内部阈值；
- 不使用多段折线；
- 尽量采用一个短有理式；
- 在当前结构相关应变范围内保持非负、光滑、无奇点；
- 不使用 Case21 Pu 反标。

## 4. 用户图示所指方向

用户图示目标不是要求一条精确数字曲线，而是提出形状方向：

- 峰值可以向 `t>1` 移动；
- 峰顶可以较宽，不必是尖锐唯一点；
- `1<t<3` 不要像现 NC-M2 那样快速掉落；
- 中后段保持更缓的软化；
- 仍然应是一个连续单式。

## 5. 当前诊断式（不是 NC-M3，不冻结）

为了验证“单式也可以形成宽峰+缓慢软化”，构造一个仅用于图形方向审计的有理式：

\[
T_d(t)=\frac{t(t+0.09)}{1-0.83t+1.04t^2+0.14t^3}.
\]

该式在 `0<=t<=10` 内无分段、无阈值、无 min/max，并给出约：

- 峰值位置 `t_p≈1.572`；
- 峰值 `T_d≈0.930`；
- `T_d(2)≈0.905`；
- `T_d(4)≈0.703`；
- `T_d(7)≈0.527`；
- `T_d(10)≈0.426`。

它与用户手绘的“宽峰—缓慢下降”方向接近，但这些系数来自图形诊断，不是文献标定，因此当前身份只能是：

`BROAD_PEAK_SINGLE_FORM_DIAGNOSTIC / NOT_A_MATERIAL_CANDIDATE`

## 6. 当前身份

- NC-M1：`REJECTED_DIAGNOSTIC_CANDIDATE`
- NC-M2：`ACTIVE_MATERIAL_CANDIDATE / NOT_YET_PRODUCTION_LOCK`
- 现 NC-M2 tension `t/(1-t+t^2)`：仍需替换/重审，但不再因为“未通过无穷耗能门禁”单独判死；
- 宽峰诊断式：只证明新方向可行，不命名 NC-M3。

下一步应在不强制峰值点的前提下，用普通混凝土拉伸物理趋势和低复杂度共同选择正式单式，然后再按九宫格+四条基础曲线要求绘制完整候选图包。
