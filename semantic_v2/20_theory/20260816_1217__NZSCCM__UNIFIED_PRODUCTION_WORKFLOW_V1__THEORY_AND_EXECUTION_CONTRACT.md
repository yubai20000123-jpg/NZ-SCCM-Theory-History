# NZ-SCCM unified production workflow V1 — theory and execution contract

**Timestamp:** 2026-08-16 12:17 +08:00  
**Identity:** CURRENT PROJECT-WIDE THEORY / EXECUTION CONTRACT

## 0. Objective

This document converts the project-wide method-consistency principle into an executable stage contract. The workflow is modular, but the global mechanics are common. A physical specimen type may select different material/steel/local-buckling adapters; it may not select a different philosophy for kinematics, membrane redistribution, structural integration, root selection or current-tangent stability.

Target families:

```text
NC + rebar
NC + steel shell
UHPC + rebar
UHPC + steel shell
```

## 1. Stage map

```text
S0  specimen/source input freeze
S1  boundary + complete-halfwave selection
S2  continuous Nguyen second-order strain construction
S3  material-family current-operator compilation
S4  phase analytic mapping
S5  moment-first General-D15 exact assembly
S6  internal-coordinate equilibrium/condensation when required
S7  total P,Rq and same-expression derivative assembly
S8  connected Rq=0 branch continuation
S9  primary limit root L=0 / first +->- maximum
S10 same-state consistent-tangent KZ audit
S11 continuous material-domain containment + residual audit
S12 post-solve comparison only
```

No stage is allowed to introduce structural Gauss/Simpson/adaptive quadrature, spatial collocation, material-point grids or specimen-fit surrogates.

## 2. S0 — specimen/source input freeze

Inputs are divided into four independent blocks.

### 2.1 Geometry / boundary block

At minimum:

\[
b,\ a,\ t,\ A_0,\ \text{boundary type},\ \text{stiffener/PBL design data if present}.
\]

The physical total length `a` may contain multiple repeated halfwaves. Production still evaluates one theoretical complete representative halfwave after S1.

### 2.2 Continuum material block

A material family supplies source parameters \(\theta_m\) and

\[
\boxed{\sigma=\mathcal M(\varepsilon;\theta_m)},\qquad
\boxed{\mathbb C_t=\partial\mathcal M/\partial\varepsilon}.
\]

For current NC, `M=R10` is frozen. For UHPC the final multidimensional source current operator remains to be frozen.

### 2.3 Steel-phase block

The steel phase is selected by physical specimen type:

- reinforcement: directions, ratios/areas, layer positions, \(E_s,f_y\), approved current cap;
- shell: layer thicknesses/centroid positions, \(E_s,f_y,\nu_s\), approved plane-stress current operator;
- PBL/web/stiffener: only the source-approved structural role is activated; no automatic load contribution is invented.

### 2.4 Comparator block

Experiment, Zhou, Winter, FE or other reference results are stored separately and are unavailable to S1-S11. They enter only S12.

## 3. S1 — boundary and halfwave selection

A common rule governs all specimen types:

```text
physical/source boundary declared first
-> admissible complete-halfwave family
-> energy/design-boundary minimization or source-approved theoretical selector
-> one representative complete halfwave used in production
```

The current Zhou Z-series uses the theoretical four-edge simply-supported/Navier boundary as already confirmed.

If another specimen family has a genuinely different boundary, its boundary formulas may differ, but the selector must remain theoretical/source-side and independent of experimental Pu.

## 4. S2 — common continuous Nguyen second-order kinematics

The global coordinates are

\[
\boxed{g=(D,q)},\qquad A=qb.
\]

The complete-halfwave field is continuous. The total strain contains:

1. uniform precompression/prebuckling state;
2. second-order membrane terms generated by the imperfect + current transverse deflection field;
3. bending/curvature terms through thickness or layer position;
4. engineering shear terms.

The exact coefficients differ with geometry but the kinematic operator does not.

**Membrane redistribution is always retained.** Stocky specimens are not allowed to disable it; if the effect is physically small, the solution must demonstrate that through the resulting terms.

The required analytic derivatives include

\[
\varepsilon_{,D},\qquad \varepsilon_{,q},
\]

and, where internal coordinates exist,

\[
\varepsilon_{,a_i}.
\]

## 5. S3 — material-family analytic compiler

The compiler takes a source current operator and returns a finite analytic representation compatible with matrix lift and exact moments.

Common interface:

```text
compile_material(
    source_operator,
    source_tangent,
    material_family_domain,
    family_compiler_policy
)
-> finite_coefficients
-> value_error_metrics
-> tangent_error_metrics
-> declared_valid_domain
```

The internal representation may use different analytic bases or converged order for NC and UHPC if their source operators require it. This is an allowed material-family adapter difference.

Not allowed:

```text
case ID -> choose special compiler
Pu error sign -> change compiler
experiment/Zhou/Winter -> select order/domain/coefficients
steel phase type -> change NC/UHPC compiler
```

The same frozen NC compiler must feed both NC+rebar and NC+shell. The same future UHPC compiler must feed both UHPC+rebar and UHPC+shell.

## 6. S4 — phase analytic mappings

Each active phase maps the common strain field into finite analytic stress/tangent objects.

### 6.1 Continuum phase

\[
\sigma_m=\widehat{\mathcal M}(\varepsilon),
\qquad
\widehat{\mathbb C}_{t,m}=\partial\widehat{\mathcal M}/\partial\varepsilon.
\]

The matrix/spectral lift is Cayley-Hamilton or the same approved finite matrix identity.

### 6.2 Reinforcement phase

For each reinforcement direction/layer, project the same continuous strain field to the bar direction and return exact analytic axial stress, resultant, virtual-work and tangent contributions.

### 6.3 Steel-shell phase

For each finite-thickness bonded shell layer, use the same membrane/curvature field over its thickness coordinate. The shell current material law and consistent tangent return exact finite-thickness contributions. No thickness Gauss stack is allowed.

### 6.4 Optional local shell-buckling phase

If a source-grounded shell-local mode is active, introduce a finite set of internal amplitudes \(\mathbf a\) with analytic residuals \(\mathbf R_a=0\). This adapter is absent in rebar-only specimens; its absence does not alter the parent global method.

## 7. S5 — moment-first General-D15 exact assembly

Every scalar integrand required by load, virtual work, derivative or tangent evaluation is compiled to finite analytic terms before structural integration.

The formal structural integrals are evaluated by exact general trigonometric/thickness moments:

\[
\mathscr D[Q]=\sum_k c_k\,J_{p_kr_k}\,J_{u_ks_k}\,Z_{h_k}.
\]

No full-field structural point sampling is an accepted replacement.

Mandatory counters:

```text
N_formal_spatial_sampling = 0
N_formal_spatial_quadrature = 0
N_formal_spatial_subdomains = 1
N_formal_thickness_quadrature = 0
```

## 8. S6 — internal-coordinate equilibrium and exact condensation

If no internal coordinate exists, S6 is the identity map.

If \(\mathbf a\) exists:

\[
\mathbf R_a(D,q,\mathbf a)=0,
\]

\[
\mathbf a_{,g}=-\mathbf R_{a,a}^{-1}\mathbf R_{a,g}.
\]

Use these derivatives to condense all global derivatives exactly. Failure/singularity of \(\mathbf R_{a,a}\) is a physical/numerical event to report; it is not repaired by deleting the local coordinate.

## 9. S7 — universal total resultants and derivatives

All active phases assemble additively:

\[
\boxed{P=\sum_pP_p},
\qquad
\boxed{R_q=\sum_pR_{q,p}}.
\]

The same analytic expressions generate

\[
P_D,\ P_q,\ R_{q,D},\ R_{q,q}.
\]

With internal coordinates use their exact condensed versions.

The determinant is

\[
\boxed{L=P_D R_{q,q}-P_qR_{q,D}}
\]

or the identically formed condensed \(\widetilde L\).

No finite-difference derivative disconnected from the production expressions is permitted as the formal derivative definition.

## 10. S8 — connected equilibrium branch

The physical branch starts from the declared unloaded/imperfect state and follows the connected positive-amplitude solution of

\[
R_q(D,q)=0
\]

(or the corresponding condensed/internal-coordinate system).

The branch solver may use scalar/root numerical algebra, interpolation and root isolation in generalized-coordinate space. These are not structural spatial discretizations.

Forbidden root selection:

```text
choose largest root
choose root closest to experiment
choose root closest to Zhou/Winter
jump disconnected branches because load is larger
```

## 11. S9 — primary ultimate-load condition

The capacity candidate is the first admissible connected-branch state satisfying

\[
L=0
\]

with verified local load sign change

```text
before peak: dP/ds > 0
after peak : dP/ds < 0
```

and equilibrium residuals within the production tolerance.

This is the common primary Pu definition for all four target material/steel combinations unless a future source-grounded physical failure mechanism explicitly introduces an additional admissibility condition project-wide.

## 12. S10 — same-state tangent/stability audit

At the S9 state and along the same branch, compute

\[
K_Z=\sum_p(K_{Z,p}^{mat}+K_{Z,p}^{geo}),
\]

with

- current consistent material tangent;
- current membrane/current stress geometric terms;
- exact finite-thickness shell contribution where present;
- exact condensation of active finite local coordinates.

If local coordinates are active:

\[
K_{gg}^{cond}=K_{gg}-K_{ga}K_{aa}^{-1}K_{ag}.
\]

The tangent audit must not use a pre-buckling elastic tangent frozen from an earlier state.

## 13. S11 — production validity audit

Every run records:

```text
material compiler/domain identity
material spectrum/envelope
source-value compiler error
source-tangent compiler error
P phase decomposition
Rq phase decomposition
P_D, P_q, Rq_D, Rq_q, L
internal residuals and condensation condition numbers when present
KZ material/geometric phase decomposition
branch/peak bracketing data
formal spatial/thickness counters
```

If the continuous material state exits a frozen material-family domain, the result is not accepted. The material-family domain/compiler must be enlarged/recompiled consistently, then all affected family results rerun.

## 14. S12 — comparison only after the solve

Only after S0-S11 pass may the result be compared with:

- experiment;
- Zhou formula;
- Winter formula;
- FE;
- other empirical/design formulas.

These comparators may diagnose model bias but may not retrospectively select coefficients, roots, halfwaves or material domains.
