# Governance semantic branch

Current primary governance includes:

- source-of-truth/evidence hierarchy;
- full/task-scoped recovery protocol;
- continuous checkpoint sync;
- content-first semantic identity rule;
- semantic-v2 naming/tree policy;
- resumable execution checkpoint requirements.

Older files that self-declare `CURRENT GOVERNANCE` are evaluated chronologically. Examples: PF1 route locks, energy-potential rules, R07R rules and material-domain rules may retain historical/conceptual value while no longer governing the current R10 -> N48-C1/MM -> CH -> Nguyen -> general-D15 production calculation.

Status belongs in the semantic manifest, not in the filename.
