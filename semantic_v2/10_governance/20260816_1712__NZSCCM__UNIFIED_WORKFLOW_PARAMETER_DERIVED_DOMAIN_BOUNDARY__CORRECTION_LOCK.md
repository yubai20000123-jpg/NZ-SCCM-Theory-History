## 2. Material-domain rule

For specimen `i`, the material compiler domain is not selected by case ID and is not tuned to its experimental capacity. It is generated by a common deterministic reachability operator:

\[
\Lambda_i = \mathcal B(\text{geometry}_i,\text{boundary}_i,\text{halfwave}_i,\theta_{m,i},\text{declared generalized-coordinate search/admissibility bounds}).
\]

Then the same family compiler policy is applied on `Lambda_i`:

\[
\widehat{\mathcal M}_i=\mathcal C_{family}(\mathcal M,\Lambda_i,\text{same fidelity gates}).
\]

Allowed:

```text
same domain-generation formula + different specimen parameters -> different domains/orders
```

Prohibited:

```text
case label -> manually chosen special interval/order
observed Pu error -> widen/narrow interval
experiment/Zhou/Winter -> choose compiler domain/order
Z6-only fallback solver
```
