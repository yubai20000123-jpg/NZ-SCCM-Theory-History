2. 当前最核心的物理层级
======================================================================

当前不再认为 q、A+、A− 是三个完全并列的主变量。

锁定理解为：

    q = 整体主路径参数 / 主序参量；

    A+、A−
    = 上、下钢壳在 q 建立的 current strain/stress state 下
      由局部平衡产生的从属局部响应。

物理因果链：

    外部轴压
    ->
    q 发展
    ->
    整体 von Karman 二维膜应变源
    ->
    UHPC + 钢壳 current membrane redistribution
    ->
    钢壳局部稳定刚度降低
    ->
    A+、A− 发展
    ->
    steel local postbuckling / yielding / redistribution
    ->
    钢壳分项承载变化
    ->
    UHPC/steel 荷载重新分配
    ->
    total P(q)

但数学上仍必须同时满足：

    Rq = 0
    RA+ = 0
    RA− = 0

不能把“A 是 q 的从属响应”误写成没有 RA 方程的经验 A(q)。

采用：

    q = continuation parameter

在每一个给定 q 上求：

    P,
    A+,
    A−

以及内部被凝聚的 membrane state。

3. 端部位移不再作为路径控制变量
======================================================================

不得再把统一端缩 Delta 作为理论主路径变量。

原因：

    强制加载边所有点具有统一轴向位移，
    可能附带限制真实简支边界允许的端部转动、翘曲和面内重分布。

因此：

    Delta(x),
    mean Delta,
    RP displacement

均属于求得平衡状态以后的派生量。

一般通过：

    epsilon_y^0
    =
    v_,y
    +
    1/2[(W_,y)^2-(W0_,y)^2]

恢复：

    v_,y
    =
    epsilon_y^0
    -
    1/2[(W_,y)^2-(W0_,y)^2]

再沿轴向积分得到：

    Delta(x).

不能为了拟合 FEM RP 位移而反向改变 q、A 或膜场。

4. 整体 global 几何：锁定 single-q
======================================================================

取：

    0 <= x <= b
    0 <= y <= a_h

x 为板宽方向；
y 为轴压方向。

整体初始几何：

    W0(x,y)
    =
    b q0 sin(pi x/b) sin(pi y/a_h)

当前整体构形：

    Wg(x,y)
    =
    b(q0+q) sin(pi x/b) sin(pi y/a_h)

加载新增整体位移：

    wg
    =
    b q sin(pi x/b) sin(pi y/a_h).

q0 是 stress-free initial geometry；
q 是 loading-induced amplitude。

初始缺陷绝不能直接产生 q0^2 初始应力。

所有几何应变必须采用：

    W^2 - W0^2

意义上的增量形式。

因此整体几何非线性必然产生：

    Q(q)
    =
    q^2 + 2 q0 q.

这是 Karman/Marguerre 几何结果，不是经验项。

13. UHPC 拉压 active-set
======================================================================

不得采用高斯点逐点 if 作为理论定义。

必须优先解析识别材料区。

如果采用方向性 current material input：

    e_x
    =
    (epsilon_x + nu_c epsilon_y)/(1-nu_c^2)

    e_y
    =
    (epsilon_y + nu_c epsilon_x)/(1-nu_c^2),

则拉压判断必须依据：

    e_x,
    e_y

而不是任意看裸 epsilon_x、epsilon_y。

厚度方向：

    e = e_m + chi z.

任何材料阈值：

    e = e_j

直接给：

    z_j
    =
    (e_j-e_m)/chi.

因此：

    tension/compression/ascending/softening

厚度区间必须先显式排序，再分段解析积分。

若：

    sigma(e)
    =
    Σ a_n e^n,

则必须优先使用原函数进行闭式：

    ∫ sigma dz
    ∫ z sigma dz.

面内如果固定一个坐标后得到：

    e(Y)
    =
    A+B cos2Y+C sinY,

令：

    s=sinY,

则：

    e
    =
    A+B+Cs-2Bs^2

材料边界：

    e=e_j

只需解二次方程。

应优先得到人工可识别：

    Y1,Y2,...

及明确区间。

若最后一个二维积分无法写成初等闭式：

    允许保留最低维度的一维确定积分，

但必须明确：

    活动集边界仍是解析的，
    厚度积分仍是闭式的。

禁止默默改成二维/三维 Gauss 积分。

数值积分可以用于独立验证解析结果，
不能定义正式理论 residual。

15. steel：当前主路线
======================================================================

原来的：

    sigma
    =
    fy/sigma_VM^elastic
    * sigma_elastic

只作为：

    current-state algebraic Mises limiter baseline

不得作为最终钢材塑性主理论。

正式主线：

    Chen-Ji-style Mises deformation theory
    +
    equivalent uniaxial polynomial
    +
    secant/tangent dual modulus.

Mises equivalent strain：

    epsilon_i
    =
    2/sqrt(3)
    sqrt[
      epsilon_x^2
      +
      epsilon_y^2
      +
      epsilon_x epsilon_y
      +
      gamma_xy^2/4
    ].

Equivalent stress law：

    sigma_i
    =
    Ps(epsilon_i).

elastic:

    epsilon_i <= epsilon_y

plastic nonlinear:

    epsilon_i > epsilon_y

其中：

    epsilon_y = fy/Es

或以实际多项式与 elastic segment 交点为准。

定义：

    E_sec
    =
    sigma_i/epsilon_i

    E_tan
    =
    d sigma_i/d epsilon_i.

finite current stress 和 tangent 必须区分：

    finite stress
    -> current internal force / virtual work

    tangent
    -> Newton/Jacobian/local stability.

不得使用 E_tan 重建有限 current force。

17. steel deformation theory 的适用性审计
======================================================================

Chen-Ji deformation theory 只在：

    基本单调加载、
    无明显应变反向、
    近似 proportional path

下合理。

因此全过程必须同步监测：
