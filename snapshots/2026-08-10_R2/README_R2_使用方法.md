# R2 使用方法

推荐在同一“轴压稳定矩阵理论推导”项目中开启新对话。

第一步：优先从本 GitHub 仓库读取 `START_HERE.md`、`CURRENT_STATE.md` 和 R2 snapshot；如 GitHub 暂不可用，再上传 `NZ_SCCM_CONVERSATION_TRANSFER_20260810_R2_FULL_CONTEXT.zip`。

第二步：读取 `04_R2_新对话首条指示词.md` 全文。

第三步：要求新对话先利用 GitHub / File Library / 项目 Sources 搜索 `03_R2_历史与材料资料强制恢复清单.md` 中列出的历史和材性资料。

不要在第一轮就继续计算。先验收它是否真正恢复：
- 148回合真实共享历史边界；
- D6—D20思想演化；
- NC/UHPC/rebar/shell材料谱系；
- 用户为什么否决不同数学/结构路径；
- 当前 final-attempt → new-operator 分岔。

只有恢复验收通过后才继续。
