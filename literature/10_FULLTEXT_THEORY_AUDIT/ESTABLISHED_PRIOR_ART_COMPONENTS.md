# Established prior-art components (evidence graded)

This is an evidence inventory, not a novelty conclusion.

## FULL_TEXT_VERIFIED

- Large-deflection plate/postbuckling structural demand: P0-01 and P0-02.
- Rayleigh–Ritz/Galerkin assumed modes for stiffened plates: P0-01/P0-02.
- Modified Airy stress-function formulation for orthotropic stiffened plates: P0-02.
- Initial imperfection entering a post-buckling relation: P0-01/P0-02.
- Plastic collapse mechanism or fold-line capacity paired with plate demand: P0-01/P0-02.
- Post-buckling/collapse-curve intersection for ultimate strength: P0-02 explicitly, P0-01 by two-branch analytical construction.
- Finite cubic root closure for ultimate strength: P0-02 Eq. (26).
- RC section `N-M` capacity from fibre/layer integration: P1-05/P1-06.
- RC wall instability from beam-column/strip equilibrium and `M-kappa`: P1-05/P1-06.
- Need for incremental/iterative solution when cracking, tension stiffening, compression softening and support interaction are retained: P1-05/P1-06.
- Effective-area/effective-width style post-local-buckling closure exists in the broader composite-wall literature, but the new P1 composite papers were not full-text acquired in this pass; mark as ABSTRACT_ONLY for this project.

## ABSTRACT_ONLY

- P1-07: PBL-stiffened DSCW effective-area post-local-buckling method (publisher abstract only).
- P1-08: DS-UHPC local-buckling model with interfacial shear slip (publisher abstract only).
- P1-09: double-skin wall local/post-buckling effect (metadata/abstract only).
- P1-11: steel–concrete composite-wall failure criterion (ASCE abstract only).

## INFERRED

- A finite control-location set can be useful when supported by mode symmetry and capacity mechanisms; only P0-02 explicitly verifies this structure in the acquired full text.
- A common structural operator with replaceable material/section capacity is a promising architecture; this is a synthesis inference from P0-02/P1-05/P1-06, not a direct claim of any one source.

## Not established by acquired full text

- RC/UHPC Marguerre–Airy 2D postbuckling plus direct finite-root multiaxial capacity.
- A zero-empirical-reduction steel–concrete/UHPC wall theory with no incremental history.
