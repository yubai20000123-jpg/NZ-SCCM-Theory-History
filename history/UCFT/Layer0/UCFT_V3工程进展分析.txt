# 2. 先纠正一个关键判断：完整不降阶L0不是“更高层理论”

我此前称完整不降阶L0为“后续升级理论”，这个表述不准确。

正确关系是：

\[
\boxed{
\text{二者属于相同的物理层级——层0。}
}
\]

完整不降阶L0没有增加下列层1机制：

- UHPC双轴或三轴强度增强；
- 围压增强；
- 钢—UHPC界面滑移；
- 黏结退化或脱空接触；
- PBL显式弹簧；
- PBL钢材独立承载；
- 钢材二维J2塑性；
- 残余应力；
- 加载端和接触柔度。

两者均采用：

\[
\boxed{N=N_c+N_s^++N_s^-}
\]

PBL只作为局部钢壳子板的强固支边界，不计独立轴力，也不设置显式弹簧能量。

真正的关系是：

\[
\boxed{
\text{L0-B1-TC-EP}
=
\text{层0物理假定下的低阶、约束型路径模型}
}
\]

\[
\boxed{
\text{完整不降阶L0}
=
\text{同一层0物理假定下解除自由度、模态、子板和耦合降阶后的正式母体系}
}
\]

因此不应称为“层级升级”，而应称为：

\[
\boxed{
\text{由低阶B1约束子空间恢复到完整层0近似空间。}
}
\]

完整矩阵锁定稿明确规定：它保留一般面内Ritz自由度、多个整体面外模态、每块局部子板独立幅值、全部区域积分和全部一致耦合项；旧B1只能作为退化校核模型，不能反向定义完整理论。

# 4. 两套理论共同的层0物理基础

以下部分两者相同，不构成差异。

## 4.1 力学对象

结构隔离体为：

\[
\text{上钢壳}
+
\text{连续UHPC核心板}
+
\text{下钢壳}
+
\text{PBL形成的局部边界约束}.
\]

PBL：

\[
N_{\mathrm{PBL}}=0,
\qquad
U_{\mathrm{PBL}}^{\mathrm{spring}}=0.
\]

总轴力：

\[
N=N_c+N_s^++N_s^-.
\]

## 4.2 初始构形几何非线性

两者均区分：

- 初始整体缺陷 \(W_{g0}\)；
- 加载新增整体挠曲 \(\widehat W_g\)；
- 局部初始缺陷 \(w_{\ell0,i}^{\pm}\)；
- 加载新增局部鼓曲 \(\widehat w_{\ell i}^{\pm}\)。

整体总挠度为：

\[
W_{gt}=W_{g0}+\widehat W_g.
\]

钢壳局部子板总挠度由整体和局部两部分叠加，并保留von Kármán型平方项和局部—整体交叉项。

## 4.3 材料层级

UHPC采用层0单轴受压主曲线和一致切线：

\[
\sigma_c=\sigma_c(\varepsilon_c),
\qquad
E_{c,t}=\frac{d\sigma_c}{d\varepsilon_c}.
\]

钢材采用纵向标量弹塑性模型；局部钢壳可进入弹性后屈曲和纤维弹塑性后屈曲。

## 4.4 路径型承载力定义

两者均应以有效平衡路径上的总轴力峰值定义承载力：

\[
\boxed{
N_u=\max_{\lambda\in\mathcal P_{\mathrm{valid}}}N(\lambda)
}
\]

钢壳首次屈服、局部屈曲、整体切线失稳、UHPC达峰、局部状态转换均只是路径事件，不必然单独等于 \(N_u\)。

# 5. L0-B1-TC-EP的完整计算过程

下面按照历史B1路径逻辑逐步列出。

## 5.1 输入与分区

输入：

\[
a_c,\ B_c,\ t_c,\ t_s^\pm,\ z_s^\pm
\]

以及：

\[
f_c,\ E_c,\ \varepsilon_{c0},\ E_s,\ f_y,\ \nu_s.
\]

钢壳按PBL边界划分为局部子板：

\[
\Omega_{\ell i}^{+},
\qquad
\Omega_{\ell i}^{-}.
\]

Case-1和Case-2的区别只来自实际分区及其局部事件：

- Case-1：120 mm子板，局部屈曲峰前不激活；
- Case-2：360 mm子板，局部屈曲和局部纤维弹塑性后屈曲激活。

## 5.2 采用单一整体面外模态

B1使用一个预选整体模态：

\[
\psi_g(X,Y).
\]

整体初始缺陷：

\[
W_{g0}=\eta_0\psi_g.
\]

当前整体挠曲：

\[
W_{gt}=\eta_t\psi_g
\]

或者以新增幅值表示为：

\[
W_{gt}=(\eta_0+\eta)\psi_g.
\]

因此所有整体挠曲形状均被限制在同一个函数方向内，只有幅值变化。

这是B1的第一个主要约束：

\[
\boxed{
\text{整体面外位移空间只有一个预选模态方向。}
}
\]

## 5.3 最小整体面内Ritz变量

历史计算保留：

\[
\mathbf q_g^{B1}
=
[q_{u1},q_{u2},q_{v1},q_{v2},\eta_t]^{\mathsf T}.
\]

因此面内位移不是完全均匀应变，但只保留预先选定的低阶Ritz项：

\[
u(X,Y)
=
-\lambda X
+
q_{u1}U_1(X,Y)
+
q_{u2}U_2(X,Y),
\]

\[
v(X,Y)
=
q_{v1}V_1(X,Y)
+
q_{v2}V_2(X,Y).
\]

整体未知量维数固定为五。

## 5.4 局部子板形函数

每个PBL间钢壳子板使用四边固支局部形函数：

\[
\psi_{\ell i}
=
\left[
1-\cos\left(
\frac{2m_i\pi X}{a_{\ell i}}
\right)
\right]
\left[
1-\cos\left(
\frac{2\pi\bar Y_i}{B_{s,i}}
\right)
\right].
\]

满足：

\[
w_\ell=0,
\qquad
\frac{\partial w_\ell}{\partial n}=0
\]

于局部子板边界。

## 5.5 B1同侧统一幅值约束

B1不让每个局部子板自由发展独立幅值，而采用：

\[
A_i^\pm=\omega_i^\pm A^\pm.
\]

其中：

\[
\omega_i^\pm
=
\frac{
\max_X|\psi_g(X,Y_i^\pm)|
}{
\max_{X,Y}|\psi_g(X,Y)|
}.
\]

对于一阶正弦整体模态：

\[
\omega_i^\pm
=
\left|
\sin\frac{\pi Y_i^\pm}{B_c}
\right|.
\]

但局部初始缺陷不按整体模态加权：

\[
A_{0i}^\pm\neq\omega_i^\pm A_0^\pm,
\]

而取统一制造缺陷值或各子板实测值。

因此B1的核心局部约束是：

\[
\boxed{
\begin{aligned}
&\text{同一侧所有局部子板只有一个母幅值 }A^\pm;\\
&\text{不同子板仅通过预设 }\omega_i^\pm\text{产生比例差异。}
\end{aligned}
}
\]

## 5.6 钢壳总挠度

上、下钢壳第 \(i\) 块子板的当前挠度为：

\[
W_{s,i}^{\pm}
=
W_{gt}
+
s_\pm
\left(
A_{0i}^\pm+A_i^\pm
\right)\psi_{\ell i}^{\pm},
\]

其中：

\[
s_+=+1,\qquad s_-=-1.
\]

钢壳纵向应变保留：

\[
\frac12
\left(
W_{g,X}+w_{\ell,X}^{\pm}
\right)^2.
\]

展开即：

\[
\frac12W_{g,X}^2
+
W_{g,X}w_{\ell,X}^{\pm}
+
\frac12(w_{\ell,X}^{\pm})^2.
\]

因此历史B1并不是完全忽略局部—整体耦合；它保留了耦合，但耦合发生在被约束后的低阶幅值空间中。

## 5.7 UHPC材料更新

在每个积分点计算：

\[
\varepsilon_c
=
\varepsilon_m
-
z\kappa.
\]

然后更新：

\[
\sigma_c(\varepsilon_c),
\qquad
E_{c,t}(\varepsilon_c).
\]

恢复：

\[
N_c
=
\int_{\Omega_c}\int_{-t_c/2}^{t_c/2}
\sigma_{c,x}\,dz\,d\Omega.
\]

当：

\[
\varepsilon_{c,\max}
=
\varepsilon_{c0}
\]

时，历史L0-B1路径按UHPC峰值边界终止。

## 5.8 局部钢壳状态判断

历史TC-EP逻辑采用分段状态链：

\[
S0\rightarrow S1e\rightarrow S1p\rightarrow S2.
\]

### S0：局部屈曲前

局部子板仍沿基本材料压缩路径承载。

### S1e：弹性局部后屈曲

局部子板达到弹性屈曲条件后，局部幅值发展，平均应力按大挠度后屈曲关系更新。

### S1p：局部纤维弹塑性后屈曲

局部最大纤维进入钢材非线性区后，局部平均应力和局部有效切线由弹塑性纤维状态计算：

\[
\sigma_{s,i}^{avg},
\qquad
E_{s,i}^{tan}.
\]

Case-2峰值时360 mm子板主要处于S1p，而不是平均全宽达到 \(f_y\) 的平台。

### S2：强度封顶

早期低阶B1理论允许在达到局部强度上限时进行幅值或平均应力封顶。该状态属于历史B1计算闭合的一部分。

## 5.9 TC切线更新

每个局部子板根据当前状态输出：

\[
\sigma_{s,i}^{avg},
\qquad
E_{s,i}^{tan}.
\]

这些量进入：

- 上、下钢壳轴力积分；
- 整体切线矩阵；
- 面外稳定项；
- 局部—整体耦合项。

因此TC的核心作用不是简单修改最终轴力，而是：

\[
\boxed{
\text{使当前钢壳局部弹塑性状态进入整板切线刚度。}
}
\]

Case-2中局部有效切线降低到约50～90 GPa，引起整体面外刚度提前软化，并加速UHPC压区应变集中。

## 5.10 整体残量和切线矩阵

给定路径参数：

\[
\lambda=\varepsilon_X^0,
\]

求解整体五变量平衡：

\[
\mathbf R_g^{B1}
\left(
q_{u1},q_{u2},q_{v1},q_{v2},\eta_t;
\lambda
\right)
=
\mathbf0.
\]

组装低阶切线矩阵：

\[
\mathbf K_T^{B1}
=
\frac{\partial\mathbf R_g^{B1}}
{\partial\mathbf q_g^{B1}}.
\]

局部子板状态通过当前平均应力和有效切线进入该矩阵，但局部子板并没有全部作为独立Newton未知量进入一个完整矩阵。

## 5.11 有缺陷路径

当：

\[
\eta_0>0
\]

时，从第一个载荷步起便存在二阶效应。路径过程为：

\[
\text{初始缺陷响应}
\rightarrow
\text{钢壳屈服或局部屈曲}
\rightarrow
\text{切线刚度退化}
\rightarrow
\eta_t\text{增长}
\rightarrow
\text{应力重分布}
\rightarrow
\text{UHPC达峰或总轴力峰值}.
\]

这对应历史B1、B2路径。

## 5.12 无缺陷路径

当：

\[
\eta_0=0
\]

时，首先沿平直完美轴压分支：

\[
\eta_t=0.
\]

对于Case-1，正确事件逻辑为：完美轴向压缩 → 钢壳屈服 → 按当前材料切线计算整板临界荷载 → 平直分支失稳 → 进入二阶效应并搜索新的非零平衡点 → 新稳定支路或被UHPC峰值截断。

对于Case-2，无缺陷路径还必须先处理局部平凡分支以及360 mm子板的完美局部分岔。

## 5.13 路径终止和承载力

每个路径点恢复：

\[
N_c,\quad N_s^+,\quad N_s^-,
\]

\[
N=N_c+N_s^++N_s^-.
\]

监测：

\[
\varepsilon_{c,\max},
\qquad
\lambda_{\min}(K_T),
\qquad
\frac{dN}{d\lambda}.
\]

有效路径在UHPC峰值边界、总轴力峰值或无法继续维持有效平衡时终止。

# 6. 完整不降阶L0的完整计算过程

完整L0保留同样的物理层0边界，但不再把运动学和局部幅值压缩到B1约束子空间。

## 6.1 一般面内Ritz场

给定轴向压缩参数 \(\lambda\)，采用：

\[
u(X,Y)
=
-\lambda X
+
\sum_{r=1}^{n_u}q_{u,r}U_r(X,Y),
\]

\[
v(X,Y)
=
\sum_{s=1}^{n_v}q_{v,s}V_s(X,Y).
\]

其中 \(n_u,n_v\) 通过模态收敛确定，不固定为2和2。

## 6.2 多个整板面外模态

整体初始缺陷：

\[
W_{g0}
=
\sum_{\alpha=1}^{n_g}
\eta_{0,\alpha}\Psi_\alpha(X,Y).
\]

加载新增整体挠曲：

\[
\widehat W_g
=
\sum_{\alpha=1}^{n_g}
\eta_\alpha\Psi_\alpha(X,Y).
\]

当前整体挠曲：

\[
W_{gt}
=
W_{g0}+\widehat W_g.
\]

因此完整L0允许一阶/高阶整体模态、模态间耦合和局部屈曲诱导的整体模态重构。

## 6.3 每块局部子板独立幅值

完整L0对每个上、下钢壳局部子板分别设置：

\[
A_i^+,\qquad A_i^-.
\]

若每块子板保留多个局部模态，则为：

\[
A_{i\beta}^\pm.
\]

不再采用：

\[
A_i^\pm=\omega_i^\pm A^\pm.
\]

因此各块局部幅值均由各自局部平衡方程独立确定。

## 6.4 完整未知向量

\[
\boxed{
\mathbf q=
\begin{bmatrix}
\mathbf q_u\\
\mathbf q_v\\
\boldsymbol\eta\\
\mathbf A^+\\
\mathbf A^-
\end{bmatrix}
}
\]

## 6.5 各区域独立构形

UHPC只采用整体挠曲：

\[
W_c=W_{gt}.
\]

第 \(i\) 块钢壳子板采用：

\[
W_{s,i}^{\pm}
=
W_{gt}
+
s_\pm
\left(
w_{\ell0,i}^\pm+
A_i^\pm\psi_{\ell i}^\pm
\right).
\]

整体初始缺陷、局部初始缺陷、整体新增模态和局部新增幅值全部独立，不相互替代。

## 6.6 完整几何非线性应变

在UHPC全体域和每一块钢壳子区域分别计算：

\[
\boldsymbol\varepsilon_m
=
\boldsymbol\varepsilon_L(\mathbf q_u,\mathbf q_v,\lambda)
+
\frac12
\left[
\mathcal G(W_t)-\mathcal G(W_0)
\right].
\]

UHPC厚度坐标处：

\[
\boldsymbol\varepsilon_c(z)
=
\boldsymbol\varepsilon_m
-
z\boldsymbol\kappa_g.
\]

钢壳第 \(i\) 块子板则使用其自己的 \(W_{s,i}^{\pm}\)。

## 6.7 各局部子板独立半波搜索

对于每块局部子板，分别在候选集合内搜索：

\[
m_i^\pm\in\mathcal M_i^\pm.
\]

每块子板可以选择不同纵向半波数。

## 6.8 积分点材料更新

在所有UHPC体积分点和所有钢壳子板积分点独立更新：

\[
\sigma_c,\ E_{c,t},
\]

\[
\sigma_s,\ E_{s,t}.
\]

材料更新直接作用于内力、残量、Jacobian、稳定特征值和局部子板切线。

## 6.9 每块局部子板的连续Galerkin残量

完整L0不再通过Case级状态机决定“启用哪个局部方程”，而是为每个局部幅值建立连续残量：

\[
R_{A_i^\pm}=0.
\]

其物理内容包括局部膜内力虚功、局部弯曲虚功、整体—局部交叉虚功、当前材料切线和初始缺陷作用。

## 6.10 完整残量系统

\[
\boxed{
\mathbf R=
\begin{bmatrix}
\mathbf R_{q_u}\\
\mathbf R_{q_v}\\
\mathbf R_\eta\\
\mathbf R_{A^+}\\
\mathbf R_{A^-}
\end{bmatrix}
=
\mathbf0
}
\]

## 6.11 完整一致Jacobian

\[
\mathbf K_T=
\begin{bmatrix}
K_{uu}&K_{uv}&K_{u\eta}&K_{uA^+}&K_{uA^-}\\
K_{vu}&K_{vv}&K_{v\eta}&K_{vA^+}&K_{vA^-}\\
K_{\eta u}&K_{\eta v}&K_{\eta\eta}&K_{\eta A^+}&K_{\eta A^-}\\
K_{A^+u}&K_{A^+v}&K_{A^+\eta}&K_{A^+A^+}&K_{A^+A^-}\\
K_{A^-u}&K_{A^-v}&K_{A^-\eta}&K_{A^-A^+}&K_{A^-A^-}
\end{bmatrix}.
\]

不得预先删除耦合块。

## 6.12 Schur凝聚

\[
R_c^{\mathrm{cond}}
=
R_c-K_{cA}K_{AA}^{-1}R_A,
\]

\[
K_c^{\mathrm{cond}}
=
K_{cc}
-
K_{cA}K_{AA}^{-1}K_{Ac}.
\]

但这只是对同一完整方程组的精确消元，不等于删除局部变量或预设局部幅值。凝聚后局部变量仍必须恢复并满足 \(R_A=0\)。

## 6.13 完美板分岔

当初始整体和局部缺陷均为零时：

\[
\boldsymbol\eta=\mathbf0,
\qquad
\mathbf A^\pm=\mathbf0
\]

可以是精确平凡分支。

完整L0通过：

\[
\lambda_{\min}(K_T)=0
\]

或Schur凝聚后的局部/整体切线特征值判定分岔。

分岔后沿相应零特征向量播种，再通过Newton和伪弧长续接进入新的平衡支路。

## 6.14 路径推进

完整L0采用预测步、Newton修正、线搜索、必要时伪弧长、SVD或稳定线性求解、接受/拒绝路径步、状态提交和事件细化。

求解器不得采用经验放大式替代路径平衡，也不得先把Case分类为S0/S1/S2后调用不同求解器。

## 6.15 峰值与收敛

完整L0不仅检查路径步长，还必须检查 \(n_u,n_v,n_g\)、局部模态数量和积分阶次的收敛；同时检查 \(N_u,\boldsymbol\eta_u,\mathbf A_u^\pm\) 以及事件顺序是否稳定。

完整理论可以逐步退化为旧B1验证模型，但反向不成立。

# 7. 两套模型的核心差异总表

| 项目 | L0-B1-TC-EP | 完整不降阶L0 |
|---|---|---|
| 物理层级 | 层0 | 层0 |
| 是否增加层1机制 | 否 | 否 |
| 理论身份 | 低阶约束路径模型 | 正式完整层0母体系 |
| 面内位移 | 固定少量Ritz项 | 一般Ritz自由度 |
| 整体面外位移 | 单一预选整体模态 | 多个整体面外模态 |
| 局部幅值 | 同侧统一母幅值或预定比例 | 每侧每块子板独立幅值 |

| 模态竞争 | 很有限 | 显式保留 |
| 设计用途 | 历史Case计算、低阶验证、机制理解 | 正式参数计算和后续设计化简母数据 |

# 8. 最本质的数学关系

可以把B1理解为完整L0近似空间中的一个受约束子空间。

完整L0允许：

\[
\mathbf A^\pm=
[A_1^\pm,A_2^\pm,\ldots,A_n^\pm]^{\mathsf T}.
\]

B1强制：

\[
\mathbf A^\pm
=
A^\pm
[\omega_1^\pm,\omega_2^\pm,\ldots,\omega_n^\pm]^{\mathsf T}.
\]

同样，完整整体模态空间为：

\[
\boldsymbol\eta=
[\eta_1,\eta_2,\ldots,\eta_{n_g}]^{\mathsf T},
\]

B1强制：

\[
\eta_2=\eta_3=\cdots=\eta_{n_g}=0.
\]

因此：

\[
\boxed{
\mathcal V_{B1}\subset\mathcal V_{\mathrm{full\ L0}}
}
\]

完整L0可以退化到B1型低阶模型，但不能反向由B1推出完整L0，因为B1已经丢失被删除整体模态方向、各子板独立幅值差、高阶面内位移模式、被删除的交叉Jacobian块，以及模态竞争和子板间非同步演化。

# 9. 这对历史A1、B1、B2结果意味着什么

完整不降阶L0的存在，**不否定**历史A1、B1、B2在L0-B1-TC-EP假设下的严格计算状态。

准确关系是：

\[
\boxed{
\text{历史结果是在B1约束子空间中的平衡路径结果。}
}
\]

而完整L0要回答的是：

\[
\boxed{
\text{解除这些约束后，完整层0近似空间中的平衡路径和峰值是什么。}
}
\]

两者数值可能不同，原因不是物理层级变化，而是允许的变形空间不同。

所以最终身份应锁定为：

\[
\boxed{
\begin{aligned}
&\text{L0-B1-TC-EP：历史层0低阶约束路径，结果在其假设内成立；}\\
&\text{完整不降阶L0：当前正式层0母体系，不是层1升级；}\\
&\text{二者差异来自运动学、局部幅值和矩阵耦合是否降阶，}\\
&\text{而不是来自不同材料物理层级。}
\end{aligned}
}
\]
