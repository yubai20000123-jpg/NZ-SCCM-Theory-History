# R05 HISTORY — MATERIAL-NATIVE DOMAIN AND COMPACTIFICATION

**Date:** 2026-08-10

## Why R05 was necessary

R01-R04 progressively showed that the apparent two-dimensional material-surface difficulty was not primarily a failure of the invariant current-map architecture:

1. R01 isolated narrow tensile transition ridges;
2. R02 showed that moderate physical widening helps but cannot alone solve representation complexity;
3. R03 exposed exact separated rank<=4 structure and separated structural spectra in a diagnostic box;
4. the user corrected the project governance: structural spectra cannot define the production material domain because the same architecture must later accept UHPC;
5. R04 therefore made `Lambda_M(material)` primary and classified the exact source-shaped radical tower as too complicated for direct generic Appell/Carlson closure.

R05 is the first step executed after that correction.

## What R05 changed

R05 did **not** change the G18/G20/G27 route.

It changed the scalar compiler problem from

```text
fit the old source-shaped oracle over an inherited broad interval
```

to

```text
material source -> material-native landmarks/domain -> compact 1D scalar representation -> invariant/matrix reconstruction -> D15
```

The ordinary-concrete active transition scale is now written symbolically as

\[
[-\gamma_2,\ \alpha_1\rho/\kappa].
\]

For the present NC material instance this is `[-10, 0.49987179454]`. This is a material-source interval, not a Swartz24 reachability interval.

## Important blocker discovered

The correct material-native domain exposes a fact that was largely hidden when only the structural range was inspected: a pure Saenz continuation at `lambda=-10` gives about `-0.1981 fc`, while the Nguyen source postcrush residual landmark is about `-0.1 fc`.

Thus the final smooth-conservative deep-postpeak scalar target is still open. The project must freeze that material target before a final scalar coefficient set can be accepted.

This is a material-closure issue, not a spatial-integration issue.

## Candidate screen

Three compact representations were actually tested against the frozen smooth source-shaped `U` benchmark:

- one global polynomial in `lambda`: slow convergence and poor tangent behavior;
- a degree-9 landmark Hermite polynomial after compactification: exact landmark interpolation but catastrophic global oscillation, rejected;
- a material-scale compactification
  \[
  \chi=\lambda/\sqrt{\lambda^2+1}
  \]
  followed by a finite Chebyshev polynomial: substantially better stress/tangent P95 performance.

The `n=24` compactified representation achieved benchmark errors of about `1.56% fc` maximum stress, `0.128% fc` stress P95 and `2.35%` initial-tangent P95. It is retained only as a material representation candidate.

## Why compactification is more than a fit trick

The compactification uses one quadratic radical. Any polynomial in `chi` remains in a scalar algebraic extension of degree at most 2, independent of polynomial order. With `lambda±=mu±sqrt(Q)`, the generic structural algebraic extension is at most degree 4.

This is a significant reduction from the old source-shaped `U`, which R04 bounded by degree 8 in the scalar coordinate and degree 16 after structural spectral substitution.
