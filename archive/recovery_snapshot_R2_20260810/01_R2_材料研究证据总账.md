# NZ-SCCM 材料研究证据总账 R2
日期：2026-08-10
用途：新对话禁止只读“最新架构评论”就开始发明新材料；必须恢复已经研究过的材料来源与它们的角色。

# 1. 统一接口与四种长期组合

必须长期保留四个可交换组合，不得把某一种材料组合写死成项目唯一对象：

1. 普通混凝土 + 钢筋；
2. 普通混凝土 + 钢壳；
3. UHPC + 钢筋；
4. UHPC + 钢壳。

统一结构接口可以写成：

\[
P = \sum_\alpha P_\alpha,\qquad
R = \sum_\alpha R_\alpha
\]

但每一材料分项必须在同一平衡/极限条件中共同求解；
不得先求各材料单独 \(P_u\) 再标量相加。

# 2. 普通混凝土 NC

## 2.1 Nguyen / Foster 来源链

必须恢复：
- Nguyen thesis Chapter 3；
- Appendix B；
- equivalent-uniaxial transformation；
- principal strain/stress；
- Saenz compression；
- ordinary RC tension stiffening；
- TC/TT/CC/TCX；
- shear retention；
- reinforcement bilinear law；
- biaxial envelope / Foster-Gilbert modifications。

当前显式 current operator 不是逐字复制 Nguyen history state machine，而是针对单调 current-state 问题构造的解析 map。

## 2.2 正式 tension law 的历史纠偏

中间阶段出现过 tanh/sigmoid variant；
历史成功 Case21 regression 追溯后，当前 benchmark 改回 algebraic Foster smoothing。

因此：
- `tanh` 不得无来源恢复成 benchmark；
- 但 benchmark 本身现在允许在新材料设计阶段被更好的文献模型替换。

## 2.3 当前治理

当前 Nguyen/Foster：
- 继续是普通混凝土 benchmark；
- 不允许用 Case21/Swartz \(P_u\) 反标；
- 如果新材料模型来自材料级文献/试验，可替换 benchmark；
- 新模型应优先 objectivity/invariant、热力学、一致切线、可解释性和解析友好性。

# 3. UHPC：必须恢复完整来源谱系，不能只读当前 architecture review

UHPC 历史研究不是“把 \(f_c=141.1\) 填进普通混凝土”。

## 3.1 用户长期强制值与参数重审

在 G16R 阶段：
- 用户只强制保留 \(f_c=141.1\) MPa；
- \(E_c,\varepsilon_{c0},f_t,\nu\) 均重新接受材料来源审计；
- 旧 \(f_t=7.3\) MPa 被退休；
- Hiew 2% fibre 数据曾用于拉伸参数重审。

后续某些 baseline 暂时继续采用：
\[
E_c\approx43.4\ {\rm GPa},\quad
\varepsilon_{c0}\approx0.0035,\quad
\nu\approx0.20
\]
但这些不是用户永久不可修改值。

## 3.2 单轴压缩来源

历史上至少出现/审查过：
- 胡文旭：早期 UCFT UHPC 单轴压缩/拉伸骨架；
- Popovics / Carreira-Chu 类光滑压缩曲线：作为解析锚点候选；
- Zhang 2023 型显式曲线：曾用于 UHPC-C0 可计算 baseline。

必须保留结论：
`UHPC-C0 = 可计算 baseline，不是最终 UHPC 二维/多轴本构。`

## 3.3 拉伸来源

必须恢复：
- Hiew 2024 unified tensile constitutive model；
- elastic → cracking/strain hardening → peak → localization → softening；
- fibre volume/orientation 对桥联的影响；
- AASHTO T397 / FHWA / JSCE / NF 作为资格/工程边界核验来源，不应自动取代材料本构。

UHPC 拉伸不能被普通混凝土 tension stiffening 直接替代。

## 3.4 双轴/拉压路径效应

已经研究过/恢复过：
- Liu 等 UHPC biaxial / tension-compression 路径；
- Lee 2017 UHPFRC biaxial TC 30 panels；
- D'Alessandro / Roberts-Wollmann / Cousins 等 UHPC biaxial evidence；
- Looney / Volz 等多轴/三轴拉伸相关试验路线。

关键历史认识：
- proportional 与 sequential tension-compression 可能有明显 path effect；
- 单一 memoryless surface 未必能同时复现不同加载顺序；
- 双轴 CC/TT 强度锚点可用，但完整 current 全曲线并不天然唯一。

## 3.5 三轴压缩：周俊

上传来源：
`UHPC三轴受压力学性能研究_周俊.pdf`

历史恢复的重要关系：

\[
\frac{\tau_{\rm oct}^u}{f_c'}
=
0.00995
+
1.394
\frac{\sigma_{\rm oct}^u}{f_c'}
\]

历史报告给出的拟合相关性约 \(R^2\approx0.986\)。

当前正确角色：
- UHPC 多轴压缩强度边界/破坏利用率；
- 不是自动提供完整应力—应变 history law。

## 3.6 三轴破坏面：王淑楠

上传来源：
`超高性能混凝土三轴受压力学性能及破坏准则_王淑楠.pdf`

历史认识：
- 基于约39个三轴试件；
- Willam-Warnke 五参数；
- 围压显著提高峰值应力、峰值应变和变形能力；
- 适合作为多轴破坏面/独立校核；
- 不应与周俊 DP “双重增强叠加”。

## 3.7 UHPC 未来推荐身份

不应机械复制当前普通混凝土 current map。

候选长期骨架：
- invariant / tensor-basis representation；
- thermodynamic internal variables；
- compact scalar potentials；
- non-associated concrete plasticity 的 admissible 扩展；
- symbolic regression 只作材料级模型发现工具；
- neural constitutive model 暂不作为解析 core。

# 4. 钢筋

Nguyen 来源 bilinear law 是当前重要 benchmark。

Case21 历史值：
\[
E_s=200000\ {\rm MPa},\quad
\varepsilon_y=0.00265,\quad
f_y=530\ {\rm MPa},\quad
E_w=0,\quad
\varepsilon_f=0.04.
\]

Case21 两向总配筋率 \(p=0.0075\)，一层、两向对称：
\[
\rho_{s,x}=\rho_{s,y}=0.00375,\qquad z_s=0.
\]

长期规则：
- 钢筋必须进入 \(P_s\) 与 \(R_s\)；
- 重新求 RC 极限；
- 不得 concrete-only \(P_u\) 后加 \(A_s f_y\)。

若未来研究循环荷载/屈服历史，可升级为 internal-variable steel law；当前单调 Case21 不必过度复杂化。

# 5. 钢壳 / Y 模块 / 云露

## 5.1 云露的真正贡献

上传：
`考虑薄膜效应的钢箱混凝土壁板局部屈曲行为研究_云露.pdf`

历史提炼：
- Kármán 大挠度；
- 应力函数/Galerkin；
- 初始缺陷；
- 薄膜效应；
- 单侧/局部钢壁板屈后平均应力与变形路径。

长期不要误写：
- 云露不是完整 UCFT 总理论；
- 云露有效宽度经验修正系数不进入正式主线；
- Y 模块只承担钢壳局部/薄膜相关物理。

## 5.2 PBL 与钢壳

PBL 作为：
- 局部子板强固支边界；
- 横向分区边界。

PBL 不作为：
- 独立轴压钢材项；
- 显式弹簧能量。

## 5.3 钢材本构历史选项

历史阶段出现过：
- 理想弹性—理想塑性；
- Ramberg-Osgood；
- Bleich / R-O 弹塑性屈曲；
- 局部 S0/S1e/S1p/S2 状态闭合。

这些要作为“历史路径选项”保存，不能假装已经全部统一成一个最终钢壳 operator。

当前严格 NZ-SCCM current-operator 分支一度把：
`M_shell = UNSPECIFIED BY CURRENT LOCKED SOURCE`
保留为空槽。

这不是说“没有钢壳资料”，而是说：
- 当前 NC Case21 主线没有最终冻结钢壳材料 law；
- Y/云露、孙立鹏等来源仍必须在重新设计 shell operator 时恢复使用。

# 6. PBL / 界面 / UCFT 构造历史边界

长期锁定的层0简化：
- UHPC 核心连续；
- PBL 不独立承载；
- 无显式 PBL spring；
- 不显式建钢-UHPC界面滑移/黏结退化/脱空；
- 这些均是 Layer-0 边界，而不是“真实结构没有这些物理”。

胡文旭的开孔板界面抗剪研究可作为未来界面层升级来源；
不得把界面材料研究误当当前层0必需机制。

# 7. 材料模型重建的治理边界

最新允许重新打开材料函数，但必须满足：

允许：
- 从材料级文献和试验重建；
- invariant/tensor basis；
- rational/symbolic law；
- generalized standard material；
- thermodynamic damage/plasticity；
- admissible non-associated extension；
- physics-constrained symbolic discovery。

禁止：
- 用 Case21/Swartz/UCFT \(P_u\) 拟合材料；
- 逐板调参；
- 为积分方便无来源删材料机制；
- 把 neural black box 当解析理论；
- 把材料 benchmark 的历史成功数值当“不可修改的真理”。
