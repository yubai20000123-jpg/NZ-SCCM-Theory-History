日期：2026-08-10
身份：对话迁移总纲，不是单一阶段结果摘要

## 0. 为什么需要 R2

R1 的主要缺陷不是“最后状态写错”，而是把历史压缩得过头：
- 把大量用户意见、反驳、路线否决原因压成几个版本名；
- 对普通混凝土、UHPC、钢筋、钢壳/Y 模块的材料来源谱系交代不足；
- 没有强制新对话先恢复历史证据再讨论“最新数学方法”；
- 没有明确指出某些历史工件只能证明后台/分支活动，不能补写共享对话中不存在的回合；
- 没有把四个最终可互换组合长期保留为同等级接口：
  1) 普通混凝土 + 钢筋；
  2) 普通混凝土 + 钢壳；
  3) UHPC + 钢筋；
  4) UHPC + 钢壳。

R2 的最高目标不是让新对话“记住所有版本号”，而是让它恢复：
1. 我们到底在解决什么力学问题；
2. 用户为什么不断否决某些看似合理的路径；
3. 哪些材料资料已经研究过、分别承担什么证据角色；
4. 哪些数学路径只是工具，哪些是理论身份；
5. 当前最后一次现路线验收为何存在，以及失败后为什么允许重新建立材料/目标函数/solution operator。

# 2. 历史路径总时间轴：必须理解“为什么变”

## 阶段 A：UCFT 结构认知与局部钢壳/PBL

早期核心对象是 UCFT 板：
- 上钢壳；
- 连续 UHPC 核心板；
- 下钢壳；
- PBL 加劲隔板形成局部边界约束。

长期有效的结构认知：
- PBL 不作为独立轴压承载项；
- PBL 不作为显式弹簧能量项；
- PBL 对钢壳局部子板提供强固支边界；
- 在当前简化中 PBL 与 UHPC 核心融合为连续 UHPC 核心板；
- 云露有效宽度经验修正系数不作为正式主线。

历史材料/局部稳定来源：
- 云露：钢箱混凝土壁板大挠度、薄膜效应、局部后屈曲；
- 张宁：PBL 加劲矩形钢管混凝土局部屈曲；
- 孙立鹏：PBL 加劲薄壁钢管混凝土及钢材 R-O / Bleich 弹塑性相关路径；
- 胡文旭：UHPC 单轴压/拉材料曲线的早期重要来源；
- 周俊：UHPC 三轴压缩 DP/八面体强度；
- 王淑楠：UHPC 三轴全过程与 Willam-Warnke 五参数破坏面。

## 阶段 B：Airy / 路径A / B1 / v5

这一阶段建立了很多可计算路径：
- Airy-2c；
- 路径A；
- B1/B2；
- 钢壳局部 S0/S1e/S1p/S2；
- UHPC 峰值路径；
- 局部钢壳有效应力、切线、后屈曲。

贡献：
- 帮助理解 Case-1/Case-2 中整体弯曲、局部屈曲、UHPC峰值、钢材屈服如何排序；
- 帮助建立 PBL 强固支、局部子板分区、上下钢壳分侧。

后来被否决为正式母体系的原因：
- 低阶模型把自由度/模态/局部幅值提前约束；
- “先分类再求解”与完整层0思想冲突；
- S0/S1/S2 标签一度被误用成求解路径选择器；
- Airy-2c 后来永久排除为正式主线，仅保留历史审计意义。

## 阶段 C：完整不降阶 Layer-0

用户进一步明确：
- 完整 Layer-0 与 B1 处在同一物理层级，不是“更高层物理”；
- 差别是恢复一般 Ritz 面内自由度、多个整体模态、每块局部子板独立局部幅值和完整耦合；
- 不允许在矩阵计算前按正则化宽厚比或人为 S0/S1/S2 先分类；
- 简化只能发生在完整矩阵计算之后，用于设计曲线。

这形成了 Layer-0 求解器治理：
- 完美板先走平凡分支；
- 切线稳定/分岔进入后屈曲；
- 不用 eta=eta0/(1-N/Ncr) 代替二阶几何；
- 完整残量/一致 Jacobian；
- 峰值邻域细化；
- 不用中心差分 Jacobian 作为生产黑箱。

## 阶段 D：N–Y 系统与 Nguyen 分支C

为了恢复来源一致的 RC 板材料和稳定理论：
- N = Nguyen 钢筋混凝土墙板；
- Y = 云露钢壳局部模块。

Nguyen 贡献被拆成：
- 第3章：二维混凝土、钢筋、状态/切线；
- 第4章：Q4 + Hermite16 + 离散钢筋梁 + 稳定矩阵；
- 第6章：初始缺陷、有限面外位移、分层应变/应力、全耦合路径。

分支：
- P：第4章小扰动稳定；
- A：第6章退化校核；
- C：第6章完整生产路径。

当时的关键教训：
- 不能算到一半才发现分支C不完整；
- 第4章临界荷载不能替代第6章极限；
- P/A 不能替代 C；
- 材料 history、trial/commit、局部算法、完整残量必须在生产前审计。

后来不再把 Nguyen FE 流程作为 NZ-SCCM 最终积分架构，是因为用户把目标进一步升级到：
- 零正式空间 quadrature；
- 零正式 material point grid；
- 不依赖空间积分点数量。

## 阶段 E：NZ-SCCM-U v0.2 / D6—D20 及 148 回合

这一段非常重要，不能只用“D15 成功”四个字替代。

历史中出现过并被讨论/纠正：
- D6 单完整半波/HM27S；
- D8 失败机制；
- D9 连续域修复；
- D10 ACQI；
- D11 直接解析；
- D12 材料候选门禁；
- D13 连续单值势；
- D14 离线凝结；
- D15 精确矩；
- D18 面内状态前沿；
- D19 状态解析矩；
- D20 PRAM/路径降维提议。

尤其要保留的用户思想：
- 不要为了数学可算性过度删物理；
- 一个完整半波不等于可以把材料物理压缩成随意的低维 surrogate；
- 材料参数必须来自材料级来源；
- 结构 \(P_u\) 不得反标材料；
- 最终必须是人工可审计的力学理论，而不是看不见的计算器。

TURN 0148 中 D20 正式回复未交付，这是历史事实，后续工件不能补写成已验收。

## 阶段 F：从状态机转向 current material operator

在“单调轴压 + 一个完整半波 + 不研究循环卸载”的限定下，项目提出：

\[
\boldsymbol\sigma = \mathcal M(\boldsymbol\varepsilon)
\]

目的不是追求“漂亮拟合”，而是切断 FE 式：
空间点 → 状态分类 → history array → 材料点 Newton → 应力。

同时要求：
- 同一 operator 导出切线；
- 普通混凝土/UHPC 都使用统一 tensor interface，但不要求共用同一物理参数；
- 不运行时 TT/TC/CC 分类作为生产主算法。

## 阶段 G：moment-first D15

核心转折：
- `expand-all → D15` 会造成空间项爆炸；
- 改为 `moment-first`：每生成一个解析材料矩对象 \(Q_{nm}\)，立即收缩到结构目标矩并删除空间变量。

历史 concrete-only Case21：
\[
P_{u,c}\approx 339.1\ {\rm kN}
\]
独立高阶 spatial audit 约：
\[
339.6\ {\rm kN}
\]
差约 0.15%。

这证明了：
- 连续 current operator；
- 一个完整半波；
- 解析矩收缩；
可以在工程上高度一致。

随后钢筋必须进入 \(P\) 和 \(R_q\) 后重新求根，不能事后加 \(A_s f_y\)。

## 阶段 H：Chebyshev/material compiler 与高精度 collocation

历史上尝试过：
- 材料 Chebyshev compiler；
- 多尺度材料坐标；
- DCT；
- 3D Chebyshev collocation。

这些方法帮助确认 Case21 高可信参考：
\[
P_{u,c}\approx338.32\ {\rm kN},\qquad
P_{u,RC}\approx342.33\ {\rm kN}.
\]

但正式身份后来被降级，因为某些实现使用：
\[
113\times113\times57
\]
空间 material evaluations。

教训：
\[
\boxed{\text{“无 Gauss”不等于“无空间离散”。}}
\]

## 阶段 I：exact algebraic integrand / FriCAS

把三角场做 tangent-half-angle 后得到 exact algebraic integrands；
问题被识别为 algebraic-function integration。

FriCAS/Sage/Colab 尝试最终卡在运行环境：
- ECL 可以启动；
- FriCAS `REQUIRE CMP` 失败；
- 从未真正对实际 integrand 完成 FriCAS 数学测试。

所以历史身份：
`FRICAS_MATHEMATICS = NOT_TESTED`
而不是 `FRICAS_INTEGRATION = FAILED`。

## 阶段 J：piecewise analytic Taylor 再次被用户否决

一套不依赖外部 CAS 的 Taylor/binomial recurrence 得到约：
- concrete 338.3175 kN；
- RC 342.3332 kN。

但源码使用固定 8×8×16 analytic seed cells 及 NeedSplit。

用户明确：
> 哪怕只分2个空间子域也不接受，因为 Case21 少不代表别的板少。

于是长期正式空间身份改为：
- sampling = 0；
- quadrature = 0；
- spatial subdomains = 1（完整连续半波本身）。

## 阶段 K：single-domain global analytic series

随后建立整个完整域上的单一 global coefficient representation，
不再空间分块。

最新困难：
- scalar material map 自身可以收敛；
- spectral apparent singularity 已可用 divided difference / matrix-function form 消除；
- 两个 principal spectral intervals 在 Case21 参数盒内分离；
- 真正难点是 nonlinear coefficient-tail validation，尤其 \(R_q\)。

## 阶段 L：2026-08-10 priority reset

用户指出此前已经“钻牛角尖”：
- Case21 本身与试验相差约 7%；
- Swartz 其他板甚至可能 >10%；
- 不应为了积分证明到 \(10^{-5}\) 级而无限阻断工程理论。

最新治理：
- theorem-level tight certificate 降级为可选数学附录；
- Case21 用 engineering analytic convergence 收口；
- 当前 Nguyen/Foster 不再是永久终极材料理论，而是 benchmark/reference；
- 若最后一次当前路线仍有真正影响 \(P_u\) 身份的硬门禁，停止 patching；
- 允许从文献重新建立材料 operator / target function / solution operator。

# 3. 当前最重要的历史“否决原因”，新对话不得忘

| 被否决/降级路径 | 不是因为“结果不好看” | 真正原因 |
|---|---|---|
| Airy-2c 正式主线 | 不是因为某个 Case 数值 | 低阶/路径身份与完整 Layer0 母体系冲突 |
| S0/S1/S2 先分类 | 不是状态标签不能存在 | 标签不能驱动预分类求解 |
| Nguyen FE 生产架构 | 不是理论来源不可靠 | 正式计算成本依赖 material points / Gauss / history |
| expand-all D15 | 不是积分不精确 | 表达爆炸、不可扩展/不可审计 |
| material compiler 成为中心 | 不是 Chebyshev 本身错误 | 隐含形成新的材料理论层，provenance 不透明 |
| 3D Cheb collocation | 不是数值不准 | 仍然是空间采样 |
| analytic cells | 不是 cell 数量太多 | 任意非1空间分区都不满足长期目标 |
| strict theorem certificate hard gate | 不是数学无价值 | 证明强度远超当前模型误差，不应阻断工程推进 |
