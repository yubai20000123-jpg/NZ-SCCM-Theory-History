3.3.1 粘结剂种类影响

   从试验参数来看，粘结剂的种类不同，破坏模式也不同。第一组参数中，采用
HPCA 的 3 个试件均为 B 类破坏，而采用 NCA 的 3 个试件均发生 C 类破坏。由于
HPCA 与 UHPC 的界面粘结力大于 NCA 与 UHPC 的，但是 HPCA 的自身强度不足
以支撑界面粘结力，导致 HPCA 的试件发生 B 类破坏。
   图 3-6（a）对比的试件有 2 个，即第一组的粘结剂为 HPCA 和 NCA 的 2 个试件。
另外，还对比了 HPCA 和 NCA 的抗折强度。可知，采用 HPCA 的试件比采用 NCA
的提高了 108.8%，HPCA 的抗折强度比 NCA 的提高了 90.8%。可见，随着粘结材料
的抗折强度的提高，抗剪强度也相应提高。

3.3.2 龄期影响

   第二组参数中，不同龄期试件发生的破坏模式有 B 和 C 类，其中 7 d 龄期的 3
个试件中，1 个试件发生 B 类破坏，抗剪强度为 2.30 MPa，其余 2 个发生 C 类破坏，
抗剪强度分别为 2.07 MPa 和 1.77 MPa；90 d 龄期的 3 个试件中，2 个试件发生 B 类
破坏，抗剪强度分别为 2.91 MPa 和 2.67 MPa，其余 1 个发生 C 类破坏，但抗剪强度
仅为 1.35MPa，由于该试件的强度不到其余试件的 85%，需被剔除。结合 28 d 龄期
的试件均发生 B 类破坏可知，随着龄期的增长，试件的破坏模式由 C 类破坏转为 B
类破坏。
   图 3-6（b）对比的试件有 3 个，在第 2 组的龄期为 7 d 和 90 d 的 2 个试件基础
上，加入第 1 组 A28-25-100 试件（28d 龄期），形成 7 d、28 d 和 90 d 三组龄期的对

   第三组参数中，A90-70-100 三个试件中，1 个试件发生 A 类破坏，抗剪强度为

但是在在相同龄期下的常温试件发生的是 B 类破坏。
   图 3-6（c）将 3 组的 2 个试件，分别与第 2 组和第 1 组的 A90-25-100 试件和
A28-25-100 试件，构成了二对不同龄期下不同温度条件的试件组。第一对比组的龄

3.5 本章小结

  通过高性能水泥基粘结剂（HPCA）连接件界面抗剪推出试验研究，得到如下
主要结论：
  （1）在常温条件下，HPCA 试件的破坏模式以粘结层内聚破坏（B 类）为主，
抗剪强度为 2.61 MPa；而 NCA 试件的破坏模式为粘结层和 UHPC 板界面脱粘破坏
（C 类），抗剪强度为 1.25 MPa。短期和长期高温条件下，试件的破坏模式同样以
C 类破坏为主，且抗剪强度减低，降幅 40~60%，但最小抗剪强度仍大于 1.0 MPa。
  （2）HPCA 的抗剪强度随龄期增长而增大，且有早期发展快（7 d~28 d）、28d
后（28 d~90 d）基本稳定的特点；常温养护 28 d 时，当粘结面积从 100 cm2 减小至
75 cm2 和 50 cm2 时，抗剪强度分别提高了 3.1%和 8.4%，可能存在尺寸效应。由于
试验数据较少，尺寸效应对抗剪强度的影响有待进一步研究。
  （3）试验结果表明 HPCA 的抗剪强度与其自身抗折强度具有相关性。本文建
立了 HPCA 的抗剪强度的预测公式，计算精度较高。但由于实验数据偏少，预测公
式的合理性和精确性还有待今后进一步的研究。

4.2.1.2 荷载-滑移曲线的四个阶段

  由图 4-4 可知，组合试件的荷载滑移曲线均包含 OA 弹性段、AB 段突降段、BC
弹塑性段和 CD 下降段。在 OA 段内，粘结剂未失效，滑移量较小；当粘结剂失效
时，曲线达到 A 点，荷载达到第一个峰值，此时滑移量为 0.011~0.038mm；在 AB
段内，由于粘结剂失效而栓钉因滑移量小还未充分发挥承载作用，使荷载出现小幅
度下降，降幅在 3.1%~9.5%范围内，同时滑移量小幅度增大，抗剪刚度退化，从试
件侧面可观察到粘结层出现明显裂缝，达到 B 点时，滑移量在 0.062~0.20 mm 范围
内；在 BC 段内，随着滑移量的增大，由于栓钉承载作用逐渐发挥，荷载值重新增
大；当达到 C 点，出现第二个峰值荷载，且第二峰值荷载大于第一峰值荷载；在
CD 段内，荷载快速下降，直到听到栓钉剪断的声响，表明栓钉被剪断，试件破坏。
