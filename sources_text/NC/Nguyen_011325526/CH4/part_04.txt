4.3.3 Solution Method



The solution method used to calculate the buckling load is as follows:

        1. The loading is divided into the load steps.

       2. At each load step, the in-plane analysis is done to obtain the tangential

          moduli and the corresponding stresses at the Gauss points of the

          concrete elements and the reinforcing elements.

       3. The element tangential stiffness matrix and the element stability matrix

          are then obtained for both the concrete and the reinforcement, after

          which the structure tangential matrix is calculated.

      4. The critical load is obtained when the determinant of the structure

          tangential matrix approximately equal to zero.

The solution was deemed to be acceptable if the error measure between consecutive

load steps was 0.5% .
