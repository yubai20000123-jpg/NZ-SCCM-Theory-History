\varepsilon_{c,\max},
\qquad
\lambda_{\min}(K_T),
\qquad
\frac{dN}{d\lambda}.
\]

有效路径在UHPC峰值边界、总轴力峰值或无法继续维持有效平衡时终止。

# 6. 完整不降阶L0的完整计算过程

完整L0保留同样的物理层0边界，但不再把运动学和局部幅值压缩到B1约束子空间。

## 6.1 一般面内Ritz场

给定轴向压缩参数 \(\lambda\)，采用：

\[
u(X,Y)
=
-\lambda X
+
\sum_{r=1}^{n_u}q_{u,r}U_r(X,Y),
\]

\[
v(X,Y)
=
\sum_{s=1}^{n_v}q_{v,s}V_s(X,Y).
\]

其中 \(n_u,n_v\) 通过模态收敛确定，不固定为2和2。

## 6.2 多个整板面外模态

整体初始缺陷：

\[
W_{g0}
=
\sum_{\alpha=1}^{n_g}
\eta_{0,\alpha}\Psi_\alpha(X,Y).
\]

加载新增整体挠曲：

\[
\widehat W_g
=
\sum_{\alpha=1}^{n_g}
\eta_\alpha\Psi_\alpha(X,Y).
\]

当前整体挠曲：

\[
W_{gt}
=
W_{g0}+\widehat W_g.
\]

因此完整L0允许一阶/高阶整体模态、模态间耦合和局部屈曲诱导的整体模态重构。

## 6.3 每块局部子板独立幅值

完整L0对每个上、下钢壳局部子板分别设置：

\[
A_i^+,\qquad A_i^-.
\]

若每块子板保留多个局部模态，则为：

\[
A_{i\beta}^\pm.
\]

不再采用：

\[
A_i^\pm=\omega_i^\pm A^\pm.
\]

因此各块局部幅值均由各自局部平衡方程独立确定。

## 6.4 完整未知向量

\[
\boxed{
\mathbf q=
\begin{bmatrix}
\mathbf q_u\\
\mathbf q_v\\
\boldsymbol\eta\\
\mathbf A^+\\
\mathbf A^-
\end{bmatrix}
}
\]

## 6.5 各区域独立构形

UHPC只采用整体挠曲：

\[
W_c=W_{gt}.
\]

第 \(i\) 块钢壳子板采用：

\[
W_{s,i}^{\pm}
=
W_{gt}
+
s_\pm
\left(
w_{\ell0,i}^\pm+
A_i^\pm\psi_{\ell i}^\pm
\right).
\]

整体初始缺陷、局部初始缺陷、整体新增模态和局部新增幅值全部独立，不相互替代。

## 6.6 完整几何非线性应变

在UHPC全体域和每一块钢壳子区域分别计算：

\[
\boldsymbol\varepsilon_m
=
\boldsymbol\varepsilon_L(\mathbf q_u,\mathbf q_v,\lambda)
+
\frac12
\left[
\mathcal G(W_t)-\mathcal G(W_0)
\right].
\]

UHPC厚度坐标处：

\[
\boldsymbol\varepsilon_c(z)
=
\boldsymbol\varepsilon_m
-
z\boldsymbol\kappa_g.
\]

钢壳第 \(i\) 块子板则使用其自己的 \(W_{s,i}^{\pm}\)。

## 6.7 各局部子板独立半波搜索

对于每块局部子板，分别在候选集合内搜索：

\[
m_i^\pm\in\mathcal M_i^\pm.
\]

每块子板可以选择不同纵向半波数。

## 6.8 积分点材料更新

在所有UHPC体积分点和所有钢壳子板积分点独立更新：

\[
\sigma_c,\ E_{c,t},
\]

\[
\sigma_s,\ E_{s,t}.
\]

材料更新直接作用于内力、残量、Jacobian、稳定特征值和局部子板切线。

## 6.9 每块局部子板的连续Galerkin残量

完整L0不再通过Case级状态机决定“启用哪个局部方程”，而是为每个局部幅值建立连续残量：

\[
R_{A_i^\pm}=0.
\]

其物理内容包括局部膜内力虚功、局部弯曲虚功、整体—局部交叉虚功、当前材料切线和初始缺陷作用。

## 6.10 完整残量系统

\[
\boxed{
\mathbf R=
\begin{bmatrix}
\mathbf R_{q_u}\\
\mathbf R_{q_v}\\
\mathbf R_\eta\\
\mathbf R_{A^+}\\
\mathbf R_{A^-}
\end{bmatrix}
=
\mathbf0
}
\]

## 6.11 完整一致Jacobian

\[
\mathbf K_T=
\begin{bmatrix}
K_{uu}&K_{uv}&K_{u\eta}&K_{uA^+}&K_{uA^-}\\
K_{vu}&K_{vv}&K_{v\eta}&K_{vA^+}&K_{vA^-}\\
K_{\eta u}&K_{\eta v}&K_{\eta\eta}&K_{\eta A^+}&K_{\eta A^-}\\
K_{A^+u}&K_{A^+v}&K_{A^+\eta}&K_{A^+A^+}&K_{A^+A^-}\\
K_{A^-u}&K_{A^-v}&K_{A^-\eta}&K_{A^-A^+}&K_{A^-A^-}
\end{bmatrix}.
\]

不得预先删除耦合块。

## 6.12 Schur凝聚

\[
R_c^{\mathrm{cond}}
=
R_c-K_{cA}K_{AA}^{-1}R_A,
\]

\[
K_c^{\mathrm{cond}}
=
K_{cc}
-
K_{cA}K_{AA}^{-1}K_{Ac}.
\]

但这只是对同一完整方程组的精确消元，不等于删除局部变量或预设局部幅值。凝聚后局部变量仍必须恢复并满足 \(R_A=0\)。

## 6.13 完美板分岔

当初始整体和局部缺陷均为零时：

\[
\boldsymbol\eta=\mathbf0,
\qquad
\mathbf A^\pm=\mathbf0
\]

可以是精确平凡分支。

完整L0通过：

\[
\lambda_{\min}(K_T)=0
\]

或Schur凝聚后的局部/整体切线特征值判定分岔。

分岔后沿相应零特征向量播种，再通过Newton和伪弧长续接进入新的平衡支路。

## 6.14 路径推进

完整L0采用预测步、Newton修正、线搜索、必要时伪弧长、SVD或稳定线性求解、接受/拒绝路径步、状态提交和事件细化。

求解器不得采用经验放大式替代路径平衡，也不得先把Case分类为S0/S1/S2后调用不同求解器。

## 6.15 峰值与收敛

完整L0不仅检查路径步长，还必须检查 \(n_u,n_v,n_g\)、局部模态数量和积分阶次的收敛；同时检查 \(N_u,\boldsymbol\eta_u,\mathbf A_u^\pm\) 以及事件顺序是否稳定。

完整理论可以逐步退化为旧B1验证模型，但反向不成立。

# 8. 最本质的数学关系

可以把B1理解为完整L0近似空间中的一个受约束子空间。

完整L0允许：

\[
\mathbf A^\pm=
[A_1^\pm,A_2^\pm,\ldots,A_n^\pm]^{\mathsf T}.
\]

B1强制：

\[
\mathbf A^\pm
=
A^\pm
[\omega_1^\pm,\omega_2^\pm,\ldots,\omega_n^\pm]^{\mathsf T}.
\]

同样，完整整体模态空间为：

\[
\boldsymbol\eta=
[\eta_1,\eta_2,\ldots,\eta_{n_g}]^{\mathsf T},
\]

B1强制：

\[
\eta_2=\eta_3=\cdots=\eta_{n_g}=0.
\]

因此：

\[
\boxed{
\mathcal V_{B1}\subset\mathcal V_{\mathrm{full\ L0}}
}
\]

完整L0可以退化到B1型低阶模型，但不能反向由B1推出完整L0，因为B1已经丢失被删除整体模态方向、各子板独立幅值差、高阶面内位移模式、被删除的交叉Jacobian块，以及模态竞争和子板间非同步演化。

# 9. 这对历史A1、B1、B2结果意味着什么

完整不降阶L0的存在，**不否定**历史A1、B1、B2在L0-B1-TC-EP假设下的严格计算状态。

准确关系是：

\[
\boxed{
\text{历史结果是在B1约束子空间中的平衡路径结果。}
}
\]

而完整L0要回答的是：

\[
\boxed{
\text{解除这些约束后，完整层0近似空间中的平衡路径和峰值是什么。}
}
\]

两者数值可能不同，原因不是物理层级变化，而是允许的变形空间不同。

所以最终身份应锁定为：

\[
\boxed{
\begin{aligned}
&\text{L0-B1-TC-EP：历史层0低阶约束路径，结果在其假设内成立；}\\
&\text{完整不降阶L0：当前正式层0母体系，不是层1升级；}\\
&\text{二者差异来自运动学、局部幅值和矩阵耦合是否降阶，}\\
&\text{而不是来自不同材料物理层级。}
\end{aligned}
}
\]

# UCFT 板轴压承载力理论体系：Nguyen-UHPC 材料模块锁定稿  
## 层 0 主线 + 层 1 参数接口

## 0. 模块定位

本模块用于 UCFT 板轴压承载力矩阵解析迭代体系中的 UHPC 核心板材料点计算。其目标不是完整复制 Nguyen 的普通钢筋混凝土墙板有限元材料子程序，而是迁移 Nguyen 的：

\[
\boxed{
\text{面内状态}
\rightarrow
\text{主应变}
\rightarrow
\text{材料状态}
\rightarrow
\text{主方向应力}
\rightarrow
\text{切线矩阵}
\rightarrow
\text{稳定矩阵}
}
\]

这一“状态—切线—矩阵”框架。

Nguyen 原文研究对象是钢筋混凝土墙板的面外稳定有限元分析，包含 perfect wall 屈曲分析和含小初始缺陷/偏心的近似切线模量有限元分析；其 perfect wall 中混凝土采用四节点 16 自由度矩形单元、非线性弹性材料行为，并允许屈曲前面内开裂；含缺陷部分则限制于小缺陷、小偏心、无面外弯曲裂缝且混凝土应力—应变关系可用抛物线近似的情形。fileciteturn125file0

因此，本体系对 Nguyen 的迁移原则是：

\[
\boxed{
\text{迁移 Nguyen 的框架，不直接迁移 Nguyen 的普通混凝土参数。}
}
\]

其中，UHPC 的单轴受压、单轴受拉本构由 UCFT 项目已锁定的 UHPC 本构提供；双轴、拉压、剪切保持、围压等高级效应只作为层 1 参数接口保留。

---

## 1. Nguyen 原框架中可迁移与不可直接迁移的内容

Nguyen 在第 3.4 节明确说明，为建立墙板屈曲公式，需要知道切线矩阵 \(D_t\) 以及初始应力场 \(S_{ij}\)；由于研究对象可能处于任意双轴面内加载，包括压缩、面内偏心和剪切，混凝土应力—应变关系取决于加载状态，包括 undamaged、cracked 和 crushed 等状态。Nguyen 进一步使用 Kupfer 等双轴强度关系的 Foster/Gilbert 修正版，用于确定混凝土板的初始应力场、割线模量和切线模量。fileciteturn124file7

但这些参数来源于普通混凝土/钢筋混凝土墙板，不应直接用于 UHPC。尤其包括：

1. Kupfer/Foster-Gilbert 普通混凝土双轴强度包络参数；
2. Saenz 普通混凝土受压曲线；
3. Darwin–Pecknold 等效单轴应变模型中的 dilation constants；
4. Vecchio–Collins / MCFT 拉压耦合压强度折减；
5. 普通 RC tension stiffening 参数；
6. shear retention factor；
7. compression-compression 或 tension-compression crushed 后双线性关系。

Nguyen 在算例中采用 Foster 建议的一组普通 RC 材料参数，例如 \(a_1,a_2,\beta_1,\beta_2,\beta_3,\gamma_1,\gamma_2\)，并说明这些参数用于每一加载步确定 tangent moduli 和 initial stresses；其中 \(a_1,a_2\) 分别取 10.0、0.3，\(\beta_1,\beta_2,\beta_3\) 取 0.7、0.3、10.0，\(\gamma_1=0.0\)、\(\gamma_2=10\)，Poisson 比取 0.18。fileciteturn124file16 这些值不是 UHPC 专属参数，不能无条件作为 UCFT-UHPC 材料模块参数。

---

## 2. 如果直接迁移 Nguyen 普通混凝土参数，会导致什么后果？

直接迁移并不会产生统一方向的误差，而是不同机制的误差方向不同：

| Nguyen 普通混凝土参数/规则 | 直接迁移到 UHPC 的后果 | 倾向 |
|---|---|---|
| 双轴压缩增强包络 | 可能把 UHPC 双轴压缩增强估得过大 | 偏危险 |
| Saenz 普通混凝土受压曲线 | 对 140 MPa 级 UHPC 峰值应变、切线退化和峰后形态不可靠 | 方向不确定，常偏危险 |
| Vecchio–Collins 拉压折减 | 可能过度削弱纤维 UHPC 压向强度，也可能漏掉真实拉压软化 | 不稳定 |
| 普通 RC tension stiffening | 不能代表 UHPC 纤维桥联拉伸行为 | 方向不确定 |
| shear retention factor，尤其 \(0.1G\) | 可能严重低估纤维 UHPC 开裂后剪切刚度 | 常偏保守但路径可能失真 |
| 压碎后双线性 | 可能让 UHPC 峰后继续稳定承载过多 | 偏危险 |
| dilation constants | 影响双轴耦合和切线矩阵，但 UHPC 未标定 | 方向不确定 |

所以当前判断不是“Nguyen 参数不能用”，而是：

\[
\boxed{
\text{Nguyen 普通混凝土参数不能作为 UHPC 主线参数；只能作为结构化模板或扩展接口。}
}
\]

## 3. 层 0 主线：最小可算通 UHPC 材料模块

层 0 的目标是保证 UCFT 板轴压矩阵解析迭代体系能够闭合：

\[
N(\lambda)
=
N_c(\lambda)
+
N_s^+(\lambda)
+
N_s^-(\lambda)
\]

\[
N_u
=
\max_{\lambda\in\mathcal P_{valid}}N(\lambda)

层 0 不引入双轴增强、不引入拉压耦合折减、不引入剪切保持退化、不引入压缩峰后双线性。它只迁移 Nguyen 的状态—切线—矩阵结构，并用 UHPC 单轴受压/受拉本构替换 Nguyen 普通混凝土本构。

其中 \(\varepsilon_x,\varepsilon_y,\gamma_{xy}\) 由 UCFT 板的位移场或 Ritz 矩阵场提供。

\varepsilon_{1,2}

+

=

约定：

拉应变为正，压应变为负。

## 3.3 主方向 UHPC 单轴本构

层 0 中，每个主方向独立调用 UHPC 单轴受压或受拉本构：

\sigma_i^{(0)}

=

这里的 UHPC 受压/受拉曲线采用项目已锁定的 UHPC 单轴本构，不采用 Nguyen 的 Saenz 普通混凝土曲线。Nguyen 的等效单轴应变思想可以作为“主方向调用单轴曲线”的理论启发，但具体单轴曲线必须 UHPC 化。fileciteturn122file0

=
\max(E_i^{phys},E_{min})

其中：

\[

建议：

\[
\eta_E=10^{-6}\sim10^{-4}

注意：正则化只用于切线刚度矩阵，不改变应力计算：

\[

## 3.8 压缩峰值终止

Nguyen 在 cracked concrete crushing 中确实设置了压碎后双线性关系、压碎后切线模量以及剪切模量更新；但这些属于普通钢筋混凝土墙板材料程序，第一版 UCFT 不直接迁移。fileciteturn124file8

# 4. 层 1 参数接口：UHPC 文献驱动修正

层 1 不改变矩阵框架，只在材料点内部引入可插拔修正函数：

\[
\boxed{
\chi_{cc},\quad
\chi_{tc},\quad
\chi_{tt},\quad
\beta_{UHPC},\quad
\chi_{conf}
}
\]

分别对应：

1. 压—压双轴增强；
2. 拉—压耦合压强度折减；
3. 拉—拉双向受拉修正；
4. 开裂后剪切保持；
5. 三轴/围压扩展。

层 1 的原则是：

\[
\boxed{
\text{函数接口先建立，具体参数由 UHPC 文献或后续试验/有限元标定。}
}
\]

## 4.1 压—压双轴增强接口 \(\chi_{cc}\)

### 4.1.1 状态判别

当：

\[
\varepsilon_1<0,\quad \varepsilon_2<0
\]

进入压—压状态。

定义压应变比：

\[
r_c
=
\frac{\min(|\varepsilon_1|,|\varepsilon_2|)}
{\max(|\varepsilon_1|,|\varepsilon_2|)}
\in[0,1]
\]

### 4.1.2 接口定义

\[
f_{c,bi}
=
\chi_{cc}(r_c)f_c
\]

\[
\chi_{cc}(0)=1
\]

\[
\chi_{cc}(1)=\chi_{cc,max}
\]

建议先采用光滑插值函数：

\[
\chi_{cc}(r_c)
=
1+
(\chi_{cc,max}-1)
\sin^2
\left(
\frac{\pi r_c}{2}
\right)
\]

### 4.1.3 参数建议

层 0 默认：

\[
\chi_{cc}=1
\]

即不考虑双轴压缩增强，偏保守。

层 1 可取：

\[
1.00\le \chi_{cc,max}\le 1.16
\]

原因是 UHPFRC 数值/材料模型文献中有研究采用双轴压缩强度约为单轴强度 1.16 倍的设定；D’Alessandro、Roberts-Wollmann 和 Cousins 的 ACI Materials Journal 论文专门研究 UHPC direct biaxial behavior，可作为 UHPC 双轴包络标定的重要文献来源；Liu 等 2024 年针对无筋 UHPC 单元双轴应力状态的试验研究提出了 UHPC 双轴压缩强度包络分段函数，后续应优先核对并替换当前占位函数。([concrete.org](https://www.concrete.org/publications/internationalconcreteabstractsportal.aspx?id=51722404&m=details&utm_source=chatgpt.com))

### 4.1.4 当前锁定

\[
\boxed{
\chi_{cc}\text{ 是层 1 接口，不进入层 0 主线。}
}
\]

## 4.2 拉—压耦合压强度折减接口 \(\chi_{tc}\)

### 4.2.1 状态判别

进入拉—压状态。定义：

压向有效强度：

\[

=
\chi_{tc}(\varepsilon_t)f_c

压向应力：

\[

=

\left(

\[

=
\sigma_t^{UHPC}(\varepsilon_t)

### 4.2.3 建议工程化函数

为保持可计算性，建议采用分段线性折减接口：

\[
\chi_{tc}(\varepsilon_t)
=
\chi_B+
(\chi_A-\chi_B)
\max
\left(
1-\frac{\varepsilon_t}{\varepsilon_B},
0
\right)

其中：

\[
\varepsilon_B=0.0025
\]

纤维 UHPC 可先取：

\[
\chi_A=1.00,\quad
\chi_B=0.70
\]

无纤维 UHPC 可先取：

\[
\chi_A=1.00,\quad
\chi_B=0.50
\]

### 4.2.4 文献依据

Fehling、Leutbecher、Röder 和 Stürwald 的 UHPC 双轴加载研究专门讨论 UHPC/UHPFRC 板件在双轴压—拉状态下的结构行为，可作为 \(\chi_{tc}\) 的基础来源。([bau.uni-siegen.de](https://www.bau.uni-siegen.de/subdomains/massivbau/publikationen/download/structural_behavior_of_uhpc_under_biaxial_loading.pdf?utm_source=chatgpt.com)) Lee 等 2017 年在 *Materials and Structures* 发表的 UHPFRC 面内构件双轴拉—压强度研究，关键词即包括 biaxial panel test、compression-softening behaviour、failure criteria、tension-stiffening behaviour 和 UHPFRC；该文是 \(\chi_{tc}\) 的直接文献来源。([link.springer.com](https://link.springer.com/article/10.1617/s11527-016-0918-1?utm_source=chatgpt.com)) Liu 等 2023 年关于 biaxial tension-softened UHPC 的研究提出了受拉后 UHPC 压缩应力—应变关系，适合作为后续替换该线性接口的正式本构来源。([sciencedirect.com](https://www.sciencedirect.com/science/article/abs/pii/S0950061823026831?utm_source=chatgpt.com))

\chi_{tc}\text{ 是层 1 中最优先启用的 UHPC 双轴修正接口。}
}
\]

\chi_{tc}=1.00

与：

\[

两种路径做敏感性分析。

## 4.4 开裂后剪切保持接口 \(\beta_{UHPC}\)

### 4.4.1 Nguyen 原规则

Nguyen 对开裂后混凝土采用 shear retention factor。其 tension-compression cracked 状态中，剪切模量等于剪切保持因子与开裂前剪切模量的乘积；文中还给出 Foster 建议的 \(\beta\) 参数，并将 \(\beta_1,\beta_2,\beta_3\) 等作为材料常数。fileciteturn124file11 对 tension-tension cracked 状态，Nguyen 还采用了大幅降低的开裂后剪切模量。

这些是普通混凝土/RC wall 开裂后剪切退化参数，不直接迁移到 UHPC。

### 4.4.2 UHPC 化接口

定义：

\[
G_{12}^{cr}
=
\beta_{UHPC}G_0
\]

其中：

\[
0.10\le \beta_{UHPC}\le 1.00
\]

建议第一轮敏感性取：

\[
\beta_{UHPC}=1.00,\quad0.50,\quad0.30
\]

不建议第一版直接取：

\[
\beta_{UHPC}=0.10
\]

除非明确模拟普通混凝土式双向贯通裂缝。

### 4.4.3 文献依据

UHPC 的开裂后剪切传递机制与普通混凝土不同，钢纤维桥联、裂缝面摩阻和残余拉应力都会参与剪切传递。已有 UHPC 剪切传递与纤维桥联相关研究可作为后续标定 \(\beta_{UHPC}\) 的来源。([ouci.dntb.gov.ua](https://ouci.dntb.gov.ua/en/works/9jK8y5o7/?utm_source=chatgpt.com))

### 4.4.4 当前锁定

\[
\boxed{
\beta_{UHPC}\text{ 是层 1 敏感性参数，不进入层 0 主线。}
}
\]

# 7. 切线矩阵的一致性处理

层 1 中，如果应力引入 \(\chi_{cc}\)、\(\chi_{tc}\)、\(\chi_{tt}\) 或 \(\beta_{UHPC}\)，严格一致切线应包含：

\[
\frac{\partial \chi}{\partial \varepsilon_i}
\]

即：

\[
E_i^t
=
\frac{\partial \sigma_i}{\partial \varepsilon_i}
+
\frac{\partial \sigma_i}{\partial \chi}
\frac{\partial \chi}{\partial \varepsilon_i}
\]

但第一版建议采用更稳的割线修正版：

\[
\boxed{
\text{应力使用层 1 修正，切线采用当前单轴曲线算法切线。}
}
\]

即：

\[
\sigma_i=\sigma_i(\chi f)
\]

\[
E_i^{alg}=\max(E_i^{phys},E_{min})
\]

暂不显式纳入 \(\partial\chi/\partial\varepsilon_i\)。

这样做不是严格一致切线，但更利于矩阵路径稳定。待层 0 主线和云露钢壳模块算通后，再升级一致切线。

# 8. 是否仍然是矩阵解析解？

即使引入层 1，体系仍然可以保持矩阵解析迭代形式：

\[
\mathbf R(\mathbf q,\lambda,\boldsymbol\alpha)=0
\]

\[
\mathbf K_T
=
\frac{\partial \mathbf R}{\partial \mathbf q}
\]

\[
\boldsymbol\alpha^j
=
\mathcal H
(
\boldsymbol\alpha^{j-1},
\boldsymbol\varepsilon^j
)
\]

其中 \(\boldsymbol\alpha\) 包括：

\[
\chi_{cc},\quad
\chi_{tc},\quad
\chi_{tt},\quad
\beta_{UHPC},\quad
\chi_{conf}
\]

只要位移场仍采用有限项 Ritz / Galerkin 展开：

\[
u=\sum q_u\phi_u
\]

\[
v=\sum q_v\phi_v
\]

\[
W=\sum q_w\phi_w
\]

则它仍是：

\[
\boxed{
\text{带材料状态更新的矩阵解析迭代模型}
}
\]

而不是传统有限元网格模型。

但如果未来要完整追踪固定裂缝方向、压碎后损伤、卸载/再加载、裂缝带宽正则化和局部化耗能，则会越来越接近 Nguyen 式有限元材料程序。

# 11. 后续使用规则

后续进入总矩阵推导或 Case 计算时，按以下顺序启用：

1. **先用层 0 跑通 UCFT 板轴压路径**；
2. 若路径中 UHPC 主体基本处于压—压状态，则优先检查 \(\chi_{cc}\) 敏感性；
3. 若路径中出现明显拉—压混合区，则优先启用 \(\chi_{tc}\)；
4. 若出现大范围拉—拉开裂，则启用 \(\chi_{tt}\) 和 \(\beta_{UHPC}\)；
5. 若后续显式得到钢壳约束产生的等效围压，再启用 \(\chi_{conf}\)；
6. 在云露钢壳局部屈后模块未闭合前，不应让 UHPC 层 1 的高级修正掩盖钢壳局部屈曲反馈缺口。

最终，UCFT 材料模块应表述为：

\[
\boxed{
\text{Nguyen 框架迁移 + UHPC 单轴本构主线 + UHPC 双轴参数接口。}
}
\]

这一定义能够保证后续矩阵解析迭代体系有完整的应力、切线、膜力和稳定矩阵输入，同时避免把普通混凝土参数错误套用于 UHPC。

## 必须保留的历史力学含义

v5 曾明确锁定：

- PBL 主要以钢壳局部子板强固支边界体现；
- PBL 不单独作为轴压承载项；
- PBL 不作为显式弹簧能量项；
- 总承载力路径历史表达为 `N(lambda)=Nc+Ns+ + Ns-`，`Nu=max_lambda N(lambda)`；
- 局部屈曲事件、整板稳定事件、材料破坏事件均不自动等同于总承载力峰值；
- 云露只提供 Kármán 大挠度/薄膜效应/Galerkin 局部钢壁板思想，UCFT 整板矩阵是项目重建，不得冒充云露原文。
