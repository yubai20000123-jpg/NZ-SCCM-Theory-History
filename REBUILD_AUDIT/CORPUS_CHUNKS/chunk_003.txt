没有新增材料参数，没有试验荷载，没有结构 \(P_u\) 进入系数求解。

## 4. 为什么本轮不采用其他“看起来更直接”的修复

已经逐项检查：

1. **只改最后两个系数**：可以强制锚点，但会造成明显高阶振荡；
2. **在原 N48 后加线性/低阶修正**：一阶锚点能恢复，但全域函数值被明显拖偏；
3. **\(\lambda^2\) 因子化残差**：锚点天然正确，但在当前宽材料域上值误差明显恶化；
4. **两段可达谱带单独最小二乘**：可达区函数值较好，但谱隙内出现巨大多项式振荡，系数可达到 \(10^5\) 量级，不符合“简单、稳健、可手算审计”的要求；
5. **提高到 N96/N112**：本轮明确不采用，因为当前首先应解决表示规则，而不是用阶次覆盖错误。

因此，本轮选取的 N48-C1 是目前**最小结构改动**方案。

## E. 谱表观奇异性已正式消除

原 spectral return 中 `(s+ - s-)/(2R)` 在 R→0 看似 0/0。现已改写为 symmetric divided difference：

- even part A_F(mu,R²)；
- divided-difference part D_F(mu,R²)。

D_F 在 R²=0 有正常解析极限 F'(mu)。

更进一步，完整 frozen interaction 可写成无 1/R 的等价矩阵函数：

`S = U - acc det(C) C + tr(T) C - C T - rho_m a_t det(T)[tr(T^7) I - T^7]`。

因此 R≈0 不能再成为任何 spatial split 的理由。

## H. 本轮严格尾项尝试与否定结果

### H1. 单一 Chebyshev l1 Banach tail

建立 finite coefficients + scalar l1 tail，严格覆盖 high-high→low feedback。数学上安全，但对 Rq 的界极端过宽（数量级百万），不能作为有效 certificate。

**结论：不是 Banach algebra 思想错误，而是把所有空间方向/谱分支/模态结构压成一个标量 tail 太粗。**

### H2. Padded nonlinear multiplication

仅扩大 nonlinear product 工作 degree 而不补真实输入高阶 modes，会产生严重伪反馈甚至爆炸，已废止。

### H3. Direct radical Newton/Zolotarev-like iteration on truncated fields

低阶 truncated global fields 不能保证正 radicand 的 positivity，迭代可发散。未经过 validated tail 前不得作为正式路径。

这意味着：当前 scalar material series 若覆盖从 λ- 最小值到 λ+ 最大值的整段连续区间，会无谓逼近一个实际不访问的大空白谱区间。

**建议下一数学主线：** 在不做空间 sampling、不分空间域的前提下，对两个分离谱区间建立具有显式统一误差的 rational / polynomial functional calculus；优先研究 Zolotarev/Akhiezer 类 minimax rational representation 或等价的 disconnected-set approximation。它不是空间分片；被逼近对象仍是同一个 frozen material function，空间域仍为一个完整半波。

# NZ-SCCM Swartz24：原文试验/屈曲观察与三组误差机制诊断

**Date:** 2026-08-11  
**Status:** SOURCE-GROUNDED DIAGNOSTIC, NON-CALIBRATING

## 0. Boundary

本诊断只用于解释已冻结的 24 板盲算误差结构，不允许据此回调 R10、N48、q0、钢筋参数或单板材料参数。

当前 NZ-SCCM 比较对象是 **failure / ultimate load**；Nguyen 第5章对 Swartz et al. (1974) 的详细原文讨论主要针对 **buckling / critical load and buckled shape**。二者不是同一个物理量。下面使用临界状态信息解释为什么三个宽厚比组进入不同主控机制，但绝不把临界荷载当作当前 Pu。

## 1. Nguyen 对 Swartz 24 板的三组原文信息

Nguyen Table 5.3/5.4 将 24 块板按宽厚比/细长程度汇总为三组：

|组|大致 Case|b/t|平均试验屈曲荷载/kN|Nguyen FE/kN|平均临界应力/MPa|临界应力/混凝土强度|
|---|---|---:|---:|---:|---:|---:|
|1|1–8|48.0|521|505|16.28|0.795|
|2|9–16|38.3|560|561|14.43|0.930|
|3|17–24|63.1|335|305|12.93|0.618|

Nguyen 明确指出：随着细长程度增加，临界应力与混凝土强度之比降低；这些细长板的屈曲发生在混凝土已经进入非线性范围以后，因此材料切线会直接影响屈曲。

### 1.1 Case 17–24：最细长组

Nguyen 说明 panels 17–24 的计算屈曲形态为 **两个正弦半波**，屈曲应力仅略高于板强度的一半；其形态接近相同 a/b=2 的弹性板，并且 panel 21 的形态与 Swartz 试验记录相似。使用加载方向混凝土切线模量、非加载方向弹性模量构成的正交异性板也能得到类似形态。

### 1.2 Case 1–16：较厚两组

对于 b/t 约 48 与 38 的板，Nguyen 得到的屈曲形态约为 **一个正弦半波**。这两组屈曲前平均应力已分别达到约 0.795fc 与 0.93fc，因此处于非常明显的材料非线性区域。其屈曲形态与同长宽比的各向同性弹性板不同，而更接近采用加载方向切线模量的正交异性板。

### 1.3 钢筋影响

Nguyen 的 Table 5.5 检查了 0.2%、0.5%、0.75%、1.0% 配筋率以及一层/两层钢筋。结论是：**钢筋对屈曲荷载的影响不显著**，并指出这与 Swartz et al. 和 Swartz & Rosebraugh 的结论一致。

注意：这是对 **buckling load** 的结论，不等价于说钢筋对最终 failure load 完全无影响。

### 1.4 Nguyen 对不同理论结果差异的原文解释

Nguyen 的 FE 临界荷载总体比 Attard 和 Swartz–Rosebraugh 解析结果高、但通常低于试验。Nguyen 给出的原因之一是：

- Attard 在非加载方向取约 0.4Ec，并假定该方向混凝土开裂；
- Swartz–Rosebraugh 的正交异性板公式则基于屈曲开始时混凝土未开裂的假设。

这说明 **非加载方向的开裂/有效模量处理，以及加载方向的切线模量状态**，能够系统改变 RC 板的稳定结果。

## 3. 为什么三组会表现非常不同

### 3.1 核心原因不是“板厚本身”，而是板厚改变了极限前的主控机制

三组宽厚比使结构分别处在不同的“几何稳定—材料非线性”竞争区间：

- b/t≈38.3：屈曲时已到约 0.93fc，属于 **材料峰值/强非线性主导的厚板区**；
- b/t≈48：约 0.795fc，属于 **材料非线性与几何稳定共同控制的过渡区**；
- b/t≈63.1：约 0.618fc 且出现两个半波，属于 **几何稳定更早介入的细长板区**。

所以一个统一的低维 D–q、单代表半波、R10 current-map 模型不应预期对三组产生同样的误差方向。

### 3.2 Case 9–16 为何系统低估最明显

这一组最厚、最不细长，原文显示其屈曲前应力已达到约 0.93fc，几乎触及混凝土峰值。换言之，试件在临界稳定附近已经进入最敏感的材料非线性区。

此时最终 failure capacity 对以下机制特别敏感：

1. 加载方向真实切线在峰值附近的变化；
2. 非加载方向是否开裂、其有效刚度如何；
3. 两向应力/应变重分布；
4. 屈曲后仍可获得的膜内再分配和承载储备；
5. 初始缺陷和轻微偏心引起的二阶路径。

当前 NZ-SCCM 虽然保留二维 current-map 与二阶运动学，但仍压缩到 D、q 两个全局变量和一个连续代表半波。对 b/t≈38 这种“接近材料峰值后才屈曲”的板，这个低维空间更容易 **过早结束或低估屈曲后的应力重分布储备**。

一个很直观的后验指标是：这一组原始平均试验屈曲荷载约 560 kN，而当前理论 failure 平均约 572 kN，二者非常接近；但真实 failure 平均约 664 kN。也就是说，当前模型在这一组捕捉到的承载水平更像“临界附近 + 少量后续储备”，而试验仍有更大的屈后/材料重分布储备。该比较是诊断，不是校准。

因此 Case 9–16 的系统性 -13.23% 很可能首先指向：

**厚板高应力区的后屈曲/膜内重分布自由度不足，或峰值附近多轴材料切线的真实演化尚未被当前低维表示完全捕捉。**

这比“把 R10 调高 13%”合理得多。

### 3.3 Case 17–24 为何整体最好

这一组最细长，原文显示在约 0.618fc 就发生屈曲，并呈两个正弦半波，形态接近弹性/切线正交异性板。此时几何稳定在材料峰值之前很早就介入，问题更接近：

```text
连续正弦半波几何
+ 二阶运动学
+ 当前切线材料
+ 稳定路径
```

这恰好是当前 one-continuous-complete-halfwave + Nguyen second-order + tangent/current-map + D15 路线最擅长表达的部分。

完整物理板 a/b≈2 时原文出现两个半波；当前理论只算一个 **代表完整半波**，并不要求把两个重复半波各自空间离散，因此与该组的实际模态结构是兼容的。

当前理论平均 371.42 kN，对比真实 failure 平均 380.93 kN，平均只低约 9.52 kN。这与其 MAPE=8.06% 为三组最低一致。

Case17 仍低估 21.56%，说明这一解释不是说第三组“已经完全解决”，而只是说明该组总体机制与当前理论架构更匹配。

### 3.4 Case 1–8 为何正负误差混合

b/t≈48 的临界应力约 0.795fc，正处于过渡区：材料已经明显非线性，但尚不像 b/t≈38 那样几乎压到峰值；几何失稳也不像 b/t≈63 那样很早主导。

因此这一组对材料曲线、当前应力面、初始缺陷、钢筋层位以及二阶几何之间的相对权重最敏感。当前结果从 Case1–3 高估、Case4接近，到 Case5–7低估、Case8再次高估，说明不存在一个单一的“组常数偏差”。

这一组当前理论平均 562.29 kN、试验 failure 平均 548.24 kN，组均值只高 14.05 kN，但 MAPE 仍为 12.66%。这意味着 **组均值发生了正负误差抵消**，不能把 +4.43% 解读为“这一组已经很好”。

## 4. 哪些原因目前有源证据，哪些只是合理推断

### 有明确文献证据

### 当前可以提出、但尚不能称为已证实的机制

## 3. 对 “L/KZ bulk gate” 名称的纠正

此前把 `L` 与 `KZ` 合称一个后置 bulk gate 容易造成错误印象。

### 3.1 L 不是 Pu 算完后的额外门禁

当前 Pu 定义本身就是同一 equilibrium branch 上的第一极限点：

`Rq(D,q)=0` 与 `L(D,q)=0`，并要求沿主支 `dP/ds : + -> -`。

因此：

```text
CURRENT_Pu_EXISTS
=> current solve must have evaluated Rq and L at the root
```

对 Cases1–18 真正的问题是 **current L/root intermediate values 没有保存到 GitHub checkpoint**，而不是“Pu 已经算出来但当时根本没有算 L”。

### 3.2 KZ 才是独立的额外一致性/稳定性审计

KZ 用同一 current tangent 检查在 Pu 之前是否已有 tangent-zero。它不作为第二套 Pu 求解器。

所以以后状态名称改为：

```text
PU_LIMIT_POINT_SOLVE = Rq + L + branch maximum
KZ_PRELIMIT_STABILITY_AUDIT = independent same-branch audit
```

不得再用“L/KZ 后置门禁”掩盖 L 已经属于 Pu 求解本体这一事实。
