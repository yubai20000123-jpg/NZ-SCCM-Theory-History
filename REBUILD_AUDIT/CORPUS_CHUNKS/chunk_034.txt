# 1. 研究目标与用户约束

本项目真正关心的是有限幅值平衡路径上的极限承载力：

\[
P_u=\max_{\text{可达平衡路径}} P .
\]

在光滑极限点处，当时采用：

\[
R_A(D,A)=0
\]

与

\[
L(D,A)=P_{,D}R_{A,A}-P_{,A}R_{A,D}=0
\]

共同确定极限状态。材料非光滑事件控制时比较事件两侧 one-sided states。

当时锁定要求包括：正式空间积分零数值积分；不允许连续板切成材料点云再用 Gauss/Simpson/adaptive quadrature；不采用板级 Chebyshev surrogate；材料 current operator 写为 \(\sigma=M(\varepsilon)\)；不使用运行时 TT/TC/CC 分类作为生产主线；不以材料点 Newton/history array/load-step history 为正式主线；切线由同一 current map 求导；材料拟合优先面向文献公式而非结构 Pu；结构试验不得反标材料；理论必须人工可审计。

# 2. 为什么采用 current material operator

在单调轴压、固定边界、一个连续完整代表半波、不研究循环卸载、结构未知量有限的限定下，给定 \(D,A\) 后连续应变场已知，因此直接使用：

\[
(D,A)\rightarrow\varepsilon(X,Y,\zeta)\rightarrow M(\varepsilon)\rightarrow\sigma(X,Y,\zeta)\rightarrow P,R_A,L.
\]

其目的在当时是切断传统 FE 式“空间点→状态分类→历史变量→材料点迭代→应力”链条。

# 6. 统一 current tensor 接口

\[
\mathbf E=\begin{bmatrix}\varepsilon_x&\gamma_{xy}/2\\\gamma_{xy}/2&\varepsilon_y\end{bmatrix},
\]

\[
\mathbf E_u=\frac{(1-\nu)\mathbf E+\nu\operatorname{tr}(\mathbf E)\mathbf I}{1-\nu^2},

\mathbf X_M=\mathbf E_u/\varepsilon_{0,M}.

# 7. 为什么不再生成自由二维大系数表

几十乃至更多二维 Chebyshev 自由系数会造成物理意义不清、stress/tangent 同时约束困难、高阶内部振荡、来源关系难保持以及空间展开项数爆炸。因此当时转向“少数一维来源函数 + 少数低参数 tensor interaction”。

# 8. D15 精确矩

基本空间矩：

\[
\mathcal I_{abh}=\int_0^\pi\sin^aX\,dX\int_0^\pi\sin^bY\,dY\int_{-1}^{1}\zeta^h\,d\zeta.
\]

\[
\int_0^\pi\sin^nX\,dX=\sqrt\pi\frac{\Gamma((n+1)/2)}{\Gamma((n+2)/2)},
\]

\[
\int_{-1}^1\zeta^h\,d\zeta=0\;(h\text{ odd}),\qquad=2/(h+1)\;(h\text{ even}).
\]

只要 integrand 写成有限三角—厚度代数组合，空间积分可由解析矩完成。

# 9. expand-all then D15 的淘汰

错误组织是完整展开巨大 \(\sigma(X,Y,\zeta)\) 后再 D15，导致表达爆炸、内存急剧增长和人工不可审计。由此转为 moment-first contraction：每生成一个结构真正需要的解析材料矩对象，立即施加目标积分泛函，不保留不必要的巨大空间展开。

# 10. Q_nm 与 moment-first 的严格意义

对解析基函数 \(T_n,T_m\)，定义连续场：

\[
Q_{nm}(X,Y,\zeta;D,q)=\mathcal C[T_n,T_m].
\]

它不是空间点。通过二维 Cayley-Hamilton 可写成：

\[
Q_{nm}=\frac12(S_{nm}-K_1A_{nm})\mathbf I+A_{nm}\mathbf Z.
\]

对轴力和幅值平衡分别施加解析线性泛函：

\[
M_{nm}^{P}=\mathscr L_P[Q_{nm}],
\qquad
M_{nm}^{R}=\mathscr L_R[Q_{nm}].
\]

所谓“立即积分并删除空间变量”是完成解析积分后的代数收缩，不是离散化。与 Gauss 求和的区别是正式成本依赖解析项数而不是空间点数。

# 2. 先纠正一个关键判断：完整不降阶L0不是“更高层理论”

\[
\boxed{
\text{二者属于相同的物理层级——层0。}
}

- UHPC双轴或三轴强度增强；

\]

整体平衡保留两个轴向面内Ritz自由度、两个横向面内Ritz自由度和一个整体面外幅值。

Case-2再通过B1局部模块计算各360 mm子板的局部幅值、平均应力、有效切线和状态，并将其回代到整体平衡和整板切线矩阵中。历史峰值表确实保存了上述五个整体变量以及局部S1p状态、轴力分项和切线特征值。

这里**不采用**此前错误建立的：

\[
[\varepsilon_Y^0,\eta,A^+,A^-]^{\mathsf T}
\]

四变量重闭合。那套模型已经撤销，不能代表历史L0-B1-TC-EP。

# 4. 两套理论共同的层0物理基础

以下部分两者相同，不构成差异。

## 4.1 力学对象

结构隔离体为：

\[
\text{上钢壳}
+
\text{连续UHPC核心板}
+
\text{下钢壳}
+
\text{PBL形成的局部边界约束}.
\]

PBL：

\[
N_{\mathrm{PBL}}=0,
\qquad
U_{\mathrm{PBL}}^{\mathrm{spring}}=0.
\]

总轴力：

\[
N=N_c+N_s^++N_s^-.
\]

## 4.2 初始构形几何非线性

两者均区分：

- 初始整体缺陷 \(W_{g0}\)；
- 加载新增整体挠曲 \(\widehat W_g\)；
- 局部初始缺陷 \(w_{\ell0,i}^{\pm}\)；
- 加载新增局部鼓曲 \(\widehat w_{\ell i}^{\pm}\)。

整体总挠度为：

\[
W_{gt}=W_{g0}+\widehat W_g.
\]

钢壳局部子板总挠度由整体和局部两部分叠加，并保留von Kármán型平方项和局部—整体交叉项。

## 4.3 材料层级

UHPC采用层0单轴受压主曲线和一致切线：

\[
\sigma_c=\sigma_c(\varepsilon_c),
\qquad
E_{c,t}=\frac{d\sigma_c}{d\varepsilon_c}.
\]

钢材采用纵向标量弹塑性模型；局部钢壳可进入弹性后屈曲和纤维弹塑性后屈曲。

## 4.4 路径型承载力定义

两者均应以有效平衡路径上的总轴力峰值定义承载力：

\[
\boxed{
N_u=\max_{\lambda\in\mathcal P_{\mathrm{valid}}}N(\lambda)
}
\]

钢壳首次屈服、局部屈曲、整体切线失稳、UHPC达峰、局部状态转换均只是路径事件，不必然单独等于 \(N_u\)。

# 5. L0-B1-TC-EP的完整计算过程

下面按照历史B1路径逻辑逐步列出。

## 5.1 输入与分区

输入：

\[
a_c,\ B_c,\ t_c,\ t_s^\pm,\ z_s^\pm
\]

以及：

\[
f_c,\ E_c,\ \varepsilon_{c0},\ E_s,\ f_y,\ \nu_s.
\]

钢壳按PBL边界划分为局部子板：

\[
\Omega_{\ell i}^{+},
\qquad
\Omega_{\ell i}^{-}.
\]

Case-1和Case-2的区别只来自实际分区及其局部事件：

- Case-1：120 mm子板，局部屈曲峰前不激活；
- Case-2：360 mm子板，局部屈曲和局部纤维弹塑性后屈曲激活。

## 5.2 采用单一整体面外模态

B1使用一个预选整体模态：

\[
\psi_g(X,Y).
\]

整体初始缺陷：

\[
W_{g0}=\eta_0\psi_g.
\]

当前整体挠曲：

\[
W_{gt}=\eta_t\psi_g
\]

或者以新增幅值表示为：

\[
W_{gt}=(\eta_0+\eta)\psi_g.
\]

因此所有整体挠曲形状均被限制在同一个函数方向内，只有幅值变化。

这是B1的第一个主要约束：

\[
\boxed{
\text{整体面外位移空间只有一个预选模态方向。}
}
\]

## 5.3 最小整体面内Ritz变量

历史计算保留：

\[
\mathbf q_g^{B1}
=
[q_{u1},q_{u2},q_{v1},q_{v2},\eta_t]^{\mathsf T}.
\]

因此面内位移不是完全均匀应变，但只保留预先选定的低阶Ritz项：

\[
u(X,Y)
=
-\lambda X
+
q_{u1}U_1(X,Y)
+
q_{u2}U_2(X,Y),
\]

\[
v(X,Y)
=
q_{v1}V_1(X,Y)
+
q_{v2}V_2(X,Y).
\]

整体未知量维数固定为五。

## 5.4 局部子板形函数

每个PBL间钢壳子板使用四边固支局部形函数：

\[
\psi_{\ell i}
=
\left[
1-\cos\left(
\frac{2m_i\pi X}{a_{\ell i}}
\right)
\right]
\left[
1-\cos\left(
\frac{2\pi\bar Y_i}{B_{s,i}}
\right)
\right].
\]

满足：

\[
w_\ell=0,
\qquad
\frac{\partial w_\ell}{\partial n}=0
\]

于局部子板边界。

## 5.5 B1同侧统一幅值约束

B1不让每个局部子板自由发展独立幅值，而采用：

\[
A_i^\pm=\omega_i^\pm A^\pm.
\]

其中：

\[
\omega_i^\pm
=
\frac{
\max_X|\psi_g(X,Y_i^\pm)|
}{
\max_{X,Y}|\psi_g(X,Y)|
}.
\]

对于一阶正弦整体模态：

\[
\omega_i^\pm
=
\left|
\sin\frac{\pi Y_i^\pm}{B_c}
\right|.
\]

但局部初始缺陷不按整体模态加权：

\[
A_{0i}^\pm\neq\omega_i^\pm A_0^\pm,
\]

而取统一制造缺陷值或各子板实测值。

因此B1的核心局部约束是：

\[
\boxed{
\begin{aligned}
&\text{同一侧所有局部子板只有一个母幅值 }A^\pm;\\
&\text{不同子板仅通过预设 }\omega_i^\pm\text{产生比例差异。}
\end{aligned}
}
\]

## 5.6 钢壳总挠度

上、下钢壳第 \(i\) 块子板的当前挠度为：

\[
W_{s,i}^{\pm}
=
W_{gt}
+
s_\pm
\left(
A_{0i}^\pm+A_i^\pm
\right)\psi_{\ell i}^{\pm},
\]

其中：

\[
s_+=+1,\qquad s_-=-1.
\]

钢壳纵向应变保留：

\[
\frac12
\left(
W_{g,X}+w_{\ell,X}^{\pm}
\right)^2.
\]

展开即：

\[
\frac12W_{g,X}^2
+
W_{g,X}w_{\ell,X}^{\pm}
+
\frac12(w_{\ell,X}^{\pm})^2.
\]

因此历史B1并不是完全忽略局部—整体耦合；它保留了耦合，但耦合发生在被约束后的低阶幅值空间中。

## 5.7 UHPC材料更新

在每个积分点计算：

\[
\varepsilon_c
=
\varepsilon_m
-
z\kappa.
\]

然后更新：

\[
\sigma_c(\varepsilon_c),
\qquad
E_{c,t}(\varepsilon_c).
\]

恢复：

\[
N_c
=
\int_{\Omega_c}\int_{-t_c/2}^{t_c/2}
\sigma_{c,x}\,dz\,d\Omega.
\]

当：

\[
\varepsilon_{c,\max}
=
\varepsilon_{c0}
\]

时，历史L0-B1路径按UHPC峰值边界终止。

## 5.8 局部钢壳状态判断

历史TC-EP逻辑采用分段状态链：

\[
S0\rightarrow S1e\rightarrow S1p\rightarrow S2.
\]

### S0：局部屈曲前

局部子板仍沿基本材料压缩路径承载。

### S1e：弹性局部后屈曲

局部子板达到弹性屈曲条件后，局部幅值发展，平均应力按大挠度后屈曲关系更新。

### S1p：局部纤维弹塑性后屈曲

局部最大纤维进入钢材非线性区后，局部平均应力和局部有效切线由弹塑性纤维状态计算：

\[
\sigma_{s,i}^{avg},
\qquad
E_{s,i}^{tan}.
\]

Case-2峰值时360 mm子板主要处于S1p，而不是平均全宽达到 \(f_y\) 的平台。

### S2：强度封顶

早期低阶B1理论允许在达到局部强度上限时进行幅值或平均应力封顶。该状态属于历史B1计算闭合的一部分。

## 5.9 TC切线更新

每个局部子板根据当前状态输出：

\[
\sigma_{s,i}^{avg},
\qquad
E_{s,i}^{tan}.
\]

这些量进入：

- 上、下钢壳轴力积分；
- 整体切线矩阵；
- 面外稳定项；
- 局部—整体耦合项。

因此TC的核心作用不是简单修改最终轴力，而是：

\[
\boxed{
\text{使当前钢壳局部弹塑性状态进入整板切线刚度。}
}
\]

Case-2中局部有效切线降低到约50～90 GPa，引起整体面外刚度提前软化，并加速UHPC压区应变集中。

## 5.10 整体残量和切线矩阵

给定路径参数：

\[
\lambda=\varepsilon_X^0,
\]

求解整体五变量平衡：

\[
\mathbf R_g^{B1}
\left(
q_{u1},q_{u2},q_{v1},q_{v2},\eta_t;
\lambda
\right)
=
\mathbf0.
\]

组装低阶切线矩阵：

\[
\mathbf K_T^{B1}
=
\frac{\partial\mathbf R_g^{B1}}
{\partial\mathbf q_g^{B1}}.
\]

局部子板状态通过当前平均应力和有效切线进入该矩阵，但局部子板并没有全部作为独立Newton未知量进入一个完整矩阵。

## 5.11 有缺陷路径

当：

\[
\eta_0>0
\]

时，从第一个载荷步起便存在二阶效应。路径过程为：

\[
\text{初始缺陷响应}
\rightarrow
\text{钢壳屈服或局部屈曲}
\rightarrow
\text{切线刚度退化}
\rightarrow
\eta_t\text{增长}
\rightarrow
\text{应力重分布}
\rightarrow
\text{UHPC达峰或总轴力峰值}.
\]

这对应历史B1、B2路径。

## 5.12 无缺陷路径

当：

\[
\eta_0=0
\]

时，首先沿平直完美轴压分支：

\[
\eta_t=0.
\]

对于Case-1，正确事件逻辑为：完美轴向压缩 → 钢壳屈服 → 按当前材料切线计算整板临界荷载 → 平直分支失稳 → 进入二阶效应并搜索新的非零平衡点 → 新稳定支路或被UHPC峰值截断。

对于Case-2，无缺陷路径还必须先处理局部平凡分支以及360 mm子板的完美局部分岔。

## 5.13 路径终止和承载力

每个路径点恢复：

\[
N_c,\quad N_s^+,\quad N_s^-,
\]

\[
N=N_c+N_s^++N_s^-.
\]

监测：

\[
