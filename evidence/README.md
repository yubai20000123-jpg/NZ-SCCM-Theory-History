# EVIDENCE

这里保存**来源与证据**，不保存“当前路线身份”。当前身份看 `current/CURRENT_STATE.md`。

## 目录

- `catalog/`：上传文件总账、File Library ID、SHA、来源 URL、inventory chain。
- `materials/NC/`：Nguyen 等普通混凝土/钢筋有效来源片段。
- `materials/UHPC/`：UHPC 一级来源证据、历史状态闭合台账、来源数据。
- `steel_shell/`：云露/张宁/孙立鹏/PBL/钢壳有效来源与边界。

## 证据等级

原始 PDF/正式出版物最高。GitHub 中的 excerpt、TXT 或 CSV 是定位和恢复辅助；涉及公式、图表、页码歧义时回到原始 PDF。

不要把多个来源“拼起来”就宣称形成完整 production operator；是否闭合由 `current/CURRENT_STATE.md` 和相应 closure/audit 文件决定。
