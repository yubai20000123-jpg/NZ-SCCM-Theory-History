定义：

\[
\Pi_\eta(z)=
\frac{z^2\left(\sqrt{z^2+\eta^2}+z\right)}{2(z^2+\eta^2)}
\]

\[
H(r;r_0)=\frac12\left[(r-r_0)+\sqrt{(r-r_0)^2+\eta_R^2}\right]

\]

\[
c=\Pi_\eta(-\lambda),\qquad t=\Pi_\eta(\lambda)
\]

\[
C(\lambda)=\frac{\kappa c}{1+(\kappa-2)c+c^2}

\[

\[

\[

并且：

\[

\]

因此本轮拟合的是以上 exact frozen source functions，而不是 R01 rational coefficients。

## 3. 实际拟合方法

对每个 primitive 和每个：

\[
n=2,3,\ldots,16
\]

搜索：

\[
p_n(\xi)=\sum_{k=0}^n a_k\xi^k.
\]

为了尽量避免把普通 least-squares 的坏结果误判成“多项式族本身失败”，本轮采用更强的离散 minimax screen：

1. 在 4001 个**材料坐标** \(\lambda\) 点上，以 Chebyshev basis 建立线性规划；
2. 最小化最大绝对 primitive error；
3. 在独立 100001 点材料坐标上验证；
4. 对 n=16 再用 20001 点 minimax + 200001 点独立验证复核；
5. Chebyshev 只用于求系数的条件数；最终候选必须转换成普通 \(\xi^k\) 显式多项式。

这些材料坐标点只用于**离线材料 compiler coefficient identification**，不是结构空间积分点，也不进入正式 production operator。

为了使 FAIL 不依赖苛刻门槛，本轮使用两个门：

```text
desired direct-production screen : normalized max error <= 5%
relaxed fail-fast screen         : normalized max error <= 10%
```

只要任一 primitive 在 n<=16 仍超过 10%，P2-A 即 FAIL。

归一化误差定义：

\[
E_{\max}^{norm}=\frac{\max|p_n-f|}{\max|f|},
\qquad
E_{95}^{norm}=\frac{Q_{0.95}(|p_n-f|)}{\max|f|}.
\]

## 9. 为什么 T/V 失败：不是简单提高到 17 阶即可解决的问题

source T 在非常窄的正拉伸坐标内迅速变化：

```text
T(0)     = 0
T(0.025) = 0.495752
T(0.05)  = 0.972971
T(0.10)  = 0.922256
T(0.20)  = 0.767075
```

而整个拟合区间宽度约为：

```text
3.1707317
```

transition characteristic coordinate 是：

```text
xcr ~= 0.0499872
```

一个 degree<=16 的 single global polynomial 必须同时处理长度约 3.17 的全域和尺度约 0.05 的 sharp activation；实际 minimax 结果已经证明它无法做到。

V=T^8 又把该 narrow activation 进一步放大，所以 n=16 的 normalized max error 仍为 43.28%。

## 11. 当前结论

P2-A 证明：

> 同一 source-shaped 物理结构不能简单通过“每个 primitive 一个 degree<=16 的全局多项式”恢复为小型 D15 production compiler。

失败的根因主要是 tension activation primitive `T` 及 `T^8` 的窄尺度结构。

这同时说明下一步若继续，必须先重新选择**兼顾 source-shape 与 direct-integrability 的低复杂度 primitive basis**；不能继续沿“提高 global polynomial degree”或“用大辅助系统救积分”两条路线。
