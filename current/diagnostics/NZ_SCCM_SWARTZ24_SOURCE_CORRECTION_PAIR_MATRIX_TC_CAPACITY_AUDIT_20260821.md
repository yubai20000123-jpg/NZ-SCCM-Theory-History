# NZ-SCCM — Swartz24 来源修正、可信配对矩阵与 TC/容量诊断

**时间：2026-08-21**  
**状态：CURRENT DIAGNOSTIC / NON-CALIBRATING**

## 0. 本轮边界

本轮不重新研究实验起屈荷载，也不修改：

\[
D_x,D_y,H,P_{cr},C,G,J,q_0,P_{pb}(q).
\]

由于当前理论已显式预置无应力初始缺陷，实验 Pcr 的 Southwell / deflection / strain 等不同识别方法不作为当前 Pu 理论必须拟合的统一事件。

本轮只做：

1. 修正 Swartz 配筋率来源解释；
2. 从24块中挑出真正具有说服力的重复/准重复试件；
3. 对这些设计点比较实验 failure load 与当前显式 Pu；
4. 在冻结结构层上诊断 CC/TC 与基础强度转换。

---

## 1. Swartz配筋率来源修正

Swartz 表中 `0.20%,0.50%,0.75%,1.00%` 为**每方向、跨全部钢筋层合计**配筋率：

\[
\rho_x=\rho_y=p_{table}.
\]

不是：

\[
\rho_x=\rho_y=p_{table}/2.
\]

现有 RC 相体积守恒公式保持不变：两个方向钢筋均替代混凝土体积，只有加载方向钢筋直接加回加载方向轴力。

---

## 2. 可信重复设计点

优先比较如下设计点，而不是先把24块整体按宽厚比分组三类做机制拟合。

### 2.1 Case1 / Case2

结构参数：

- `t=25.40 mm` 两块相同；
- `rho_x=rho_y=0.20%`；
- 单层中面钢筋；
- 混凝土实测值存在正常批次/试件差异。

实验：

\[
P_{f,1}=490.194\rm\ kN,\qquad P_{f,2}=506.652\rm\ kN,
\]

相差约 `+3.36%`。

正确配筋率映射后的当前显式理论：

\[
P_{u,1}=567.712\rm\ kN,\qquad P_{u,2}=561.638\rm\ kN,
\]

相差约 `-1.07%`。

理论和实验均判断二者属于近似同一承载水平，但理论成对整体约偏高13%。因此 `1/2` 是“重复性较好 + 理论稳定偏高”的可信设计点。

### 2.2 Case9 / Case10

结构设计相同：

- `t=31.75 mm`；
- `rho_x=rho_y=0.20%`；
- 单层中面钢筋。

主要区别来自混凝土批次：

- Case9 `fc=15.02 MPa, E0=15.480 GPa, eps0=0.00194`；
- Case10 `fc=15.54 MPa, E0=17.656 GPa, eps0=0.00176`。

实验：

\[
625.865\to696.147\rm\ kN\quad(+11.23\%).
\]

理论：

\[
515.424\to534.711\rm\ kN\quad(+3.74\%).
\]

方向一致，且两块均明显低估。因此“Case9/10 这一设计点当前理论确实偏低”比“Case9–16组均值偏低”的证据更强。

### 2.3 Case19 / Case20

高度接近：

- `t=19.23 / 18.97 mm`；
- `fc=20.20 / 20.76 MPa`；
- `E0=21.482 / 20.977 GPa`；
- `eps0=0.00188 / 0.00198`；
- `rho_x=rho_y=0.50%`；
- 单层中面钢筋。

实验：

\[
377.654\to372.761\rm\ kN\quad(-1.30\%).
\]

理论：

\[
339.177\to335.013\rm\ kN\quad(-1.23\%).
\]

相对变化几乎完全一致，但整体约低10%。这是当前最强重复性设计点之一。

### 2.4 Case21 / Case22

参数高度接近，均 `rho_x=rho_y=0.75%`、单层中面钢筋。

实验：

\[
368.313\to355.858\rm\ kN\quad(-3.38\%).
\]

理论：

\[
350.460\to351.679\rm\ kN\quad(+0.35\%).
\]

二者均表现为接近承载水平；整体偏差较小。

## 3. 控制变量配筋对与实验离散

### Case18 / Case23

两块均：

- `t=19.38 mm` 完全相同；
- 单层中面钢筋；
- `fc=19.83 / 19.89 MPa`；
- `E0=23.058 / 23.818 GPa`；
- `eps0=0.00172 / 0.00167`。

显著差异主要为：

\[
\rho_s:0.20\%\to1.00\%\quad\text{per direction}.
\]

当前理论已经扣除钢筋替代的混凝土体积，仍给出温和的正承载增益；实验却由 `396.337 kN` 降至 `346.961 kN`。因此不能用该单对反标钢筋增益；它首先证明 Swartz 单板极限值包含表中参数之外的离散/潜变量。

其它控制配筋对也出现明显不一致：例如相似的 `0.75%→1.00%` 变化在 `14/15` 中实验增幅约7%，在 `13/16` 中却约41%。因此总体配筋效应不能由单板差值直接反推。

## 4. 四个可信设计点的平均极限应力

用毛截面平均应力

\[
\bar\sigma=P/(bt)
\]

比较，实验四个可信设计点约为：

|设计点|实验平均应力 MPa|理论平均应力 MPa|设计点偏差|
|---|---:|---:|---:|
|1/2|16.08|18.22|约 +13.3%|
|9/10|17.06|13.56|约 -20.6%|
|19/20|16.10|14.47|约 -10.2%|
|21/22|15.40|14.93|约 -3.0%|

实验四点均值约 `16.16 MPa`，CV约4.2%；理论四点离散反而更大。这提示当前确定性模型对某些材料输入/容量状态的响应可能强于这些可信设计点实际表现，但不能因此直接调整材料参数。

## 5. 单轴 squash 上界诊断

对于单层中面钢筋，若暂时假定加载方向钢筋全部屈服，并使用当前分析压缩强度，定义极宽松单轴上界：

\[
P_0=bt[(1-2\rho_s)f_c+\rho_sf_y].
\]

可信设计点的平均 `Pf/P0`：

- Case1/2 ≈0.684；
- Case9/10 ≈1.048；
- Case19/20 ≈0.702；
- Case21/22 ≈0.621。

Case9/10 平均试验已经达到/超过当前 `0.85 fcyl` 分析强度定义下的单轴 squash 上界；Case10 尤其明显。因此 Case9/10 的缺口至少部分是**容量侧**问题，不能只归因于几何稳定或起屈荷载。

## 6. Airy二维状态诊断

冻结当前结构层，在原显式极限根处直接使用 Airy 膜力，并以最小 transverse plane-stress closure 恢复厚度应力，仅作象限诊断。

|Case|Nx N/mm|CC厚度比例|受压面 transverse sigma_x MPa|低压侧 transverse sigma_x MPa|
|---:|---:|---:|---:|---:|
|1|+17.11|36.3%|-0.396|+2.61|
|2|+14.82|37.9%|-0.396|+2.36|
|9|+5.83|48.7%|-0.302|+0.97|
|10|+5.56|48.9%|-0.300|+0.96|

Case9/10 虽有更厚 CC 区，但并不是强横向围压：净 `Nx` 为拉力，受压面横向压应力约0.30 MPa。Nguyen/Foster CC 包络只给约3%局部峰值增强，无法单独解释 Case10 的缺口。

19/20/21/22 在当前恢复中受压混凝土区主要/全部为 TC，因此未来正式 TC 门禁必须检查是否会把已有低估进一步扩大。

## 7. TC容量门禁诊断

Nguyen/Foster TC 包络有来源，但 Swartz 表没有逐板实测 `ft`。项目历史临时锁 `ft=0.10fc` 仅可用于方向性诊断。

保持 `D,Pcr,C,G,J,Ppb` 全部冻结，联立轴力、弯矩和TC峰值门禁。临时 `ft/fc=0.10` 得：

|Case|未加TC Pu kN|TC诊断Pu kN|Pf kN|TC后误差|
|---:|---:|---:|---:|---:|
|1|567.712|495.989|490.194|+1.18%|
|2|561.638|501.025|506.652|-1.11%|

原根 TC tensile-envelope utilization：

- Case1 1.279；
- Case2 1.216；
- Case9 0.910；
- Case10 0.890。

因此 `ft=0.10fc` 的来源式门禁会**选择性地下修1/2而不先截断9/10**。

但结果对 `ft/fc` 强敏感：

|ft/fc|Case1 PuTC kN|Case2 PuTC kN|
|---:|---:|---:|
|0.08|442.12|445.19|
|0.09|470.18|474.24|
|0.10|495.99|501.02|
|0.11|519.93|525.92|
|0.12|542.29|549.21|

所以当前只允许：

```text
TC_SELECTIVITY = SUPPORTED
TC_EXACT_CORRECTED_PU = NOT FROZEN
SWARTZ_FT_SOURCE_CLOSURE = REQUIRED BEFORE PRODUCTION
```

## 8. Nguyen 0.85fcyl 转换链容量侧敏感性

Nguyen 对 Swartz 的分析强度采用：

\[
f_c^{analysis}=0.85f_{cyl}.
\]

本轮不改刚度，只在最终截面容量层做敏感性。若容量层采用完整 `fcyl`：

|Case|Pu(fcyl) kN|相对Pf误差|
|---:|---:|---:|
|1|645.565|+31.70%|
|2|641.234|+26.56%|
|9|595.578|-4.84%|
|10|619.458|-11.02%|
|19|376.766|-0.24%|
|20|370.522|-0.60%|
|21|385.768|+4.74%|
|22|388.216|+9.09%|

这说明：

- 完整圆柱强度会严重恶化 Case1/2；
- 大幅改善 Case9/10；
- 几乎恰好闭合 Case19/20；
- 会让 Case21/22 由接近转为偏高。

因此 `0.85` 不能被简单改成一个新的全局常数。

---

## 9. fcyl + CC 联合量级

在结构层冻结下，诊断地使用 `fcyl` 为基础容量，再施加受压面 CC 包络：

- Case9: `Pu≈612.407 kN`, 误差约 `-2.15%`；
- Case10: `Pu≈636.653 kN`, 误差约 `-8.55%`。

Case9 大部分缺口可由“基础容量更接近圆柱强度 + 小CC增强”解释；Case10仍有明显剩余异常。

---

## 10. 当前结论

目前最合理的工作分解不是统一系数，而是：

\[
\boxed{\text{base-strength conversion}+\text{TC weakening}+\text{small CC enhancement}}.
\]

但三个组成部分的身份必须分开：

- `0.85fcyl` 是 Nguyen 对 Swartz 的分析来源约定；是否适用于最终极限截面仍需来源审计，不能用Pf反标。
- TC 包络形式有来源，但 Swartz `ft` 未源闭合，数值校正只能是诊断。
- CC 包络有来源且当前应力水平只支持小幅增强，不能解释成强围压。

当前不授权修改 `D/Pcr/Ppb`，也不授权按单板试验误差拟合 `fc`、`ft` 或 q0。
