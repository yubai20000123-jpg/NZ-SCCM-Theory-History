A. R10 材料层

逐式检查：
- κ=E0 ε0/fc 的量纲和初始切线意义；
- ρ、x_cr、η 的定义及来源身份；
- Πη(z) 是否满足预期的平滑正部性质、零点值/导数性质；
- c(λ)、t(λ) 的拉压符号约定；
- C(λ) 的零点、初始导数、压缩符号及极限行为；
- Foster 源拉伸函数、H(r,r0)、T_src、W_src 的数学关系；
- u1、u2、h 的端点值、一阶/二阶连续性和材料功闭合是否真的成立；
- T、T^7、U 的零点 C1 锚点是否由公式本身推出；
- 主应力式 s+、s- 与张量式 S 是否严格等价；
- a_cc 是否已在仓库中给出唯一来源和值；若没有，标记阻断级别。

不得只复述文件中的 PASS，要自行求导/代入验证。

B. 等效应变与张量层

独立从式 E_u 推导 X11、X22、X12；检查工程剪应变和张量剪应变的 2 倍关系是否一致。
检查 λ± 的主值公式。
检查 current map 是否客观、主值交换对称、在重复特征值 λ+=λ- 时是否连续且方向无关。

C. N48-C1/MM 编译层

独立检查：
- 49 个 Chebyshev roots 与 degree 48 的关系；
- direct coefficient 公式的归一化系数 2-δn0 是否正确；
- H=V^T V 的对角形式是否正确；
- G 的第二行是否确实是对真实 λ 的导数而非 ξ 导数；
- C1 minimum-disturbance 公式是否是带等式约束二次最小化的正确闭式解；
- 约束矩阵是否满秩、何时可能失秩；
- T constrained-minimax 定义是否存在/是否唯一/是否足以形成可复现的生产系数；
- 该层是材料坐标近似，不是空间离散；
- 但仍需检查材料值误差和一阶切线误差是否有明确接受门，不能因为“零空间积分”而忽略材料近似误差。

D. Cayley–Hamilton 二维提升

独立从二维 Cayley–Hamilton 恒等式与 Chebyshev recurrence 推导 A_n、B_n 递推。
检查：
- T_n(Y)=A_n I+B_n Y 是否对所有 2×2 对称 Y 成立；
- 与主值逐点应用标量 F(λ±) 是否等价；
- 不同 primitive 形成的矩阵是否都是 Y 的函数，从而相互可交换；
- CC、TC、TT 张量式是否与主应力式严格一致。

从
w0=A0 sinX sinY,
w1=A sinX sinY

- χq=q0 q+q²/2；

- ex、ey、gxy；
- b≠ℓ 时所有 b/ℓ 比例；

- q0 是 stress-free reference imperfection、q 是 added displacement，因此初始点为 (D,q)=(0,0) 是否自洽。

F. “N48 coefficient → D15”闭合性

这是重点阻断审计。

不要默认以下陈述成立：
“所有实际 integrand 都可写成 C_i(sinX) C_j(sinY) C_k(ζ) 的有限和。”

必须实际检查 Nguyen 场中含有 cosX、cosY、sinX cosX、cosX cosY 的项后，以下对象是否落在声明的 D15 基函数闭包内：
- S_yy；
- Q_q=S:∂e/∂q；
- current tangent/stability 所需 integrand；
- 钢筋 contribution。

如果单独 S_xy 或某中间 primitive 不能仅由 sinX/sinY 的函数表示，但最终实际 integrand 因奇偶性/乘积而闭合，要明确证明“中间不闭合、最终 integrand 闭合”。
如果需要更一般的 sin^p X cos^r X sin^q Y cos^s Y ζ^h 精确矩，必须指出当前式(85)–(94)是否写窄了，并与历史 D15/D15R 原始基核对。

逐一独立验证：
M_n=∫_0^π C_n(sinX)dX；
Z_k=∫_-1^1 C_k(ζ)dζ；
JΩ=bℓtp/(2π²)。

G. P_c 与 R_q 的力学来源

检查：
- Pc=-(1/ℓ)∫σyy dV 的力学意义：为什么是沿 y 的体积平均而不是某一截面的直接应力合力？该定义在近似位移场下是否与轴向平衡一致？
- Pc=-fc b tp/(2π²) D[Syy] 的 Jacobian 与 ℓ 消去是否正确；
- Q_q=S:∂e/∂q 是否与虚功原理一致；
- Rq,c=fc ε0 JΩ D[Qq] 的量纲是否为与无量纲 q 共轭的力×长度；
- 钢筋 Ps、Rq,s 是否在当前正式理论中已经给出足够显式的闭式公式，而不是只有符号占位。

如果钢筋部分无法仅凭正式理论逐式算出，标记 INCOMPLETE_REBAR_CLOSURE。

H. L 与 NC-R1 根拓扑

独立从 level-set differential geometry 证明：
t0=(Rq,q,-Rq,D) 是 Rq=0 的切向量；
L=P_D Rq,q-P_q Rq,D=∇P·t0。

重点检查：
- Rq,q=0 是否只是 q(D) 图表示失败而不是 L 失效；
- 真正正则性失败是否是 ∇Rq=0；
- g=dP/ds 与 L=0 的等价条件；
- first +→- maximum 作为 load-controlled ultimate 的力学解释是否成立；
- disconnected root、negative-q root 的排除是否是明确建模/初始缺陷方向假定，而非数学必然；
- R_norm 和 L_norm 是否无量纲、尺度合理；
- L_norm 的 D'=aD,q'=bq 重标度不变性是否严格成立；
- d_ij 的三个分量是否真的无量纲且尺度定义完整。

I. Zhou current-tangent 稳定骨架

重点审查，而不是默认接受：
- Ct=∂σ/∂E 来自同一 current operator 是否满足一致切线要求；
- Dx=tp³ Cxx,t/12、Dy=tp³ Cyy,t/12 等公式在 current tangent 随 X,Y,ζ 变化时，究竟代表局部值、厚度/面内平均值还是某个投影值；当前正式理论是否定义清楚；
- Dμ,eff、D66、H_eff 的映射是否与 Zhou/Navier 方程的张量 convention 一致；
- Ny,cr^Z 的量纲与 α、β 次数是否正确；
- 最重要：当前理论是否给出了“Zhou stability acceptance gate”究竟如何作用于生产状态/Pu 的明确判据。如果只有 Ny,cr^Z 公式但没有与当前膜力/状态比较的 gate equation，标记 INCOMPLETE_ZHOU_GATE。
