## 2. 结论排序
1. **fcr/fcyl 是本次所检验变量中最强的诊断量**：与有符号误差 Spearman ρ=-0.753, p=0.00002；去除 Southwell 的 Case1、4 后仍为 ρ=-0.819, p=0.000003。屈曲越接近材料峰值，当前 Pu 越倾向低估。
2. **Pf/Pcr 与误差有中等负相关**：ρ=-0.548, p=0.0056；去除 Southwell 后 ρ=-0.481, p=0.0236。但 Error=Pu/Pf-1 与 Pf/Pcr 共享 Pf，存在数学耦合，只能作为机制支持而非单独因果证明。
3. **b/t 对误差正负的统一控制弱**：ρ=+0.324, p=0.123；但与绝对误差有中等负相关 ρ=-0.462, p=0.023，即更细长板整体反而更容易被当前模型捕捉。
4. **总配筋率的全样本相关性弱**：ρ=+0.135, p=0.531；但这不等于钢筋对 Pu 不重要，因为 Swartz 原文明确把钢筋作用区分为“对初始屈曲应力小、对总承载力与屈后延性重要”。
5. **层数和 buckling-location 单独都不是主解释变量**；层数与厚度/配筋率强混杂，而 Table 2 的 location 是鼓曲峰区位置，不等同于完整模态。

### 2.1 组内钢筋率信号

把厚度组固定后，钢筋率与有符号误差的 Pearson 相关为：

- Case1–8：r=-0.606, p=0.111；
- Case9–16：r=+0.281, p=0.500；
- Case17–24：r=+0.939, p=0.00055。

因此“钢筋率无影响”不能作为极限承载力结论。特别是最薄的 Case17–24，误差随钢筋率从0.2%增加到1.0%由明显低估逐步转为高估；这应作为后续钢筋-屈后作用诊断对象，但不能据此反标钢筋模型。

## 4. Pcr测定可靠性边界

- Case1、4：Southwell plots。Swartz明确指出 Southwell 对非线性混凝土会高估屈曲荷载；这两块甚至出现 Pf/Pcr<1，因此不能把它们的 Pcr 当作与应变法同等可靠的“真实初始屈曲点”。
- Case5、6：由 deflection profiles 判断。
- 其余20块：主要由屈曲区附近两表面轴向应变的反向变化判据判断。

因此任何使用 Pf/Pcr、fcr/fc 或 Pcr 的相关分析都必须保留 `Pcr_method` 标志。

## 6. 当前机制判断

当前数据不支持“整体材料强度统一偏高/偏低”的单一解释。更合理的诊断排序为：

1. 屈曲时混凝土进入材料峰值的程度 `fcr/fcyl`；
2. 屈曲后的试验承载储备 `Pf/Pcr`，但须考虑共享 Pf 的数学耦合与 Pcr 判定方法差异；
3. `b/t` 所代表的稳定-材料非线性机制区间；
4. 钢筋对极限承载力/屈后延性的组内作用；
5. 层数与 Table2 buckling-location 仅作为次级诊断量。

本文件只授权后续机制审计，不授权修改 R10、N48、q0、钢筋材料参数或利用试验值进行板级校准。
